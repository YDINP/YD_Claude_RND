# run23 건설 개편 계획 (rebuild-plan-run23)

- 기준: 세이브 `ai-coop-run23`, tick 약 15.15M~15.16M, 진화 0.666, 연구 중 research-speed-5
- 근거: 읽기 전용 조사 5개 영역(광석·제련 / 중간재 / 과학·연구소 / 물류·전력 / 방어 보급). 게임 상태는 바꾸지 않았다.
- 목표 우선순위: (1) 대포(artillery) 연구 최단 경로 = 노랑팩 → (2) 철 병목 완화 → (3) 물류 로봇·요청 상자 전환 준비 → (4) 방어 보급 무중단
- 표기: "추정"은 레시피 손계산이거나 단순화한 값이다. 좌표는 조사 당시 값이고, 공사 직전에 `can_place_entity`로 다시 확인한다.
