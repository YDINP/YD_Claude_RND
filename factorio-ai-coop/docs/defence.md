# 방어선 — 조사와 규칙

> 20회차에 여덟 중 여섯을 잃고 나서 조사한 것. 출처는 공식 위키와 포럼이며,
> 각 항목은 «코드에 넣을 수 있는 수»로 끝맺는다.

## 0. 우리가 틀리게 읽고 있던 것

20회차 실측:

```
우리 건물          443채
포탑 사거리 안     169채  =  38%
포탑                55대  (사거리 18, 55대 중 53대가 서로 사거리 안)
공해 합            32,731   가장 짙은 칸 258
진화도             0.2219
```

우리는 이것을 「38%만 지켜진다」로 읽었다. 틀렸다.

위키 [Enemies](https://wiki.factorio.com/Enemies)는 벌레가 목표까지 **최단
경로**로 움직이며, *"If there is a clear path somewhere around those
obstacles, the biters will attempt to go around"* 라고 명시한다. 즉 —

> **커버리지 38%는 「38% 방어」가 아니라 「포탑을 지나가지 않아도 되는 뒷문이
> 62% 열려 있다」는 뜻이다.**

포탑 55대가 촘촘했던 것은 벌레 입장에서 무관했다. 애초에 그 앞을 지날 이유가
없었으니까. **문제는 간격이 아니라 사슬의 길이였다.**

이것이 이번 조사에서 가장 값진 한 줄이다. 방어를 「비율」로 재면 안 된다.
«닫혔나 열렸나»로 재야 한다. 95%는 5%가 아니라 **열림**이다.

## 1. 둘레냐 길목이냐

- 숙련자 다수는 **길목(chokepoint) 방어**를 권한다
  ([Defence design help](https://forums.factorio.com/viewtopic.php?t=69298)).
- 단, 그것은 **지형이 길목을 만들어 줄 때**의 얘기다. 물과 절벽은 벌레가
  통과하지 못하므로 그 구간은 «공짜 방어선»이다. 숙련자들은 기지를 물가·절벽에
  붙여 두를 둘레 자체를 줄인다.
- 자연 장벽이 없는 **평지 확장형 기지라면 길목이라는 선택지 자체가 없다.**
  부분 방어는 곧 우회로를 열어 두는 것이다.

**규칙** — 물·절벽으로 막히지 않은 모든 구간은 「열린 길목」으로 센다.
지형이 없으면 완전 둘레 방어가 유일한 답이다.

## 2. 벽

- 돌벽 체력 **350** ([Wall](https://wiki.factorio.com/Wall)).
- 함정: **대형 비터·스피터는 사거리 2칸**이라 단일 벽 바로 뒤에 붙은 포탑을
  벽 너머로 때린다.
- 배치: `벽 1줄 → 빈 칸 1 → 포탑`. 진화도가 올라 대형(약 0.5)·거대형(약 0.9)이
  나오면 `벽-벽-빈칸-포탑`.

**규칙** — 벽 없는 포탑은 초반 임시방편으로만. 벽이 있으면 포탑이 맞기 전에
벽이 먼저 깎여 생존 시간이 크게 는다.

## 3. 포탑 간격

- 건 터렛 사거리 **18** ([Gun turret](https://wiki.factorio.com/Gun_turret)).
- 사거리 원이 서로 겹치게 두면 한 대가 부서지거나 탄이 떨어져도 옆이 메운다.
- **겹침이 필요한 곳**: 공해 진원지 방향, 길목 입구.
  **불필요한 곳**: 물·절벽 구간(포탑 자체가 불필요).

**규칙** — 우리 문제는 간격이 아니었다. 같은 55대를 **12~14칸 간격**(여전히
사거리 18 안이라 겹침 유지)으로 성기게 펴면 훨씬 긴 둘레를 덮는다.
`RING_GAP = 12` 는 이 근거로 맞다. 고칠 것은 **사슬의 길이**다.

## 4. 공해와 진화 — 수치

[Pollution](https://wiki.factorio.com/pollution), [Enemies](https://wiki.factorio.com/Enemies):

| 항목 | 값 |
|------|-----|
| 흡수 주기 | 64틱(약 1초)마다 spawner가 자기 청크를 확인 |
| 흡수량 | 청크 공해 ≥ 20이면 `20 + 0.01 × 청크 공해` |
| 공습 발동 | 흡수 누적이 유닛 소환비용(소형 4, 거대 400)을 넘으면 그 유닛을 집결지로 |
| 공격대 | 1~10분 간격, 진화도가 높을수록 잦고 커짐(5~20마리) |

**진화도 상승 계수** (비가역):

| 원인 | 계수 |
|------|------|
| 시간 | `0.000004 / 초` — 막을 수 없음 |
| 공해 **생산** | `0.0000009 / 단위` — 이미 나간 공해를 청소해도 무효 |
| 둥지 파괴 | `0.002 / spawner 1개` — 공격적 확장이 직접 올림 |

> **공해 «합계»와 진화도는 다른 것이다.** 우리가 재던 32,731은 현재 구름의
> 잔존량이고 공습 «빈도/규모»에만 영향을 준다. 진화도는 누적 **생산량**으로만
> 오르며 되돌릴 수 없다.

**공해 줄이기 효과 크기 순서:**

1. **효율 모듈** — 압도적 1위. 전기 채굴기에 효율모듈1 3개 = 소비전력·공해 약
   **80% 감소**(90kW → 18kW). 같은 공해로 채굴기 5배.
2. **버너 → 전기 전환** — 버너 분당 12, 전기 분당 10인데 전기가 **2배 빠름** →
   채굴량 대비 공해 절반 이하.
3. **태양광** — 화력 공해 제거. 다만 초반엔 발전보다 채굴·제련 비중이 커서
   효율모듈이 먼저.
4. ~~나무 심기~~ — **바닐라에 나무 심는 기능은 없다.** 모드 얘기와 혼동 금지.

**규칙** — 공해 총량을 줄이면 공습 빈도만 준다. 적이 «약해지길» 바라면 생산
누적량을 줄여야 하고(효율모듈 → 전기화), 둥지를 필요 이상 부수지 말 것.

## 5. 초반(버너 시대)

- 탄창 용량: 인서터가 포탑에 넣을 수 있는 최대 **10개**.
- 발사 속도: 초당 10발(탄창 1개/초). 연사 연구 만렙이면 초당 25발.
  **교전이 길어지면 급탄선이 끊기는 곳부터 뚫린다.**
- 급탄: 버너 인서터는 노란 벨트에서만 안정적이라 초반엔 **포탑 3대당 하프벨트**
  수준이 한계. 일반 인서터로 바꾸면 벨트 하나로 둘레 전체 급탄 가능.
- 버퍼: `벨트 → 인서터 → (여유 1칸 남긴) 상자 → 인서터 → 포탑`.

**규칙** — 초반이라도 **얇게 전체를 두르는 편**이 두껍게 일부만 두르는 것보다
낫다(1번과 같은 논리). 포탑 1대뿐인 구간도 없는 것보다 훨씬 낫다.

## 6. 밖에서 일할 때 / 초소

- 방어선 밖 작업 표준: 모듈러·파워 아머 + 개인 레이저 방어 + 실드.
  탱크에 타고 개인 레이저를 켜는 조합이 특히 강하다
  ([Permanent Biter Defense](https://forums.factorio.com/viewtopic.php?t=32819)).
- 초소 구성 순서
  ([outposts](https://forums.factorio.com/viewtopic.php?t=14435)):
  1. 광맥·역 전체를 **2겹 벽**으로 두름
  2. 안쪽 둘레를 따라 레이저 포탑을 짧은 간격으로
  3. 로보포트 + 건설로봇 약 50기 + 수리키트 자동 공급
  4. 레이더 1 + 태양광 1 + 축전기 1 = 본진과 무관한 자립 정찰
- 부수 효과: **공해를 안 내는 초소는 벌레가 무시하고 지나친다.** 초소를 여럿
  두면 공격이 분산된다.

**규칙** — 멀리 나가 일하는 개체는 «포탑 사거리 안으로 물러설 경로»를 늘
확보해야 한다. 장기 채집지는 임시로 두지 말고 즉시 2겹 벽+포탑으로 정식
초소화한다.

## 우리에게 적용할 것 — 우선순위

1. **커버리지를 비율이 아니라 「닫힘/열림」으로 잰다.** 95%는 «거의 닫힘»이
   아니라 열림이다. `guard.py` 의 목표는 100%이며, 미달 구간은 「남은 일」이
   아니라 «뚫린 문»으로 보고해야 한다.
2. **포탑을 늘리기 전에 사슬을 편다.** 간격 12~14칸으로 성기게 펴서 둘레
   길이를 먼저 확보한다. 밀도는 그다음이다.
3. **증식을 방어선에 묶는다.** 밭이 방어선보다 빨리 자라면 매번 같은 일이
   난다 — 20회차의 사망 여섯 중 넷은 «후퇴 명령을 내린 뒤»에 죽었다.
4. **벽을 포탑보다 먼저.** 돌은 이미 남아돈다.
5. **효율모듈·전기화를 「고도화」가 아니라 «방어»로 분류한다.** 진화도는
   되돌릴 수 없으므로, 늦추는 것이 곧 방어다.

## 할 일 - 외곽 포탑을 돌벽으로 두른다 (사용자 지시, 21회차)

> "외곽쪽 포탑은 돌벽으로 둘러쌓는게 방어력을 올리는거같은데 추후에 진행해줘"

- 대상은 «외곽» 포탑만. 기지 안쪽 포탑은 벽이 길만 막는다.
- 포탑은 벽 «뒤 한 칸 이상»에 둔다 - 큰 바이터는 사거리 2 라 벽에 붙은
  포탑을 벽 너머로 문다 (위 조사 참고).
- 벽 HP 350, 돌벽 1개 = 석재 벽돌 5. 창고 돌 1,900 / 벽돌 85 (21회차 기준).
- 선행: `stone-wall` 연구 (빨간 팩). 연구 큐에는 걸어 두었다.
- 새 스크립트로 나눈다 (`scripts/wall.py`) - guard.py 에 얹지 않는다.

**진행 (21회차)** - `scripts/wall.py` 로 돈다. 둘러싸지 않고 «밖을 보는 변에
한 줄»(7장, 포탑 몸에서 한 칸 띄움). 외곽 판정은 포탑 무리의 중심에서 나가는
방향에 더 먼 포탑이 없는 것. 벽돌이 모자라면 창고 옆 가마 둘에 돌을 굽는다.
첫 순번: 외곽 42대 중 3대, 돌벽 13장.
