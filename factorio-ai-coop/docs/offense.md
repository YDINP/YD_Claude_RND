# 방어선 거리 규칙과 공격 계획 (2026-09-23, 21회차)

사용자: "적기지/몬스터에게 인식이 되지 않을정도의 거리에 방어선을 구축하고
직접 무기랑 공격수단을 동원해서 기지를 파괴할 계획도 세워줘."

## 1. «인식»의 실측 거리

| 무엇 | 거리 | 근거 |
|---|---|---|
| 소형 웜 | 25 | prototype attack range |
| 중형 웜 | 30 | 실측 (2파 포탑 열 19.7칸에서 전멸) |
| 대형 웜 | 38 | 실측 (1파 포탑 열 19.5칸에서 일방 피격) |
| 베헤모스 웜 | 48 | prototype (진화 0.9 부터) |
| 둥지의 유닛 모이는 곳 | 둥지 주변 ~20 | 순찰 무리가 (110,62)에 - 둥지 (120,74)에서 15 |
| 순찰·확장 무리의 공격 반경 | 지나가는 길에서 ~30 | 회랑 y=10 (둥지에서 48~63)에서 사람이 쫓겼다 |
| 공격 «출발» | 공해가 둥지 청크에 닿을 때 | 포탑은 공해를 안 낸다 - 방어선 자체는 공격을 안 부른다 |

**규칙**: 방어선은 적 «구조물»에서 **70칸 이상**(베헤모스 48 + 여유), 우리 둘레에서
35칸 밖. 순찰 무리는 어디든 온다 - 그것은 방어선이 «맞아 주는» 것이다.

지금 네 줄 + 서쪽 전초의 가장 가까운 적(순찰 유닛 포함): 남서 85 · 남 71 · 동 68 ·
북 87 · 서 73. 구조물 기준으로는 전부 150 이상. 진화 **0.598** (빠르게 오른다 -
공해 416/h + 시간). 0.9 에서 베헤모스가 온다: 그 전에 아래 3단계를 끝내야 한다.

## 2. 지금 쓸 수 있는 공격 수단과 수치

관통탄 발당 피해 = 8 x 1.4(탄 연구) x 1.4(포탑) - 저항(감소). 사람 총은 포탑 배율이 없다.

| 수단 | 있나 | 대형 웜(물리 -10, 1500hp)에 | 둥지(1242hp, 저항 없음)에 | 한계 |
|---|---|---|---|---|
| 포탑 밀기 (관통탄) | O, 실증 | 5.7/발, 4대로 잡음 | 4대로 2초 | 세우는 10초 동안 웜 사정권. 사람은 반사로 튄다 |
| 기관단총 + 관통탄 | 레시피 O, 사람은 «못 쏜다» | 1.2/발 (배율 1.4만) | 11/발 | 모드가 shooting_state 를 안 준다 - 캐릭터는 스스로 안 쏜다 |
| 수류탄·디펜더 캡슐 | 레시피 O | - | - | 캡슐은 플레이어 API - 스크립트 캐릭터는 못 던진다 |
| 자동차 (기관총) | 레시피 O | 약함 | 가능 | 스크립트 운전은 riding_state 로 가능하나 조종이 거칠다 |
| 화염방사 포탑 | 석유 뒤 | 강함 (사거리 30) | 강함 | 원유 필요 - 지금 관로를 잇는 중 |
| 로켓 | 화학 팩 뒤 | 폭발 -10/30%: 63/발 | 좋음 | 사거리 36 < 38 |
| 독 캡슐·전투 산탄총 | military-3 (화학 팩) | - | - | |

결론: **지금 실증된 것은 포탑 밀기뿐**이고 그것도 사람이 웜 사정권에 10초 들어간다.
사람이 «스스로 쏘게» 만드는 것이 첫 투자다 (모드 `attack` 태스크: 가장 가까운 적을
향해 shooting_state, 체력 40% 아래면 포탑 곁으로).

## 3. 공격 계획 (단계)

### 3-A. 지금 (빨강·녹색·군용) - 둥지만 지운다, 웜은 남긴다
- 대상: 둥지가 있고 대형 웜이 없거나 하나인 무리. 동쪽 (120..142, 74..92) 둥지 3·중형 웜 3
  (대형 없음) 이 첫 대상 - 동쪽 방어선과 석유 회랑을 가장 위협한다.
- 방법: `creep.py` (열의 x 는 «우리를 때릴 수 있는 것» 기준, 셋이 4대씩). 둥지는
  포탑 사거리 안에 들면 2초에 죽는다. 웜은 유닛을 안 만드니 남겨도 된다 - 단
  그 사거리 안에 우리 것을 두지 않는다.
- 사람: 기관단총 + 관통탄 + 중갑옷을 «전원» 지급 (`arm.py`). 모드 `attack` 태스크로
  세우는 동안 쫓아오는 유닛을 쏜다. 반사는 포탑 곁으로.
- 준비물: 포탑 재고 62 -> 손으로 100대 더 (철 20·구리 10·톱니 10 씩, 창고에 넘친다).

### 3-B. 석유 뒤 - 화염방사 포탑 밀기
- 원유 -> 정유(기본) -> 경유/중유 는 고급 정유 뒤. 기본 정유는 석유가스만 준다;
  화염방사 포탑은 원유·중유·경유 아무거나 먹는다 -> **원유를 바로** 탱크에 담아 밀기.
- 화염 포탑 사거리 30 > 중형 웜 30 (동거리), < 대형 38. 대형 웜은 여전히 «세우면서
  맞는다» - 그러나 화염 피해는 저항을 뚫고 크다 (대형 웜 화염 3/70% 이라도 초당 수십).
- 사람이 원유 통(배럴)을 들고 가 채운다.

### 3-C. 화학 팩 뒤 - 로켓·독 캡슐·전투 산탄총, 그리고 포탑 위력 5+
- physical-projectile-damage-4/5 (화학) -> 관통탄 25+ - 대형 웜도 포탑 열이 이긴다.
- 로켓 발사기는 «총»이라 shooting_state 로 쏠 수 있다 (사거리 36).
- military-3 -> 독 캡슐은 캡슐이라 못 던진다; 전투 산탄총은 총이다.

### 3-D. 우선순위 (둥지 무리, 기지 (-40,30) 기준)
1. 동 (120..142, 74..92) - 191칸, 대형 없음 -> 3-A 로 지금
2. 북 (20,-180) 둥지 4 - 218칸 -> 3-A
3. 남서 (-252..-272, 101..114) 둥지 3·대형 웜 3 -> 3-B 이후
4. 남 (-81..-94, 258..288) 대형 웜 6 -> 3-C 이후
5. 남남서 (-188..-212, 200..212) 둥지 4·대형 1 -> 3-B

## 4. 안 하는 것
- force.chart, 스크립트로 투사체 생성, 적 세력 조작 - 게임이 주는 수단만 쓴다.
- 사람이 총 없이 웜 사정권에 서는 일. 세우는 10초는 예외이고 그것도 반사가 덮는다.
