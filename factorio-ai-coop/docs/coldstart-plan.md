# 22회차 콜드스타트 설계서 — 맨손에서 빨강·초록 45/분까지, 그리고 그 다음

교리: `doctrine-v2.md`. 수치 출처는 전부 실행 중인 게임이다 (`ratio.py`, 프로토타입 조회, 2026-09-24).
좌표는 월드마다 다르므로 이 문서는 **모듈의 크기·순서·통과 조건**만 정한다. 좌표는 P0-1 조사
뒤에 `docs/run22-site.md` 에 적는다.

## 0. 최종 목표부터 (T2 = 첫 번째 완성형)

**빨강 0.75/s + 초록 0.75/s (각 45/분), 연구소 10대, 탄약 자동 공급, 전력 여유 50%.**

`ratio.py automation-science-pack=0.75 logistic-science-pack=0.75` (조립기 1형, 돌 화로):

| 줄 | 초당 | 기계 |
|---|---|---|
| 철판 | 5.62 | 돌 화로 18 ← 철광석 5.62/s = 전기 채굴기 12 |
| 구리판 | 1.88 | 돌 화로 6 ← 구리광석 1.88/s = 전기 채굴기 4 |
| 구리선 2.25 · 톱니 1.88 · 회로 0.75 · 팔 0.75 · 벨트 0.75 | | 조립기 2 · 2 · 1 · 1 · 1 |
| 빨강 0.75 · 초록 0.75 | | 조립기 8 · 9 |
| 탄창 (방어) | 역압으로 0~0.5 | 조립기 1 (철판 최대 2/s — 버스 여유분으로) |

철판 수요: 과학 5.62/s + 탄약 여유 2/s → **철 기둥은 돌 화로 24대(7.5/s)** 로 짓는다. 탄약이
멈추면(포탑이 차면) 철판은 벨트에 차서 채굴기가 멈춘다 — 그것이 역압이다. 상자에 쌓지 않는다.

**연료 (석탄 4MJ):** 돌 화로 90kW = 0.0225/s × 30대 = 0.68/s · 보일러 1.8MW = 0.45/s.
**전력:** 채굴기 22×90kW + 조립기 25×75kW + 연구소 10×60kW + 팔 약 100×15kW(평균 1/4) ≈ **4.6MW**
→ 보일러 4 · 증기기관 8 (7.2MW) = 여유 55%. 보일러가 다 돌면 석탄 1.8/s.
**석탄 합계 ≈ 2.5/s → 전기 채굴기 5대** (광맥이 약하면 6대).

## 1. 레이아웃 (모듈)

```
   [철광 채굴기 12~15] ─ 광석 벨트 (광석|석탄 레인) ─▶ [철 기둥: 돌 화로 24, 양쪽 팔]
   [구리 채굴기 4~5]   ─ 광석 벨트 (광석|석탄)     ─▶ [구리 기둥: 돌 화로 6~8]
   [석탄 채굴기 5~6]   ─ 석탄 벨트 ─┬─▶ 두 광석 벨트의 석탄 레인 (옆치기)
                                    └─▶ 보일러 4
                                         │
   철판 2레인 · 구리판 1레인 ═════ 버스 (남북 또는 동서, 한 레인 = 한 품목) ═════▶
        ├─ 톱니·구리선·회로 → 버스에 다시 올린다 (톱니 1레인, 회로 1레인)
        ├─ 빨강 8 · 초록 9 (팔·벨트 조립기 포함) → 팩 벨트 2레인 (빨강|초록)
        ├─ 연구소 10 (팩 벨트 양옆)
        └─ 탄창 조립기 1 → 탄약 벨트 → 포탑 보급점
```

- 버스는 **처음부터 T2 크기로 자리를 비워 두고**, 흐르는 양만 늘린다. 나중에 옮기는 비용이 제일 크다.
- 화로 기둥은 «광석|석탄» 한 벨트 + «판» 한 벨트 (화로 줄 가운데 광석, 바깥 판 — 표준).
- 버스 끝은 **소비자가 끝**이다 (창고 상자 아님). 판이 끝에 차면 역압이 걸린다.
- 창고는 «짓는 재료»만 둔다: 사람이 짓기 위해 만든 기계·벨트·전봇대. 판 비축은 하지 않는다.

### 방어 관문 D (23회차부터 — «병행»이 아니라 관문. 22회차 복기: `docs/run22-postmortem.md`)

22회차는 이 절이 «P1 끝부터 병행»이었고, 한 번도 불리지 않은 채 8명이 전멸했다. 그래서:

- **P1 통과 조건에 D 가 들어간다. 그 뒤 모든 페이즈의 통과 조건에 «D 유지»가 들어간다.**
  공해를 늘리는 증설(채굴기·보일러·화로·조립기)은 `health.py` 위협 줄을 먼저 보고, ⛔ 가 있으면 증설보다 그것이 먼저다.
- D 의 조건 (`health.py` 위협 줄로만 판정):
  1. 경계(공해 구름 반경 + 64, 하한 300칸) 안에 적 구조물 0 — 있으면 진화 0.2 전에 지운다 (소형 웜·소형 바이터뿐, 포탑 4 + 일반 탄창).
  2. 포탑 ≥ 4 가 공격이 올 쪽(가장 가까운 둥지 방향)에, **탄약 벨트로** 채워지고 탄창 ≥ 10 (팔 자동 삽입 상한 = 가득).
  3. 사람 전원 무장 (기관단총 + 탄 100) — military 연구 직후.
- 정찰은 주기다: 공장이 커질 때마다(페이즈 통과 때마다) 경계 안을 걸어서 다시 밝힌다 (force.chart 금지). 새 둥지는 확장으로 생긴다 — 22회차의 새 둥지는 알던 것(570칸)의 절반 거리(213칸)였다.
- 포탑 줄은 적 구조물에서 70칸 이상. 포탑마다 탄약 보급 경로를 세우는 순번에 같이 만든다 (탄창 조립기 → 벨트 → 팔).
- 도망: 적 구조물 반경 안을 지나는 도망길은 쓰지 않는다. 도망 목적지는 로그에 남긴다.
- 방어/정찰 두 명은 `detached` 로 묶어 건설 루프가 부르지 못하게 한다.

### P4 고도화 — 같은 방식으로 «목표율부터»
1. `advanced-material-processing` → 돌 화로 24 → 강철 화로 12 (같은 판, 연료 절반, 자리 절반).
2. `automation-2` → 과학 블록 조립기 2형 교체 = 1.5배 (그만큼 채굴기·화로 +50% 를 **먼저** 짓는다).
3. 군사팩: `ratio.py military-science-pack=0.75` → 강철·돌벽 줄 포함 블록. 손으로 채우는 입력 없이.
4. 석유 → 화학팩. 회랑과 유전 방어는 탄약 벨트까지 한 번에 짓는다.
5. 확장은 복제다: 제련 기둥 + 과학 블록 한 벌을 통째로 복사해 T2 × 2 = 90/분.

## 4. 21회차에서 가져가는 함정 목록 (다시 밟지 않는다)

- 지하벨트 입구에 옆치기하면 **한 레인만** 통과한다 (석탄이 막혀 철 화로 전체가 연료 부족).
- 필터 팔은 **세운 순번에** 필터를 건다. 늦게 걸면 섞인 레인을 다시 깔아야 한다.
- 모드의 build 는 같은 계열 기계 위에 **겹쳐 지을 수 있다**(1형이 2형 위에). build 전에 can_place 로 확인한다.
- `detached.json` 은 동시 쓰기로 등록이 사라질 수 있다 → 사람마다 파일 하나로 바꾼다.
- 2x2 화로의 중심 c 는 c-1..c+1 을 덮는다. 팔을 그 안에 두지 않는다.
- 싱크 상자 = 느린 배수구. 차면 고리가 선다. 만들지 않는다.
- 반사로 도망갈 포탑: 탄이 있고, 공격자 반대쪽이고, 가는 길이 적 구조물 30칸 밖이어야 한다.
