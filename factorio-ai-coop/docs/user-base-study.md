# 사람이 지은 공장을 읽다 — 68시간 세이브 분석

사용자의 세이브(`saves/1.zip`, 68시간 · 기술 173개)를 사본으로 띄워 실측했다.
에이전트 셋(`structure` 배치, `intent` 의도, `improve` 개선점)이 따로 읽고
서로 반박하게 했다. 원본 세이브는 건드리지 않았고, 데몬 없이 띄워 지도가
바뀌지 않게 했다.

이 문서의 목적은 「사람은 어떻게 짓는가」를 우리 무리에게 가르치는 것이다.
우리가 이 세션 내내 겪은 실패(광맥 위에 제련소, 벨트 미로, 방어 늦음)가
여기서 전부 «사람도 겪은 것»으로 다시 나온다 — 규모만 천 배다.

## 2. 이 사람은 어떻게 지었나

### 밀집과 산개 사이에 아무것도 없다

장변 길이를 늘어놓으면 **165 이하 아니면 290 이상**이고 그 사이가 비어 있다.

| 밀집 (사람이 앉힌 것) | 산개 (광맥과 적이 정한 것) |
|---|---|
| 랩 24, 정유 49, 화학 86, 조립기3 125, 증기 165 | 전기화로 343, 태양광 520, 조립기2 558, 채굴기 891, 벽 997 |

**이것이 이 분석에서 가장 중요한 한 줄이다.** 랩은 9타일/대로 지었다 —
이 사람은 조밀하게 지을 줄 안다. 생산 설비에만 «안» 했다. 즉 능력이 아니라
**규칙의 부재**다. 버스에서 몇 타일 안에 지어야 한다는 규칙이 없으면,
건물은 「지을 때 서 있던 자리」에 선다.

우리 무리도 정확히 같은 병이었다. `city.lua` 이전의 구역은 전부
«짓다 보니» 정해진 자리였다.

### 철도를 거부하고 그 대가를 제련으로 치렀다

벨트 6,829 : 레일 268 = **25:1**. 기관차 1대, 역 2개.

기차가 없으니 먼 광맥을 벨트로 끌어야 하고, 벨트로 끌기 싫으니
**제련소를 광맥으로 보냈다.** 전기화로 150대가 332x343에 흩어진 이유가 이것이다.

그 대가가 벨트 방향 통계에 그대로 찍혀 있다:

```
화로 중심 (-77,-183)   버스 x=6~18   조립기2 중심 (38,-13)
남행 2,902  vs  북행 1,007
```

광석이 남으로 160타일 내려가 판이 되어 다시 올라온다. **귀환 경로가
하행의 3분의 1 굵기다. 병목은 가는 길이 아니라 오는 길이다.**

### 증기 고집이 자기를 먹이는 고리를 만들었다

```
증기 132MW : 태양광 5.6MW = 96:4
  -> 공해 -> 진화도 0.895
  -> 레이저터렛 117대 (방어의 100%가 전기)
  -> 전력 수요 증가 -> 증기 증설 -> (처음으로)
```

그리고 고리에 구멍이 하나 더 있다. 레이저 117대의 순간 전력은 총 발전
137.6MW와 «같은 자릿수»인데 축전지가 20개(버퍼 100MJ)뿐이다.
**공격마다 전 공장 브라운아웃**이 난다.

보일러 78대 만재 = 석탄 초당 35개 = **드릴 66대, 채굴 설비의 34%가
자기 발전소 먹이를 캐고 있다.**

## 3. 가동률 — 피라미드가 위에서 무너진다

| 계층 | 실측 산출 | 설비 환산 | 설치 | 가동률 |
|---|---|---|---:|---:|
| 채굴 | 원광 2,500~3,000/min | — | 193 (용량 5,790) | ~50% |
| 제련 | 철 872 + 구리 532 + 강철 76 | 47.5대분 | 150 | 32% |
| 조립 | 회로 194 / 고급 39 / 처리 3.43 | 25~30대분 | 186 | 13~16% |

(기간 평균이므로 현재값은 20~25%일 수 있다 — `improve` 자가 보정.)

처리장치 **3.43/min**. 조립기2 이론치 4.5/min의 **0.76대분**이다.
공장 전체의 블루서킷 산출이 기계 한 대에 못 미친다.

**벨트 6,829칸 x 8 = 최대 5.5만 개가 상시 이송 중이다.** 철판 872/min
기준 60분 치 생산량이 재고가 아니라 벨트 위에 동결돼 있다.

## 4. 로켓을 못 쏜 이유 — 장부가 닫힌다

로켓 부품 «정확히 100개»는 우연이 아니다. 사일로는 100에서 자동으로 멈춘다.
**로켓은 완성된 채 서 있다.**

```
로켓 부품 100 = 로켓제어장치 1,000 = 처리장치 1,000
노랑 과학 16,878팩 / 3 x 2  = 처리장치 11,252
                     합계    = 12,252
누적 처리장치                = ~14,000      <- 닫힌다
```

**68시간이 만든 처리장치의 88%를 노랑 과학이 먹었고 로켓 몫은 7%였다.**
3.43/min에서 로켓 1기분 1,000개는 공장 전체 산출을 **5시간 독점**해야 나온다.

그리고 그 다음이 진짜 막힌 곳이다 — **위성 생산 0**.
위성 = 태양광 100 + 축전지 100 + 레이더 100 + 처리장치 50 + 로켓연료 50.
지상의 축전지는 20개이고 태양광 94장은 «이미 땅에 깔려 있다».
**위성 라인이 아예 없다. 로켓은 준비됐고 화물이 없어서 서 있다.**

### 만든 것과 놓은 것

보라 과학 13,806팩을 만들려면(= 전기화로 1 + 생산성모듈 1 + 레일 30 -> 3팩):

| 만든 것 | 수량 | 땅에 놓인 것 |
|---|---:|---:|
| 레일 | 138,060 | **268** |
| 전기화로 | 4,602 | **150** |
| 생산성 모듈 | 4,602 | **0 (비콘 0)** |

**전부 과학팩으로 태웠다.** 생산성 모듈 4,600개 중 400개만 제련·회로
라인에 꽂았어도 위 가동률 표가 달라진다. 레일 13.8만을 만들고 광석은
700타일 벨트로 날랐다.

## 5. 변전소가 0개라는 사실

| 전봇대 | 공급 면적 | 배선 |
|---|---:|---:|
| 소형 | 25타일 | 7.5 |
| 대형 | 16타일 | 30 |
| **변전소** | **324타일** | **18** |

소형 : 대형 = **11 : 1**. 1,000x1,000 공장에 간선은 2,300타일뿐 —
**가늘고 긴 단일 트리**다. 말단의 전압 강하가 전 공장으로 전파된다.
소형은 7.5타일 데이지체인이라 바이터가 하나만 부수면 가지 전체가 암전된다.

그런데 로봇포트 건설 커버리지는 **13%**다. **끊겨도 봇이 못 간다.**
벽 2,069개도 같은 이유로 전부 수동 수리 대상이다.
(같은 이유로 3세대 도색이 62%에서 멈췄다 — 빨강 벨트 38%, 벌크 인서터 6.4%.)

그리고 이것이 4번과 같은 뿌리다. **비콘 배치의 표준 규격은
«변전소 열 + 비콘 열 + 기계 열»이다. 변전소를 안 쓰면 비콘 블록을
설계할 수 없고, 그래서 화로 150대가 속도 2에 머물렀다.**

비용은 이유가 아니었다. 변전소 70대 = 강철 700 + 고급회로 350 =
생애 고급회로의 **0.2%**.

## 6. 다시 짓는다면 — 5단계

### 1단계 (0~3h) — 버스를 한 번에 제대로 긋는다
현재 버스는 길이 230~290타일. **너무 짧아 공장이 안 들어갔고**, 그래서
화로가 (-77,-183)로 유배됐다. 8차선 폭(40타일)을 비워두고 **길이 600타일 이상**.
**버스에서 100타일 넘게 떨어진 건물은 짓지 않는다** — 이 규칙 하나가
16만 타일 스프롤을 원천 차단한다. 랩 밀도(9타일/대)를 모든 블록에.

### 2단계 (3~8h) — 전력과 공해를 먼저
효율 모듈 1을 드릴·화로에 «전량». 전기드릴 3슬롯 = 공해 10 -> 2/min.
파랑 과학 이전에 태양광 착수(1MW당 패널 23.8 + 축전지 20).
보일러는 피크 백업으로만. 목표 진화도 0.6 이하 — 그러면 벽 2,069개와
레이저 117대를 **아예 안 짓는다**.

> **진화도는 되돌릴 수 없다. 0.895는 영구다. 전력 전환은 늦출수록
> 비용이 아니라 손실이다.**

132MW 대체 비용은 강철 15,705(생애의 5.1%) + 구리 47,115(2.2%) +
회로 15,705(2.0%) — **50시간 전에 이미 감당 가능했다.**

### 3단계 (8~20h) — 블록화 + 철도
제련: 고속벨트 1개(45/s)를 전기화로 72대(0.625판/s)가 정확히 소화한다.
철·구리 각 **2열 x 36대 = 90x20 = 1,800타일**. 두 블록 3,600타일 —
현재 113,876타일의 **32분의 1**.
광석은 벨트가 아니라 열차로(최소 4~6 노선).
전봇대는 변전소로 통일 — 비콘 규격이 여기서 확정된다.
로봇포트는 **방어선 전체**를 덮도록.

### 4단계 (20~40h) — 조립기3 + 모듈 + 비콘
조립기2 전량 폐기, 조립기3 통일: **같은 인서터·벨트·부지에서 속도 +50%**.
비용 고급회로 3,720 = 생애의 2.3%.
**생산성 모듈은 과학팩에 태우기 전에 회로·제련 라인에 먼저 꽂는다** —
보라 과학이 강제로 4,600개를 만들어주므로 재료비는 이미 내고 있다.
비콘을 두르면 전기화로 실효속도 2 -> 5. **150대 일을 50대가 한다.**

### 5단계 (40h~) — 블루서킷 전용 + 로켓/위성 동시
목표 처리장치 **60/min**(현재의 17.5배). 생산성+비콘 조립기3 15대.
**노랑 과학과 로켓제어장치를 같은 버스에서 경쟁시키지 않는다** —
88:7 배분의 재발 방지책이다.
**사일로와 위성 라인을 같은 날 짓는다.** 사일로가 100/100으로 차기 전에
위성이 상자에 들어가 있어야 한다.

## 7. 우리 무리가 가져갈 것

| 사람의 실패 | 우리가 겪은 같은 실패 | 이미 넣은 규칙 |
|---|---|---|
| 버스 거리 규칙이 없어 16만 타일 스프롤 | 구역이 «짓다 보니» 정해짐 | `city.lua` — 짓기 전에 지도를 본다 |
| 제련을 광맥으로 보냄 | 제련 구역이 돌 광맥 위 155타일 | `clear()` — 광맥 위는 자리가 아니다 |
| 벨트 6,829 vs 레일 268 | 유통->제련 49타일을 154칸으로 돌아감 | `walk()` 길이 타이브레이크 |
| 방어를 진화도 0.895에서 시작 | 여유 13타일에서 터렛 2대 탄약 0 | `turrets_wanted(slack)` |
| 모듈 4,600개를 만들어 0개를 꽂음 | 탄약 누적 생산 0 | 세우고 잊지 않기 |
| 로봇포트 13%로 자동 복구 불가 | — | (아직 없음) |

그리고 하나 새로 배운다. **사람은 조밀하게 지을 줄 알면서도 규칙이 없는
곳에서는 산개했다.** 능력과 결과를 잇는 것은 «그때그때의 판단»이 아니라
«미리 정해둔 거리 규칙»이다. 우리 반장이 `lay_out()`을 먼저 부르는 이유가
바로 이것이고, 거기에 **「버스에서 100타일」 같은 상한**이 아직 없다.
