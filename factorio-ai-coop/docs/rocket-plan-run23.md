# 로켓 발사 계획 (run23)

요청 (09-28 16:5x): «이제 방어는 어느 정도 됐으니 로켓 발사를 위한 작업 및 효율 개선 진행. 기지 근처에 새로 생긴 적 기지들 제거하고, 우라늄도 필요하다면 끌어다 쓰도록 계획 세워서 진행.»

이 문서는 **조사와 계획만** 한다. 실측 tick 20,711,346 · 진화 0.790. 게임에는 아무것도 짓거나 바꾸지 않았다.
수치는 전부 브리지 질의 (`game.forces.player.recipes / technologies`, `get_item_production_statistics`, 엔티티 조회) 에서 왔다. 계산 가정은 조립기 2 (속도 0.75), 화학 공장 1, 강철로 2, 모듈 없음.

## 0. 한 페이지 요약

- **연구 3 개만 남았다**: speed-module-3 (300) → productivity-module-3 (300) → rocket-silo (1000). 선행 (production-science-pack · speed/productivity-module-2 · automation-3 · LDS · 로켓 연료 · 처리장치 · 콘크리트) 은 **전부 완료**.
  필요 팩: 빨강 · 초록 · 파랑 · **보라 각 1,600**, **노랑 1,000**.
- **병목 1 = 보라팩 (10 분 0)**. 줄은 있다 (조립기 1 대씩, (-94..-82,-83)) 하지만 재료 부족으로 섬. 보라 150/10 분이면 1,600 에 107 분.
- **병목 2 = 원유·구리**. 로켓까지 (연구 + 사일로 + 부품 100) 총량: 구리판 **165k** · 철판 91k + 강철 20.8k · 석유가스 375k + 가벼운 기름 110k (원유 ~46 만) · 돌 19.7k.
  지금 구리 10 분 5,000 (다 쓰임) → 구리만으로 5.5 시간. 원유 10 분 24k (정유 3 대가 **basic** 이라 가스만 45%) 이고 탱크 11,853 이 20/s 로 줄어드는 중.
- **우라늄은 로켓에 필요 없다** (rocket-part · rocket-silo 레시피에 우라늄 0, 실측). 전력은 증기 3 뱅크 (+18 MW) 로 충분 → 원자력은 **나중** (첫 발사 뒤).
- **적**: 반경 350 안 둥지 무리 7 (구조물 ~54). 대포는 지금 북동 (126,-144), 탄 0 - 전부 사거리 밖. 키트를 남동 → 남서 두 자리로 옮기면 7 무리 다 닿는다. 포탄 10 분 17~19 (재료 부족) 가 병목 - 원유 고치면 같이 풀린다.
- **순서**: P0 무비용 (정유 advanced 고정 · 분해 · 연구 대기열 · 연구소 모듈) → P1 원유 우물 4 → P2 구리 ×2 · 강철 → P3 발전 뱅크 3 → P4 보라 150 → P5 노랑·PU·LDS → P6 로켓 연료 → P7 연구 → P8 사일로·비축 → P9 발사. 대포 소탕 (P-A) 은 P0 부터 병행.
- 예상: 건설 2~3 시간 + 연구 ~2 시간 (비축과 겹침) + 부품·발사 ~1 시간 → **5~6 시간**.
