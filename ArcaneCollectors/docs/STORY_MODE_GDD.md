## 0. 이 문서가 푸는 문제

ArcaneCollectors는 세계관과 캐릭터 설정이 풍부하지만, **플레이어가 게임 안에서 읽는 이야기가 하나도 없다.**

| 항목 | 착수 전 상태 |
|------|-------------|
| 챕터 서사 | `stages.json`에 `story_intro`/`story_clear` 필드는 있으나 **코드에서 전혀 사용되지 않음** (`src/types/stage.d.ts`에 타입 선언만) |
| 텍스트 품질 | 챕터 1~2의 한국어가 기계번역/파손 수준 ("숲의 가장 깊. 거대한 그림자가 나타에 걸려있다") |
| 컷씬 | 없음 |
| 캐릭터 대사 | 없음 (설계 문서에만 존재) |
| 온보딩 | 없음. 신규 유저는 로그인 직후 **13항목 메뉴 그리드**를 마주함 |
| 신규 유저 파티 | 레거시 `char_1`~`char_4` — 게임의 코어 루프(미정령→기본영웅→전직)와 **무관** |

본 GDD는 위 6개 공백을 메우는 기획을 확정하고, 구현 태스크로 분해한다.

## 1. 게임 비전 — game-design-director

### 1-1. High Concept

> **"당신은 신을 이기러 온 것이 아니다. 신이 사라진 자리에 무엇을 세울지 정하러 온 것이다."**

플레이어는 **수집가(Collector)**다. 균열로 흩어진 **미정령**을 발견해 **기본영웅**으로 각성시키고, 12기관 중 하나의 문 앞에 세워 **전직영웅**으로 만든다. 기관 선택은 분류가 아니라 **그 존재의 정체성이 결정되는 순간**이다.

5챕터를 관통하는 질문은 "균열은 누구의 소행인가"이며, 5-5에서 오딘이 "우리가 만들었다"고 자백하는 순간 질문이 뒤집힌다 — **"통합된 새 신화의 주인은 누가 되는가."** 그 답은 대사가 아니라, 플레이어가 그때까지 문 앞에 세워둔 영웅들이다.

### 1-2. Core Experience Pillars

| # | 필러 | 의미 | 이 기획에서의 구현 |
|---|------|------|------------------|
| P1 | **선택이 정체성이다** | 기관 선택을 무겁게 만드는 것이 스토리의 첫 번째 임무 | `evolve_gate` 컷씬을 기관 선택 화면 직전에 배치. 전직 대사를 **기관 루트별로 각각** 작성 |
| P2 | **읽히는 세계, 막지 않는 진행** | 서사는 보상이지 관문이 아니다 | 전 컷씬 스킵 가능. 스킵해도 보상·플래그 무손실(스텝 완료 커밋 귀속). Skip All 제공 |
| P3 | **유닛이 아니라 동행자** | 기본영웅 10명은 실제 인물 | 첫 만남 / 각성 / 전직(루트별) 대사 세트 44종 |
| P4 | **첫 세션 안에 첫 각성** | 온보딩의 성패는 코어 루프 1회전 체험 | 첫 세션 14분 내 첫 전직 완료. 챕터 1은 온보딩과 한 몸 |

### 1-3. 플레이어 프로파일

방치형 수집 RPG 경험자. 모바일 720×1280 세로, 한 손 조작. 세션 3~10분. 텍스트를 읽는 층과 스킵하는 층이 대략 반반이라고 가정하며, **두 층 모두 진행에 지장이 없어야 한다**(P2).

### 1-4. KPI

| 지표 | 목표 | 검증 방법 |
|------|------|----------|
| 튜토리얼 완주율 (T-01~T-12) | 85% 이상 | 스텝별 이탈 계측 |
| D1 리텐션 | 40% 이상 | — |
| D7 리텐션 | 20% 이상 | — |
| 첫 세션 내 챕터 1 클리어 | 60% 이상 | 1-5 first clear 도달률 |
| 첫 전직(기관 선택 확정) 도달 | **첫 세션 14분 이내** (KPI 상한 3일) | T-09 완료 시각 |
| 컷씬 스킵률 | 제한 없음 (스킵해도 무손실이 요구조건) | 스킵 후 보상 지급 회귀 테스트 |

### 1-5. 우선순위 원칙과 의존성

핵심 루프 → 세계관/캐릭터 → 레벨 구조 → 수치 → UX 순으로 진행했다.
의존성은 **내러티브 → 레벨**(스토리 이벤트 배치), **시스템 → UX**(튜토리얼 내용).
실행은 2웨이브 병렬이었다. 웨이브 1(내러티브 + 시스템) → 웨이브 2(레벨 + UX).

## 2. 내러티브 — game-narrative-designer

**산출물**: [`docs/story/NARRATIVE_STORY_MODE.md`](story/NARRATIVE_STORY_MODE.md) (2,002줄)

### 2-1. 요약

- **드라마틱 퀘스천**은 "신이 사라진 자리에 누가 무엇을 세울 것인가"이며, 답은 대사가 아니라 **플레이어의 세이브 데이터**다. 오딘의 최종 대사에 `{{ascendedCount}}` / `{{institutionCount}}`를 치환해, 플레이어가 지금까지 문 앞에 세운 영웅 수 자체를 반론의 증거물로 쓴다. **분기 0, 개인화 최대.**
- **보스 폭로 사슬 계승**: 1-5 "더 강한 자들이 온다" → 2-5 "배후에 신들이 있다" → 3-5 "더 큰 존재들의 계획" → 4-5 "내가 만든 것이 아니다" → 5-5 오딘 "**우리가** 만들었다".
- **수집가는 무언의 주인공**. 25스테이지 내내 침묵하고 5-5 에필로그에서만 2줄 말한다.
- **신규 NPC는 "등록관" 1명뿐**. 포트레이트가 없으므로 영구 `portraitId: null` + 실루엣 연출 전제. 정체(전대 수집가)는 세 번의 암시로만 남기고 확정 텍스트를 두지 않았다.
- **대화 선택지 없음**이 기본. 기관 선택 화면이 이 게임의 유일한 진짜 선택지이기 때문이다.

### 2-2. 산출 규모

| 항목 | 수량 |
|------|------|
| 컷씬 장면 | **26** |
| 대사 라인 | 약 202 |
| 기본영웅 대사 세트 | **44종** (첫 만남 10 + 각성 10 + 전직 루트별 24) |
| 챕터 1 완전 대본 | 5스테이지 전부 (진입/클리어, 1-5는 보스 전/후 분리) |
| 챕터 2~5 대본 | 챕터당 최소 3장면 (진입 / 보스 전 / 보스 후) |
| `story_intro`/`story_clear` 재작성본 | 챕터 1~2 전 스테이지 **20건** |

### 2-3. 데이터 SSOT 분리

`story.json`이 **컷씬 대본의 SSOT**, `stages.json`의 `story_intro`/`story_clear`는 **스테이지 카드용 1~2문장 캡션**으로 역할을 분리해 병존시킨다. 충돌 시 `story.json` 우선.

## 3. 시스템 — game-system-designer

**산출물**: [`docs/story/SYSTEM_ONBOARDING_ECONOMY.md`](story/SYSTEM_ONBOARDING_ECONOMY.md) (851줄)

### 3-1. 요약

- **레거시 스타터 폐지**. `char_1~4`를 버리고 `base_iris`(아이리스) 1명 확정 지급, **1인 파티로 시작**. 기존 보유자는 회수하지 않으며 세이브 `version` 1→2.
- **1-4가 의도된 벽**이다. 권장 500 대 초기 전투력 430으로 0.86배. 이 벽이 첫 무료 10연의 동기다.
- **첫 무료 10연**은 1-3 클리어 직후, standard 배너, 리롤 불허, 피티 정상 카운트. `GachaSystem` 로직은 **일절 수정하지 않고** 결과 위에 "각성의 인도" 봉투(오마르 조각 30)를 얹는다.
- **초기 젬 2,700 → 1,500.** Day3 누적 2,870이 되어 두 번째 10연이 정확히 Day3에 열리도록 유도한다. 티켓 10 유지(무료 10연 재원), `spiritStones` 6 신설, 각인서 1.
- **첫 각인 보증**: 기관 선택 확정 순간 각인서/에센스/불꽃 부족분을 **계정당 1회** 보전. 신규 재화 0종, `EVOLUTION_SYSTEM_GDD`의 3레이어 구조 불변. 결과적으로 **첫 전직이 Day1 첫 세션 12~15분**에 일어나 KPI 3일 대비 2일 여유가 생긴다.
- **메뉴 점진 해금**. 시스템 기준 마일스톤은 0 → 3(T-06) → 4(1-4) → **7(1-5 / T-11)** → 9~10(챕터2) → 13(챕터3)이다. **강제 스텝 4개**(T-03/05/07/09), 누적 2분, Skip All 제공.

### 3-2. UX에 넘긴 하드 제약

1. 강제 구간은 4개뿐이다. 첫 전투, 소환 버튼, 각성 버튼, 기관 선택 확정. **5개 이상은 시스템 측에서 기각한다.**
2. 첫 화면 그리드 항목 수는 0개, 첫 세션 종료 시 7개. **13개 동시 노출 금지.** 해금 SSOT는 `onboarding.unlockedMenus`.
3. 보상 지급은 컷씬 재생 콜백이 아니라 **스텝 완료 커밋**에 귀속한다. 멱등이고 스킵해도 손실이 없다.
4. 소환 화면 **확률 고지는 법적 요구이자 가챠 재활성화 차단 조건**이다.

## 4. 레벨 — game-level-designer

**산출물**: [`docs/story/LEVEL_STORY_PLACEMENT.md`](story/LEVEL_STORY_PLACEMENT.md) (974줄)

### 4-1. 요약

- **컷씬 26장면 전량 배치, 미배치 0.** 밀도는 52%(13/25)로 확정했다. X-2·X-3·X-4를 챕터마다 **의도적 무컷씬 3연속**(총 12스테이지)으로 두어 파밍 구간과 육성 이벤트의 무대로 쓴다.
- **1-4의 벽은 현행 배치로는 체험되지 않는다.** 10연이 1-3 클리어 직후 오므로 플레이어는 항상 2.78배로 진입한다. 트리거 시점을 건드리지 않고 그 사이에 **15초 "벽 인지 구간"**(전투 0, 에너지 0, 골렘의 "등록되지 않은 자, 통과 불가" 3줄 프리뷰)을 삽입해 좌절 대신 외부 귀인으로 전환한다.
- **난이도와 긴장의 정합**은 1-4, 1-5, 2-5, 3-1, 4-1에서 완전 일치한다. 어긋난 5곳 중 최대 문제는 **보스 점프율의 단조 감소**(1-5 2.00배 → 5-5 1.07배)다. 4-5를 8,000, 5-5를 18,000으로 상향하고 3-5에 2페이즈 기믹을 얹어 대응한다. **챕터 1~2 수치는 한 값도 건드리지 않아 Day1~3 시뮬이 보존된다.**
- **첫 세션 실측 15분 41초**로 목표 상단을 41초 초과했다. 자동진행 3.0초/줄과 회수안 3종으로 14분 36초가 된다. **4.0초/줄이면 18분으로 KPI가 붕괴한다.**
- **보스전 규칙**: `boss_before`는 재도전 시 재생하지 않는다. 패배 화면 기본 포커스를 [재도전]이 아니라 **[파티 편성]**에 둔다. 5-5 개인화 변수는 재생 직전 스냅샷으로 고정한다.

## 5. UX — game-ux-designer

**산출물**: [`docs/story/UX_ONBOARDING_FLOW.md`](story/UX_ONBOARDING_FLOW.md) (1,327줄)

### 5-1. 요약

- 스텝 T-01~T-12를 그대로 승계하고 **강제는 정확히 4개**(T-03/05/07/09)다. 나머지 8개는 코치마크에 개별 폴백 동선을 붙였다. 전체 14분, Skip All 약 5분, **첫 성공 2분 40초, 첫 기관 선택 9분 20초.**
- **"딤이 있으면 강제, 없으면 안내"**라는 단일 UI 문법으로 12스텝을 관통시켰다. 잠긴 메뉴는 자물쇠로 그리지 않고 **아예 렌더하지 않는다**. 스텝 단위 그리드 추이는 0 → 2 → 3 → 4 → 7 → 8 → 10 → 12 → 13이다. 시스템 문서의 마일스톤 표기보다 해상도가 높을 뿐 충돌은 아니며, **시작 0개 / 첫 세션 종료 7개 / 최종 13개**라는 세 고정점은 양쪽이 동일하다.
- 컷씬은 `PopupBase`가 아니라 **신규 `CutsceneScene`**으로 간다. 근거는 부모 씬의 `update`와 트윈이 계속 도는 문제, `activePopup` 단일 제약(T-09에서 팝업과 동시 표시 불가), depth 경쟁, 그리고 `BattleScene`에서도 호출해야 한다는 점이다.
- **`portraitId: null` 폴백을 예외가 아니라 기본 연출로 설계**했다. Graphics 벡터 엠블럼과 실루엣 3종으로 **신규 이미지 자산 0건**에 컷씬 26장면을 출시할 수 있다.
- 하이라이트 대상은 **TID 3단 해석**이다. 레지스트리 → `setName('tid:…')` → 정적 좌표 순으로 찾고, 해석에 실패하면 **마스킹 자동 해제 후 코치마크로 강등**하는 것을 불변 규칙으로 못박아 갇힘을 원천 차단했다.
- 재감상 동선은 **도감 '이야기' 탭**이다.

### 5-2. 신규 컴포넌트 13종

| 우선도 | 컴포넌트 |
|--------|---------|
| **P0** | `CutsceneScene`, `CutscenePlayer`, `TutorialManager`, `TutorialTargetRegistry`, `TutorialOverlay`, `CoachMark`, `MenuGridGate`, `RateDisclosurePanel`(법적), `SpeakerSilhouette`, `src/data/tutorial.json` |
| **P1** | `StoryLogPopup`(도감 탭), `ReturningPlayerCard` |
| **P2** | `PowerComparisonBanner` |
