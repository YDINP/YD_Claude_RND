# 치비 스프라이트 + 명상 로비 전환 계획 (2026-09-03)

> 사용자 지시: (1) 전신 이미지 대신 2~3등신 캐릭터를 **공용 규격 고정** 스프라이트 시트로 뽑아 애니메이션처럼 움직이게 할 것, 메인 캐릭터 1인 선행 시도. (2) 메인 로비를 "보스를 공격하는 방치 전투"에서 **"파티원이 명상해 보상을 쌓는"** 구조로 변경.

---

## A. 치비 스프라이트 규격 (SSOT)

모든 캐릭터가 동일한 캔버스·등신·앵커를 쓴다. 캐릭터마다 크기가 달라지면 파티 4인이 한 무대에 설 때 정렬이 무너지므로 **규격을 데이터가 아니라 후처리에서 강제**한다.

| 항목 | 값 | 근거 |
|---|---|---|
| 셀 크기 | **256 × 256** px | 4인 배치 시 base 720 폭에서 여유(각 160~180 표시) |
| 등신 | 2.5등신 (big head / small body) | 지시값. 프롬프트 `2.5 heads tall` 고정 |
| 캐릭터 높이 | 셀의 **82%** (210px) | 프레임 간 크기 흔들림 제거 |
| 발밑(접지) y | 셀의 **94%** (240px) | 바닥선 정렬 기준. 앉은 포즈도 동일 기준 |
| 가로 | 중앙 정렬 | — |
| 배경 | 투명(알파) | 크로마키 그린 생성 → 후처리 제거 |
| 시트 배치 | 가로 1행, 프레임 순서 고정 | Phaser `spritesheet(frameWidth:256, frameHeight:256)` |

### 프레임 세트 (공통 4종)

| 프레임 | 용도 | 포즈 |
|---|---|---|
| `idle` | 파티 편성·대기 | 서 있는 기본 자세, 눈 뜸 |
| `meditate` | 로비 명상 기본 | 가부좌, 눈 감음, 손 무릎 |
| `channel` | 집중 게이지 상승 | 가부좌, 합장, 오라 강화 |
| `awaken` | 보상 수확 순간 | 눈 뜸, 팔 벌림, 에너지 방출 |

**움직임은 프레임 수가 아니라 트윈으로 만든다.** 4프레임만으로 충분한 이유는 명상 연출의 핵심 동작이 부유·호흡·발광이기 때문이다.

| 연출 | 구현 |
|---|---|
| 호흡/부유 | `meditate` 프레임에 y ±4px, 2.4초 sine yoyo |
| 집중 상승 | `meditate` ↔ `channel` 교차 페이드(게이지 비율에 따라 빈도 증가) |
| 오라 | 교단색 파티클 + 발밑 룬 원 회전 |
| 수확 | `awaken` 0.6초 + 스케일 1.0→1.12 펀치 + 빛기둥 |
| 눈 깜빡임 | 필요 시 `idle` 전용 2프레임 추가(현재 범위 밖) |

### 생성 파이프라인

```
tools/art/gen-chibi.mjs        # ComfyUI(novaAnimeXL), 고정 시드 + 포즈 프롬프트만 교체
  → art/gen/chibi/<hero>_<frame>.png        (1024², 크로마키 그린)
tools/art/build-chibi-sheet.py # 크로마키 제거 → 최대 연결성분만 → 규격 정렬 → 가로 시트
  → art/gen/chibi_sheet/<hero>_sheet.png    (256×256 × N)
  → art/gen/chibi_sheet/chibi-manifest.json (cell/bodyHeight/footY/frameOrder)
```

**함정 기록**
- 프롬프트에 `character sheet` 계열 뉘앙스가 섞이면 좌우에 분신이 생긴다 → `solo, 1 character only` + 네거티브 `multiple views, duplicate, twins, character sheet, turnaround`로 해소.
- 프레임 간 정체성은 **시드 고정**으로 유지된다(포즈 문구만 교체).
- 크기·위치 흔들림은 생성으로 못 잡는다. 후처리 정규화가 규격의 실제 보증자다.

### 선행 시도 결과 (아이리스)

`art/gen/chibi_sheet/base_iris_sheet.png` (1024×256, 4프레임). 정체성(은백 단발·금안·남색 재킷·번개 모티브) 4프레임 일관, 분신 0, 규격 정렬 완료. 검증 시트 `art/portraits/sheets/2026-09-03_sheet19_chibi_v2.jpg`.

### 확장 순서

1. **아이리스 1인** (완료) → 로비에 실제 적용해 규격·연출 검증
2. 기본영웅 나머지 9인 (프레임 4 × 9 = 36장, 약 5분)
3. 전직영웅 24종은 기본영웅 시트를 **교단색 틴트 + 이펙트 차등**으로 재사용, 인기 캐릭터만 전용 생성

## B. 메인 로비: 보스 전투 → 명상 성소

### 컨셉

파티가 성소에서 **명상하며 마력을 축적**한다. 화면 중앙 제단에 에너지가 차오르고, 가득 차면 수확한다. 세계관상 "균열로 흩어진 신성을 모으는 수집가"와 맞물린다.

### 로직 매핑 (기존 `IdleProgressSystem` 재사용, 수치 변경 없음)

| 기존 | 변경 후 표현 | 비고 |
|---|---|---|
| 파티 DPS | **집중력(명상력)/초** | 계산식 그대로 |
| 보스 최대 HP | **다음 수확까지 필요한 마력** | 임계치 |
| 누적 데미지 | **축적된 마력** | 게이지 |
| 보스 격파 | **수확(정화 완료)** | 보상 지급 동일 |
| BOSS READY | **수확 준비 완료** | CTA 펄스 |
| 오프라인 누적 | 동일 | 복귀 시 스냅 |

**보상 로직·수치는 건드리지 않는다.** 표현 계층만 교체하므로 밸런스 회귀가 없다.

### 화면 구성 (base 720×1280 기준, 기존 관측창 영역 재사용)

```
┌──────────────── 관측창(마스크) ────────────────┐
│  성소 배경(교단색 틴트) + 상단 신성 입자        │
│                                               │
│        [파티2]      ✦제단✦      [파티3]        │  ← 원형 배치
│                   (마력 게이지)                 │
│    [파티1]                         [파티4]      │
│  ─────────── 바닥 룬 원(회전) ───────────       │
└───────────────────────────────────────────────┘
   집중력 128/초 · 다음 수확까지 00:42
   [ 수확하기 ]  (준비되면 골드 펄스)   [ 보스전 ]
```

- 파티 4인은 `meditate` 프레임으로 제단을 향해 원형 배치(앞 2·뒤 2, 뒤쪽 0.86배).
- 각 캐릭터에서 **교단색 오라 입자가 제단으로 흘러간다**(집중력이 높을수록 빈도↑).
- 제단은 마력 비율에 따라 밝기·회전 속도 증가, 100%에서 빛기둥.
- 수확 시 전원 `awaken` 프레임 + 보상 팝업.
- 미보유 슬롯은 빈 방석(잠금 표시).

### 유지해야 할 계약

`mainmenu.idle.view` 등 튜토리얼 타깃 키, `mainmenu.adventure.*` CTA, BOSS READY 진입 경로, `IdleProgressSystem` 호출부, 오프라인 복귀 스냅.

## C. 실행 단계

| 단계 | 내용 | 산출물 |
|---|---|---|
| C-1 ✅ | 치비 규격 확정 + 생성/후처리 파이프라인 + 아이리스 4프레임 | `gen-chibi.mjs`, `build-chibi-sheet.py`, `base_iris_sheet.png` |
| C-2 | 시트를 런타임 에셋으로 반영(webp, manifest `chibi` 버킷, 지연 로드) | `public/assets/characters/chibi/` |
| C-3 | `IdleBattleView` → `MeditationView` 재작성(표현만, 로직 유지) | 명상 성소 렌더 + 트윈 |
| C-4 | 아이리스 외 슬롯은 기존 실루엣/포트레이트 폴백 | 점진 적용 |
| C-5 | 기본영웅 9인 치비 확장 | 시트 9종 |
| C-6 | 전직영웅 틴트 재사용 규칙 | 매핑 표 |

**C-2·C-3이 이번 라운드 구현 범위**이며, 아이리스만 실아트로 서고 나머지는 폴백으로 둔다.
