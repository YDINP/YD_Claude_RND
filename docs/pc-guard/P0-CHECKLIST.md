## 사용자가 할 일

### 1. 랜섬웨어 폴더 보호 켜기 (관리자 권한 필요, 1분)
**관리자 PowerShell**에서:
```powershell
Set-MpPreference -EnableControlledFolderAccess Enabled
```
- 문서·사진·바탕화면 같은 기본 폴더만 보호한다. 작업 폴더 `D:\park`는 추가하지 않는다. node·git 쓰기가 막힐 수 있기 때문이다.
- 어떤 앱이 저장을 못 하면 Windows 보안 → 랜섬웨어 방지 → "앱 허용"에서 그 앱을 추가한다.

### 2. Chrome 비밀번호 75개 정리 (20분)
Chrome에 저장된 비밀번호는 같은 계정으로 실행되는 악성코드가 꺼내 갈 수 있다. 니케 건이 노린 것이 바로 이것이다.
1. 비밀번호 관리자를 하나 정한다: **Bitwarden**(무료·동기화) 또는 **KeePassXC**(오프라인)
2. Chrome `chrome://password-manager/settings` → 비밀번호 내보내기 → 관리자로 가져오기 → **내보낸 CSV는 즉시 완전 삭제**(휴지통도 비우기)
3. Chrome에서 저장 비밀번호를 삭제하고 "비밀번호 저장 제안"을 끈다
4. Edge도 `edge://wallet/passwords`에서 같은 방법으로 정리한다

### 3. 2FA 점검 (돈·배포 권한이 걸린 순서대로)
| 계정 | 2FA | 비고 |
|---|---|---|
| Google | ☐ | 패스키 또는 OTP 앱, 문자 인증만 쓰는 건 피한다 |
| Microsoft(Windows 로그인 계정) | ☐ | PC 로그인과 연결돼 있음 |
| 네이버 | ☐ | 해외 로그인 차단도 켠다 |
| GitHub | ☐ | 배포 권한이 걸림 — 가장 중요 |

| Supabase | ☐ | |

| Telegram | ☐ | 설정 → 개인정보 → 2단계 인증 비밀번호 |
| Discord / Steam / 게임 계정(니케 포함) | ☐ | |
| 가상자산 거래소(있다면) | ☐ | 출금 화이트리스트 |

### 4. 미끼 키 놓기 (선택, 10분)
1. https://canarytokens.org 에서 **AWS keys** 토큰을 만든다 (알림 받을 메일은 직접 입력)
2. 받은 키를 `D:\park\.env.backup`에 `AWS_ACCESS_KEY_ID=...` 형식으로 저장한다
3. 누가 이 파일을 훔쳐서 키를 써 보면 메일이 온다 → 이 PC가 털렸다는 확실한 신호

> 로컬 미끼 파일과 읽기 감사(SACL)는 관리자 권한이 필요해서 P3에서 따로 설치한다.
