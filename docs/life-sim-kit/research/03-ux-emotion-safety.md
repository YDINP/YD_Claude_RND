## 3.1 화면 흐름과 상태 머신

```
[intro 랜딩+설정] (실시간 카운터, 추모관 캐러셀)
    ├─ 진행 중인 삶 있음? → guard "돌아가기 / 새로 태어나기"
    │
[roll 출생 룰렛(3.3초) → 출생 신고서]

    │

    ├─ modal 결정 (내려두기 가능)
    ├─ 잠시 멈춤(회고 질문)

    └─ 주마등→장례→비문 연출
    │
[dead 사망 기록] (스크롤, 공감 패널)
    └─ 공유 카드 / 다시 태어나기
```

## 3.2 랜딩 구성

### 상단 히어로
- **언어 스위처** (en/ko/ja/zh/vi, aria-current)
- **밝기 버튼** (자동 → 어둡게 → 밝게 순환)
- **리드 문장**: "지금 이 순간에도 1초에 네 명꼴로 아기가 태어납니다… 어디서, 누구의 아이로 태어날지는 고를 수 없습니다. **당신이 그랬던 것처럼.**"

### 실시간 카운터
```
출생 = 경과초 × (172개국 연간 출생 합) / 31,557,600
사망 = 경과초 × 61,700,000 / 31,557,600
```

### 설정 4그룹 (세그먼트 버튼)

| 그룹 | 선택지 | 기본값 |
|---|---|---|
| 태어날 세상 | 지난/지금/다가올/아무 | 지금 (지난은 연도 select) |
| 나라 기준 | 출생아수(가중) / 인구 | 출생 |
| 생애 길이 | 약 30/60/90분 | 60분 |
| 당신의 나라 | select, 비교 표 생성 | 비어있음(짐작) |

### 하단 CTA
- `태어나기` + "설정은 그대로 두고 바로 태어나도 괜찮아요"
- `♪ 잔잔한 음악` (볼륨 슬라이더)
- `이어하기` (진행 중 삶)

## 3.3 출생 신고서 (비교와 맥락)

### 룰렛 연출
```
프레임 간격 = 40 + (i/26)^3 × 380 ms
26프레임, 전체 약 4초
prefers-reduced-motion 있으면 스킵
```

### 신고서 콘텐츠
| 영역 | 내용 |
|---|---|
| 상단 띠 | 출생 신고 / No. KOR-2026-1234567 |
| 배경 | 길로셰 무늬(사인×코사인 14가닥) |
| 이야기 문단 | "{년}년 {월}월, {나라} {도시/농촌 마을}의 {가장 가난한 20% 가정…}에서 {여자아이}로 태어났습니다. {형제 서열}. {종교}. {아버지 부재}." |
| 필드 그리드 | 성별/출생국/도시농촌, 가정형편(점 5개+분위), 부모나이, 기대수명, 5세 전 사망 확률, GDP |
| 지도 캔버스 | 출생지 위치 |
| 확률 문장 | "지금 태어나는 아기 중 **0.18%**가 대한민국에서 태어납니다. **558명 중 1명꼴입니다.**" |
| 비교 표 | (설정했을 때) 기대수명/5세사망/교육/GDP: 당신의 나라 vs 이 아이 |
| 같은 1초 4명 | 이름·도시/농촌·성별·형편 |

### 가드 문구 (리롤 억제)
```
"OOO, 대한민국에서 태어난 34세의 삶이 아직 이어지고 있어요.
새로 태어나면 그 삶은 기록 없이 사라집니다.

현실의 삶은 다시 시작할 수 없지만, 여기서는 고를 수 있어요."
```

## 3.4 플레이 화면 (3단 레이아웃)

### 반응형 중단점
```
≤860·800·640·560·480·420·400·350px → 한 단으로 쌓임
모바일: sticky 미니바 (나이, 진행도, 배속)
```

### 왼쪽 단
- **신분증 카드**: 길로셰 배경, 픽셀초상화, 이름
- **여권 MRZ 2줄**: `I<KOR이름<<…`, 생년월·성별·현재국·나이 36자
- **스탯 4종 막대** (0~100, 색상: good/gold/stamp/accent)
  - `<details>` 열어서 각 효과 설명
- **돈**: 순자산·연소득 "체감 원", PPP 달러 작게, 소득 위치

### 가운데 단
- **올해의 초점 칩** (나이 단계별 선택)
- **장면**: 192×60 논리해상도 픽셀아트 (집, 가족, 탈것, 날씨) + 캡션
- **인생 기록 피드** (최근순, aria-live=polite, 별표 최대 12개, DOM 1,500줄 상한)
- **상태 줄**: "대학교 2학년 · 서울 · 기혼 · 자녀 2명"

### 오른쪽 단
- **같은 1초 4명**: 현재 상태, 사망자는 흐리게 표시
- **인생 지도**: 10열 격자, 1칸 = 1년 (색상: 행복도)
- **생존 곡선**: SVG

### 상단 스티키 바
- 브랜드 / **나이 큰숫자** "34세" / "2060년 · 이름 · 1년 ≈ 50초"
- **진행 막대** (한 해 진행률)
- **배속 버튼** (❚❚ 멈춤, 1×~16×, 다음결정까지 »)
- **메뉴** (자동결정, 음악, 생각남기기, 밝기, 의견, 가족보기, 나가기)

## 3.5 결정 모달

### 구성
```
[종류 라벨] (잠시멈춤 / 작은선택 / 가족이 정해요 / 중대결정)
[오른쪽] 34세 · 2060년

제목
설명
.fact (통계 근거 한 줄)
선택 버튼 (굵은 라벨 + 작은 부연)

[잠깐 내려 두기 ▾] (하단 칩 decPeek로)
```

### 자동 결정 모드
- 추천 선택지에 `.auto` 표시
- 진행 막대 채워지며 카운트다운
- 대기 시간:
  - 잠시멈춤: 9초
  - 일반 결정: clamp(글자수/9, 5, 14)초
  - 16×배속: 절반

## 3.6 마지막 순간 연출 (풀스크린, 다크)

### 진행 (타이밍 밀리초 단위)

| 단계 | 내용 | 대기 |
|---|---|---|
| 1 | "마지막 해, 72세" | 1,800 |
| 2 | (있으면) 마지막 상실 한 줄 | 2,600 |
| 3 | "{나라}에서 (잠든 채 조용히) 숨을 거두었습니다." + 사인 | 2,200 |
| 4 | (있으면) 마지막 말 "…" | 2,600 |
| 5 | "눈을 감자, 지나온 날들이 스쳐 지나갔습니다." | 2,600 |
| 6 | **주마등**: 출생 프레임 + 장면들(교차페이드) + 행복띠 | 프레임당 420+2,100+min(1,500, 글자수×20) |
| 7 | **장례**: 종교·지역별 장례 양식(픽셀)+문장+참석문장 | 3,200/3,800/3,400 |
| 8 | **묘비문**: 생몰년, 비문 줄들, "단 한 번뿐인 삶이었습니다" | 줄마다 700(비문 1,100) |

### 컨트롤
- 어디서나 클릭 → 다음 (처음 900ms는 무시)
- Esc → 닫음
- 건너뛰기 → 2탭 확정 (3초 안)

## 3.7 사망 기록 구성

### 1단계: 사망 증명서 카드
```
사망 기록 · RECORD OF DEATH
No. KOR-2026-072
나라·성별 | 이름 | 2026 – 2098 · 향년 72세 · 도시

[일대기 문단 - 요약 거울]
"OOO에서 태어나 BBB에서 잠들었습니다."

[사인 문장 - 맥락 제시]
"대한민국에서 70대 사망의 약 N%가 같은 원인입니다 (WHO·GBD).
같은 해 태어난 여자아이 중 약 38%가 당신보다 오래 삽니다.
기대수명보다 3.1년 더 살았습니다."

[요약 그리드]
최종학력 · 마지막일 · 함께한사람 · 자녀/손주 · 
최종거처 · 가장행복했던해 · 살았던나라 → · 취미 · 남긴것 · 보낸시간
```

### 2단계: 공감 패널
- (교육용/15세미만) "왜 이렇게 일찍?"
- 숨겨진 발견, 회고, 오늘의 주제 결산
- **남기는 말** (60자) → 공유 카드에 인용
- 내 나라 비교
- **같은 1초 5명**: 짧은순(나 강조), "누구도 고르지 않았습니다"

### 3단계: 공유 카드
```
카드 미리보기 이미지(1080×1350)
공유 문구 (끝이 "너는 누구로 태어날까?")

[공유 방법]
이미지 공유 / 저장 / 글·링크 복사 / 의견
(인앱 브라우저 안내)
```

## 3.8 공유 카드 문구 체계

### 내용 우선순위
```
1. 이름 · 성별 · 출생국 · 도시/농촌
2. 확률 "○○에 태어날 확률 1/556"
3. 마일스톤 (기대수명, 5세 전 사망확률)
4. 사인 · 나이
5. "당신이 그랬던 것처럼"
6. 남긴 말 (선택)
7. "너는 누구로 태어날까?"
```

### 캔버스 생성 (클라이언트)
- 1080×1350, 20fps 렌더
- 폰트 로드 대기
- Web Share API 우선, 실패 시 다운로드

## 3.9 민감 주제 안전장치

### calm 모드 (30일)
```
trigger: 사망 기록 또는 추모관에 위기 문구 입력 감지

effect:
- 그 기기의 시뮬에서 자살 사건 발생 안 함
- calm 아이콘 표시 (첫 화면에 "모드 끔" 버튼)

위기 어구 예: "죽고싶다", "자해", "피하고싶다" 등
```

### 민감 사건 제외
```
주마등·공유에 절대 안 들어갈 것:
- 체벌, 가정폭력, 외도, 범죄, 도박, 흡연
- 아동학대, 조혼, 복권, 자살, 약물, 성폭력

공유 카드에 표시 안 함:
- 자살·성폭력·약물 사인
```

### 18세 미만 자살 사망
```
사망 기록에서:
- 사인 줄을 .quiet(흐릿하게)
- 바로 뒤 도움 안내 상자 (국가별 번호)

판매 권유 미표시:
- 간직하기 이용권 CTA 띄우지 않음
```

### 도움 창구
```
사망 카드 하단에 국가별 상담 번호 표시
예: 한국 109, 일본 いのちSOS, 미국 988
```

## 3.10 비교의 거울 (감정 설계)

### 거울 1: 실제 나라와 비교표
```
당신이 태어난 나라        이 아이의 나라
기대수명: 84.3세        기대수명: 72.4세
5세 전 사망: 0.3%        5세 전 사망: 11.7%
기대 교육: 16.6년        기대 교육: 9.2년
1인당 GDP: 54,029$       1인당 GDP: 8,400$
```

### 거울 2: 같은 1초에 태어난 4명
```
① 엘프 귀족 여자 (기대수명 700, 가정 형편 상)
② 인간 농노 남자 (기대수명 70, 가정 형편 극저)
③ 오크 전사 (기대수명 40, 기대 교육 5)
④ 하플링 상인 (기대수명 70, 기대 교육 12)

→ 비교: 같은 시간에 태어났는데 기대가 극적으로 다름
```

### 거울 3: 회고 질문 (플레이어 자신에게)
```
5세: "당신이 5살 전에 떠날 수 있었어요. 그때는 어땠나요?"
15세: "학교는 어떻게 되었나요?"
30세: "지금 당신의 월 소득은 얼마인가요?"
50세: "당신의 가족은?"
70세: "당신이 남길 것은?"
```

## 3.11 바이럴 루프 설계

### 공유의 3가지 힘

**① 결과 인증**
```
"태어날 확률 1/556 — 아랍에미리트에서 소녀로"
"72세, 말라리아로 사망 — 차드"
"91세까지 살았다"
```

**② 운명의식**
```
"같은 1초에 태어난 4명 중 나만 오래 살았다"
"형제가 3세에, 나는 80세"
```

**③ "너는 누구로 태어날까?"**
```
문구로 끝나 → 받은 사람이 자연스럽게 시작
클릭 → 태어나기 → 사망 → 공유 → 반복
```

### 메타 서사
```
"1인이 AI로 4시간 만들었다"
→ 개발 로그 공개 + 하루 수십 패치 = 신뢰
→ 해시태그 + 인증 글 폭발
```
