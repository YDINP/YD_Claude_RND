## 2.1 출생 추첨 (newLife)

### 국가 선택
```
국가 가중치 = 연간 출생아수 b (또는 인구 pop)
선택 확률 = b / Σb
```

### 개인 생성 순서

| 항목 | 규칙 |
|---|---|
| 성별 | 남아 0.512 (특정 국가 편향 있음) |
| 종교 | 국가별 rel % 가중 추첨 |
| 계층 q (1~5분위) | q = 1~5 균등 또는 지역별 편향 `w = exp(g·(q-3))` |
| 도시/농촌 | 저소득(PPP<15k): `odds(urb%, e^0.45(q-3))` / 나머지: `e^0.15(q-3)` |
| 모친 나이 | clamp(afm + 3 ± 상관 변수, 15, 46) |
| 부친 나이 | clamp(모친 + 부부차 ± 상관, 17, 70) |
| 형제 수 | λ = max(1, tfr × (저소득면 1.25 - 0.1(q-1))) |
| 초기 스탯 | hl=clamp(78+3(q-3)-u5/12±6, 40, 95), h=60±8, sm=50, so=55±6 |
| 재능 6축 | 공통 g~N(0,1) + 개별: 0.25g + 0.968·N(0,1) |

## 2.2 생존 모델

### 생명표 구성 (lifeTable)

**영아·아동 구간**
```
성별 e0 = le + 0.49·gap (여), le - 0.51·gap (남)
성별계수 k = 0.92 (여), 1.08 (남)

q0(영아) = min(0.25, im/1000 × k)
u5누적 = min(0.35, max(q0 + 0.0005, u5/1000 × k))

1~4세 위험도 H = -ln((1-u5)/(1-q0))
1~4세 분배 = [0.40, 0.27, 0.19, 0.14]
```

**5세 이상: Gompertz–Makeham**
```
μ(x) = A + B·e^(g(x+0.5))

A = 0.00025 + 0.000028·u5
g = clamp(0.112 - 0.00016·u5, 0.085, 0.112)

초고령 상한: max(μ, min(0.7, (0.39|0.5)·e^0.15(x-100)))

B는 e0 맞춤: ln B ∈ [ln 1e-8, ln 0.05]에서 50회 이분탐색
기대수명 = Σ(l_x - 0.5d_x), 0세만 0.85d_0
```

**기본 q에 배수 m을 곱함**
```
P = 1 - (1-q)^clamp(m, 0.25, 9)
```

### 사망 배수 m 요소

| 요인 | 배수 |
|---|---|
| 건강 편차 | exp((expHealth(a) - off - hl) × (5세미만 0.02, 나머지 0.03)) |
| 계층 기울기 | exp(-G(qe-3)) / 정규화 (G: 지역별 0.15~0.25) |
| 흡연(25세이상) | 1.7(흡연)/1.25(끊음)/1.0(비흡연) |
| HIV | 1.8(치료중)/1.4(6년미만)/7(미치료) |
| 만성질환 | 1.3(미치료), 1.0(치료중) |
| 난민/알코올/약물/수감 | 1.15 / 1.5 / 2 / 1.3 |
| 고립(25세이상) | so<75면 1+0.15·clamp((75-so)/35), 상한 1.35 |
| 85세이상 완화 | m^clamp(1-(a-85)/20, 0.3, 1) |
| 국가/시대 보정 | CAL[id] × eraMort |

### 사망 원인 가중표 (CT)

**연령대 구간**: `<1, 1-4, 5-14, 15-29, 30-49, 50-69, 70+` (7단)

**지역 7종 × 연령 7단** → 원인별 가중치표
```
고소득(hi) band 6(50-69):
  암 42, 허혈성심질환 16, 뇌졸중 5, COPD 5 ...

사하라이남(ssa) band 1(1-4):
  말라리아 25, 폐렴 18, 설사 14, 감염 14 ...
```

**국가 지표 보정**
```
HIV: × (국가hiv / 지역기준)^0.8
살인: × (hom / 기준)^0.85
교통: × road/기준
전쟁: + war × (남15-49세 8, 여3, 나머지 2)
약물: × OD[국가]/2
```

**개인 위험(personal)**
- 흡연: 암+80%, COPD+200%, 심질환·뇌졸중+40%
- 직업 위험 JOBS.risk (어부 익사×3, 광부 사고×3, 건설 낙상×3, 군인 전쟁×3)
- 빈곤(15세미만): 영양·설사·폐렴·말라리아·결핵에 e^(-c(q-3))

## 2.3 4개 스탯과 초점

### 스탯 정의

| 키 | 이름 | 범위 | 특징 |
|---|---|---|---|
| `hl` | 건강 | 0~100 | 연령별 기대치 추종, 사망 배수에 영향 |
| `h` | 행복 | 0~100 | 국가·소득·관계·건강 기반 |
| `sm` | 지식 | 0.5~99.9 | **또래 백분위** `100·Φ(z)` |
| `so` | 관계 | 0~100 | 혼인·자녀·부모·취미 기반 |

### 올해의 초점 (FOCUS) — 연간 1개 선택, 체류시간 비례

| 초점 | 건강 | 행복 | 지식 | 관계 | 소득 |
|---|---|---|---|---|---|
| 공부 | — | -1 | +5 | -1 | — |
| 놀이 | — | +4 | — | +4 | — |
| 집안일 | — | — | -1 | +2 | — |
| 운동 | +4 | +2 | — | +1 | — |
| 취미 | — | +4 | — | — | — (대표취미 레벨+1.2) |
| 일 | -3 | -2 | — | -2 | +10% (승진+0.012) |
| 균형 | +1 | +1 | — | +1 | — |
| 가족 | — | +3 | — | +5 | — |
| 건강관리 | +5×fitK | +1 | — | — | -2% |
| 자기계발 | — | -1 | +4 | — | (승진+0.006, -2%) |
| 종교·봉사 | — | +3 | — | +4 | — |
| 휴식 | +2 | +2 | -1 | — | — |

### 목표값 추종 (연말, ak = clamp((age-14)/6, 0, 1))

**건강**
```
hTarget = expHealth(a+1) + 자전거·식단 보너스 + (q-3)×1.5
        - 흡연 6 - 만성질환수×5 - 난민 6 + 건강초점비율×6×fitK
hl ← hl + (hTarget - hl) × 0.25
```

**관계**
```
soTarget = 45 + 혼인 12 + min(15, 생존자녀×4) + 모친생존 3 - 이주 6
속도 = so > soTarget-8×ak 면 0.12+0.13×ak, 아니면 0.12
```

**행복**
```
happyBase = 28 + 5.5×WHR
relInc = 성인비학생면 (소득백분위-0.5)×18, 아니면 (q-3)×3
hpTarget = happyBase + relInc + 꿈직업 3 + 외식 1 + (so-50)×0.25 + (hl-기대)×0.2
속도 = h > hpTarget-12×ak 면 0.35, 아니면 0.20
```

**지식 (또래 백분위)**
```
z = talW(age)×재능st + kE
sm = 100·Φ(z)

talW(a) = 0.9 × clamp(0.35 + 0.055(a-3), 0.35, 1)
d = 0.075 × (Σ KNOW_EFF[초점]×비율 - 기준치)
kE ← kE × (25세미만 0.97, 나머지 0.985) + d, 범위 [-1.4, 1.6]
```

## 2.4 소득과 재정

### 소득 분포 (로그정규)
```
σ = √2 · Φ⁻¹((G+1)/2)     (G = 지니)
incomeAt(c, p) = 0.9·PPP × exp(σ·Φ⁻¹(p) - σ²/2)
pctOfIncome = 역함수
worldPct = 세계 누적 CDF
```

**중요**: 거의 모든 비용과 보상이 **중위소득 배수**로 정의됨

### 직업 정의
```
직업 = {
  필요학력 e (0~5),
  백분위 구간 [lo, hi],
  위험도 JOBS.risk,
  도시선호도 u
}
```

예: 개발자(e=4, lo=0.70, hi=0.97), 소농(e=0, lo=0.03, hi=0.32)

### 연봉 드리프트
```
room = clamp((hi + 0.04 - pct)/(hi - lo) × 1.2, 0, 1)
drift = 기경력+자격 + 일초점 0.012 + 자기계발 0.006 - 가족 0.003 + 지식도움
Δpct = drift + U(-0.01, 0.01)
```

## 2.5 결정 카드 엔진

### 구성

| 항목 | 규칙 |
|---|---|
| 연 한도 | 최대 2장 |
| 예약 | 필수 카드(조건 필터링) |
| 풀 | 남은 자리는 후보에서 무작위 1장 |
| 상한 | 최근 14개 ×0.08 가중치 제외 |
| 카드별 초점 | 고르면 그 초점으로 해당 연도 설정 |

### 카드 효과 타입
```
SAME_WAY: 선택지 없이 자동 적용
PLAIN: 기본값으로 쏠림(자동모드)
ONE_A_YEAR: 연 1회만
700ms 가드: 빠른 더블탭 방지
```

### 자동 결정 (autoChoice)
```
선택지 = 국가·형편별 현실 비율표 + 특수 규칙
예: 이혼 양육권, 유언, 노후 거처 지역별 가중치
```

## 2.6 동반자 사전 시뮬

### 동작
1. 플레이어 출생 시 같은 조건(1초 + 국가 가중 추첨)으로 4명 생성
2. 엔진을 헤드리스(HOOK 비활성화)로 끝까지 실행
3. 사망 시각과 나이 기록
4. 같은 나이에 사망한 동반자 알림 (endYear에서)

### 용도
- 비교 대상 (화면 우측 "같은 1초에 태어난 4명")
- 회고 시 비율 계산 ("이 나이에 살아있을 확률")
- 공유 문구 ("같은 1초에 태어난 5명은 각각 2, 45, 67, 72, 81세까지")

## 2.8 회고 (잠시 멈춤)

### 단계별 회고
- **5세**: 5세 전 생존 문구 + 현실 질문
- **15세**: 교육 진행률 + 질문
- **30세**: 경력·소득 거울 + 질문
- **50세**: 가족 상태 + 질문
- **70세**: 유산·기여 + 질문

### 구현
```
거울 통계 1줄 + 현실 질문 1개 + 200자 응답 입력
응답이 위기 문구면 calm 모드 활성화
응답은 추후 사망 기록에 "남긴 생각"으로 표시
```

## 2.9 재구현 체크리스트 (우선순위 높음)

| # | 시스템 | 난이도 | 비고 |
|---|---|---|---|

| 3 | 출생 추첨 | 중 | 세계 연감 레코드 필요 |
| 4 | 사인 가중표 | 중 | 판타지 원인으로 교체 |
| 5 | 4스탯 목표 추종 | 하~중 | 계수 그대로 재사용 |
| 6 | 결정 엔진 | 중 | SAME_WAY, PLAIN, ONE_A_YEAR 로직 |
| 7 | 자동 결정 | 중 | 국가/신분별 비율표 구성 |
