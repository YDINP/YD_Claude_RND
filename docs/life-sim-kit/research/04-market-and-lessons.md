```

**출생 복권 체감**
```
"태어난 곳 하나로 인생이 달라질 줄 몰랐다"

**통계의 실감**
```
"아동 사망률 3%가 내 아이의 위험처럼 느껴진다"

```

**진입 장벽 0**
```
가입 없음 + 버튼 1개 + 인앱 브라우저 지원
```

## 4.3 원작 성공 이유 5가지

### 1. 출생 복권을 숫자로 체감하게 함
**핵심**: 첫 문장 + 감속 룰렛 + "558명 중 1명꼴", "5세 전 떠날 확률 11.7%"

→ 서사보다 **숫자가 세게 와닿는다**
→ 모든 숫자에 출처 표기 + 사용자 통계("많이 모이면 실제를 닮아 가요")로 신뢰 증명

### 2. 비교의 거울이 세 겹
**거울 ①**: 내 실제 나라와 비교표
**거울 ②**: 같은 1초에 태어난 4명(사전 시뮬, 운명 정해짐)
**거울 ③**: 회고 질문이 "화면 속 인물"이 아니라 **플레이어 자신의 과거**를 묻는다

→ 남의 삶을 보다가 자기 삶을 돌아보게 됨

### 3. 죽음을 의식으로 치름
**구조**: 주마등 → 장례 → 비문 → "단 한 번뿐인 삶이었습니다" → 남기는 말 → 촛불

→ 점수·팝업 없고 **공문서 미학**(신고서·여권 MRZ·사망 기록)
→ 게임이 아니라 **한 사람의 삶**으로 받아들여짐
→ 애도가 감정을 정리해 주고, 추모관·재방문으로 이어짐

### 4. 진입 장벽 0 + 질문으로 끝나는 공유
**구조**: 가입 없음 → 버튼 1개 → 인앱에서도 실행
→ 결과 카드는 **인증 놀이 연료**(어디서, 몇 살에, 무엇으로)
→ **"너는 누구로 태어날까?"로 끝남** → 받은 사람 자연스럽게 시작

→ URL 인코딩 공유(서버 저장 0)

### 5. 무거움을 안전하게 다루고 투명성 보임
**장치**: "통계 빈도로만, 장면 없이, 도움 창구와 함께"

→ calm 모드(30일 자살 미발생), 자유 댓글 없는 추모관(정해진 한마디 6종)
→ 18세 미만·자살 사망에는 판매 권유 안 함
→ "1인이 AI로 4시간" + 하루 수십 패치 = 신뢰와 화제

## 4.5 판타지 장르의 빈틈 (기회)

### 1. "통계 기반 판타지"가 비어 있다
```
BitLife 판타지 팩: 얕음
Life in Adventure: 모험 로그라이크(인생 전체 아님)

→ 빈자리: 세계관 내 "가짜 통계"를 현실처럼 엄격하게 짜서
   종족별 기대수명, 왕국별 영아사망률, 문해율 등을 굴리는
   웹 인생 시뮬

→ 진정성의 원천: "UN 데이터" → "세계 연감(年鑑)"으로 전환
```

### 2. 종족 = 국가의 판타지 치환
```
출생 복권의 낙차가 현실판보다 더 극적

인간 70세 vs 엘프 700세 vs 오크 40세 vs 드워프 250세
→ "어디에 어떤 종족으로" 태어나느냐가 운명을 극적으로 갈림
```

### 3. 무거운 주제를 우회하는 안전판
```
현실판: 자살·아동사망 논란
판타지판: 역병, 마물, 전쟁, 저주, 마나고갈 = 은유적 같은 무게

→ 실존 국가·현실 통계의 정치·윤리 리스크 회피
→ "그 나라에 태어나면 불행" 논란 없음
```

### 4. 반복 동기의 공백
```
현실판: 점수 없음 → 다시 할 이유 = '다른 출생'뿐

판타지판: 윤회·환생 서사 자연스럽게 정당화
① 전생 기록 10개 → 천부 1개 계승 (人生重开式)
② 내 전생들이 같은 세계 역사책에 기록 (Wildermyth Legacy식)

→ 반복 플레이가 "세계 구축"이 됨
```

### 5. 추모관 → 영웅 전당·묘비 마을
```
다른 플레이어의 삶이 세계 안의:
- 비석, 전설, 노래로 남음
- 다음 판의 이벤트로 재등장

→ 현실판에는 불가능한 **비동기 MMO 감각**
```

### 6. 동아시아 수요 (검증된 시장)
```
중국: 수선 인생 시뮬(人生重开), 鬼谷八荒 (수선 모드)
일본: 이세계 전생 장르

→ 판타지 환생 인생 시뮬에 대한 수요 **이미 검증됨**
→ 원작이 일본에서 두 번째 물결을 일으킨 곳
→ **일본어 대응이 1순위**
```

### 7. 포맷 범용화에 대한 방어
```
현실판 클론: 1주일 만에 3개 이상

복제하기 어려운 해자:
- 세계관과 고유명사
- 연감 데이터(종족별 수명, 왕국별 통계)
- 아트(픽셀 씬, 공유 카드 디자인)
```

## 4.6 바이럴 포인트 설계 (원작에서 검증된 것 → 판타지 치환)

| 원작에서 검증 | 왜 먹혔나 | 판타지판 |
|---|---|---|
| "○○에서 태어났다, 확률 1/556" | 복권 결과는 즉시 자랑·한탄 거리 | **"엘프로 태어날 확률 1/312 — 은빛 숲 하이엘프 왕가"** |
| | | 희귀 출생 등급(용혈·성흔) 표시 |
| "○세, 사인" | 짧은 비극 + 긴 해피엔딩 대비 | **묘비 카드**: "드워프 대장장이, 211세, 용의 불길에 스러지다" |
| 같은 1초에 태어난 4명 | 비교가 복권을 드러냄 | **"같은 별자리 아래 태어난 4명"** (인간·엘프·오크·하플링, 신분 다양) |
| 해시태그 인증 | 일본 X에서 두 번째 물결 | 공유 텍스트에 기본 해시태그 삽입, **일본어판 동시 출시** |
| "AI로 4시간" 메타서사 | 개발 과정 자체가 콘텐츠 | 제작 로그·패치 노트 공개 → '매일 고치는 1인' 서사 계속 |
| 무가입·버튼 1개 | 인앱에서도 1초 시작 | 유지, 단 인앱 저장 막힘 → 공유 카드 이미지 생성으로 우회 |
| 사용자가 각자 다른 교훈 | 학력/주식/무지의베일 | **"어떤 종족·직업이 오래 살까"** 메타 토론 유도 → 연감 페이지 SEO |

## 4.7 가져갈 것 (그대로) vs 바꿀 것 vs 버릴 것

```
✓ 엔진 골격: 정규화 연시간, 예약 큐, 결정 시 정지, 연 피드 2~3개

✓ 결정 엔진 장치(SAME_WAY, PLAIN, 700ms 가드, 자동결정)
✓ 최근 사용 패널티 ×0.08, 반복 피로 방지 장치
✓ 같은 순간 4명, 공문서 미학, 담담한 3인칭 톤
✓ 마지막 연출(주마등·비문), 위기 안전장치
✓ 로컬 퍼스트, 임의 열쇠 소유 증명, 비콘 응답 = 실시간
✓ 결과 비변경 기념품 과금, 30일 환불
✓ 절차 생성 음악, 공유 카드 1080×1350

## 4.8 신규 컨셉 선택 시 판단 기준 (일반화)

### 가져갈 것
```
1. 엔진 골격과 루프의 타이밍
   → 음악·페이싱·심리 만족도가 검증됨

2. 4스탯 + 초점 시스템
   → 수치가 검증됨, 초점명만 바꾸면 됨

3. 공문서 미학과 담담한 톤
   → 감정을 정리하는 장치(비문, 공유카드)

4. 로컬 퍼스트·계정 없음
   → 진입 장벽 0 + 개인정보 리스크 회피

5. 안전장치(calm, 정해진 한마디, 도움 창구)
   → 무거운 주제를 존중하는 신호
```

### 바꿀 것
```
1. 세계관·통계 기반
   → 진정성의 원천을 현실에서 세계관으로 전환
   → "가짜 통계를 현실처럼 엄격하게"

2. 반복 동기
   → 원작: "다른 출생"만
   → 신규: 윤회·천부·세계 누적 등 서사 추가

3. 포맷 차별화
   → 클론 방어: 세계관·아트·연감 데이터
```

### 버릴 것
```
1. 현실 정치·윤리 리스크
   → 판타지 은유로 같은 주제를 "안전하게"

2. 현실 제도·통계의 세부
   → 분량만 크고 판타지에 맞지 않음

3. "이 게임은 교육용이다"는 주장
   → 그냥 "좋은 게임"이 되는 게 낫다
```

## 4.9 판타지판 차별화 축

### 1순위: 세계관과 연감
```
현실판 포맷은 1주일 만에 범용재가 됐다.
→ 해자는 **세계관·고유명사·연감 데이터·아트**

예: "엘프는 700년을 사는데, 영아사망은 0.8%"
   (기대수명에 맞춰 생명표 재구성, 자동으로 모든 내용이 일관성 있게 따라옴)
```

### 2순위: 종족 수명 낙차 (극적 출생 복권)
```
현실판: 최대 기대수명 차 = 약 20세 (일본 85 vs 시에라레온 54)
판타지판: 수명 차 = 660세 (엘프 700 vs 오크 40)

→ "어느 종족으로 태어나는가"가 현실판보다 훨씬 극적
```

### 3순위: 동아시아 시장 우선 (검증된 수요)
```
이미 검증된 것:
- 중국의 인생 리셋/수선 인생 시뮬 (인기 높음)
- 일본의 이세계 전생 장르 (문화 코드)
- 원작의 두 번째 물결 = 일본

→ 일본어판 동시 출시 필수
```
