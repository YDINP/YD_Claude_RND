## 1.3 연 루프 (1년 = 클램프된 초 단위)

### 1년의 길이
```
yearSec = clamp(pace분 × 60 / max(e0, 60), 12, 120) 초
```
- `pace`: 기대수명까지 사는 데 걸리는 시간(30/60/90분, 기본 60)
- `e0`: 기대수명
- 예: e0=80, pace=60분 → 연 45초

### 배속과 빨리감기
- 배속: 1×, 2×, 4×, 8×, 12×, 16×
- "다음 결정까지" ff: 24배 (자녀 사망/실직 시 자동 중단)
- dt 상한: 0.25초

### 연도 계획 `planYear`
1. 초점 설정 (생애 단계별)
2. 이벤트 2~3개 생성 (6세 미만은 2개, 이상은 3개)
   - 발생 시각: 0.08~0.94 구간에 고르게 분산
3. 결정 카드 최대 2장 (시각: 0.3, 0.6 근처 + 오프셋)
4. 마일스톤 로그 (t=0.03, 나이: 1/5/15/30/50/65/80/90/100)

### 연말 처리 `endYear`
1. 초점 체류 시간 비율 적용
2. 취미 레벨 상승
3. 지식·학교·재정 업데이트
4. 건강/관계/행복 목표값 추종
5. 가족 시스템 (부모·배우자·자녀·조부모 노화·사망)
6. 약 50개 하위 시스템 (반려동물, 기질, 장애, 범죄, 전쟁 등)
7. 동반자 4명 중 같은 나이 사망자 알림
8. **사망 판정**: `P = 1 - (1-q)^clamp(m, 0.25, 9)`
9. age++, 122세 도달 시 강제 사망
10. planYear로 돌아감

## 1.5 기술 구조

### 빌드
- **언어별 단일 HTML** (ko 3.0MB, en 4.4MB)
- CSS·로직·데이터 모두 인라인
- 보조 JS: 내용 해시 파일명 (`labw.ko.<hash>.js`, `keepx.<hash>.js`)
- **프레임워크 없음**: 바닐라 JS + 문자열 템플릿 `innerHTML`

### 엔진/UI 분리 (HOOK 패턴)

- **훅** 9개: log, change, decision, death, year, err, noPause, humRecent, calm

### RNG
- 기본: `Math.random`
- 교실 코드: 문자열 해시 → mulberry32 시드 RNG
- 개인당 결정별 하위 스트림 가능

- **한국어 원문이 키** (태그드 템플릿 `` L`…${x}…` ``)

- 5개 언어: ko, en, ja, zh(번체), vi

### 인프라 (추정)

### 로그인 없음, 즉 익명

### 소셜 기능 3가지

**① 함께 나눈 삶** (커뮤니티 글)
- 자유 글 300자, 기억해요·신고(무장 2탭 확정)
- 필터: link/personal/abuse/crisis/spam + 위기 정규식
- 위기 문구 감지 시 calm 모드 30일 활성화

**② 추모관** (유료, 1회 결제당 하루 20곳)
- 촛불(기기당 1회), **정해진 한마디 6종**(인덱스만 전송)
- 추모관별 `dk` 소유 증명 (24hex)
- 공개 URL: `/{lang}/m/{id}` (9자 [a-z2-9])

**③ 전생의 집** (추모관 묶음 공개 페이지)
- 집 = 이용권당 1개, 방 = 모신 추모관별
- 꾸밈: 벽지 11종, 바닥 6종, 창밖 9종, 옷 8종, 음악 6종

### 추가 API
- **실시간 현황**: `/api/e` (비콘) → 지금 사는 사람, 최근 사건
- **오늘의 주제**: 집계된 주제(역병의 달, 용의 계절 등)
- **실시간 지도**: 지금 사는 나라를 점으로 (약 30fps)

## 1.9 성공 요인 5가지

1. **출생 복권을 숫자로 체감** — 감속 룰렛, "558명 중 1명꼴", 실제 숫자의 충격
2. **비교의 거울 3겹** — 실제 나라 비교표, 같은 1초 출생자 4명, 현실 자신의 삶을 묻는 회고
3. **죽음을 의식으로 치름** — 주마등→장례→비문 연출, 공문서 미학, 추모관
4. **진입 장벽 0 + 바이럴** — 가입 없음, "너는 누구로 태어날까?" 문구로 끝나는 공유 카드
5. **무거움을 안전하게 + 투명성** — calm 모드, 정해진 한마디(자유 댓글 없음), "AI로 4시간" 메타 서사
