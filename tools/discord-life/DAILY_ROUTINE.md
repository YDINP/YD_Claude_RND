# 매일 아침 생활 채널 루틴 (세션 cron 이 이 파일을 읽고 그대로 실행)

목표: **10:00 전후** 페이퍼닥 디스코드 `#핫딜`·`#유용정보`에 검수 끝난 글을 올린다.
검수에서 확신이 없는 항목은 **올리지 않고 빼는 쪽**으로 한다. 막히면 올리지 말고 사용자에게 보고.
작업 폴더: `D:/park/YD_Claude_RND` · 날짜는 KST 기준 오늘(YYYYMMDD).

## 1. 핫딜 수집 → `reports/핫딜_TOP50_<오늘>.md`
- 어제 파일(`reports/핫딜_TOP50_<어제>.md`)과 **같은 형식·같은 방법**(WebFetch, 로그인·캡차 없음)으로 최근 24시간 글을 모은다.
  사이트: 펨코 hotdeal · 루리웹 1020 · 퀘이사존 qb_saleinfo · 딜바다 · 뽐뿌 · 클리앙 알뜰구매 (막힌 곳은 "접근 결과" 표에 기록하고 넘어감)
- 종료 표시 글 제외, 같은 상품은 한 줄로 합치고 출처를 메모에 병기, 추천 많은 순.
- 어제와 겹치는 글은 추천이 늘어난 경우만.

## 2. 핫딜 검수 (상위 30개 기준, 걸리면 빼고 31위부터 채움)
1. `node tools/discord-life/check.mjs hotdeal` — 링크·중복·가격·부적절 키워드·종료 표시 자동 확인
2. 「봇 차단으로 자동 확인 못 함」 항목은 **WebFetch 로 원글을 직접 열어** 종료·품절·가격 변동 확인
3. 눈 검수: 성인·도박·코인·대출·리딩방, 사기 의심(지나친 할인·개인 판매·외부 결제 유도), 가격 오기(단위·$/원), 리셀가는 메모로 표시
4. 고친 내용은 리포트 맨 위 "검수" 줄에 한 줄로 기록

## 3. 핫딜 게시
- 디스코드: `node tools/discord-life/post-hotdeal.mjs` (채널엔 제목 카드, 스레드에 분류별 30개)
- 텔레그램 b_s 봇: TOP50 리포트를 이전처럼 `cd ben_suno && node scripts/tg.mjs --file ../reports/핫딜_TOP50_<오늘>.md --send "<M/D> 핫딜 TOP50"`

## 4. 유용정보 검수 → 게시
1. `node tools/discord-life/check.mjs info --n 5` — 빈 칸·마감 경과·지역 표현·출처 링크
2. 눈 검수: 다음 5개 각각 **WebSearch 로 최신 상황 재확인**(예산 소진·조기 마감·금액 변경). 바뀌었으면 `info.json` 고치고, 끝난 제도는 빼기
3. 지역 한정 혜택은 절대 올리지 않음. 개인정보·우리 동네 이야기 금지
4. 새로 쓰거나 고친 문장은 korean-spell-check 로 맞춤법 확인
5. `node tools/discord-life/post-info.mjs --n 5` → `node tools/discord-life/post-info.mjs --remind`
6. 남은 항목이 10개 미만이면: 지역 무관 공용 혜택·생활 정보를 새로 리서치해 5개를 `info.json` 끝에 추가 (공식·언론 출처 확인된 것만, 미확인 수치는 "안내 글 기준" 표기, big/due/hook 포함)

## 5. 마무리
- `git add tools/discord-life reports/핫딜_TOP50_<오늘>.md` → 커밋 `chore(tools): <M/D> 생활 채널 게시`
- 사용자에게 3줄 보고: 핫딜 몇 개(검수로 뺀 것), 유용정보 올린 제목, 이상 사항
- **cron 갱신**: CronList 에서 이 루틴 작업이 만든 지 6일 이상이면, 같은 프롬프트·같은 시각으로 CronCreate 새로 만들고 예전 것은 CronDelete (세션 cron 은 7일 뒤 사라짐)

## 금지
- 토큰 출력·커밋, 비밀번호·캡차 입력, 로그인 필요한 사이트 진입
- 검수 안 된 항목 게시, 이미 올린 날짜 중복 게시 (스크립트가 막지만 확인)
