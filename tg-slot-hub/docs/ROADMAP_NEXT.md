## 2. 기존 슬롯 완성도

신작과 **병렬로** 돌릴 수 있는 것과, 신작 전에 끝내야 하는 것을 나눈다.

### 2-1. 사운드 2차 (신작 전 — 신작부터 게임별 소리를 갖고 나오게)
지금은 6종이 같은 합성음이다. 게임 이름만 바뀌고 소리가 같으면 카탈로그 다양성이 반감된다.

| 작업 | 내용 |
|---|---|
| 게임별 소리 세트 | `theme.json`에 `sound: { preset, ... }` 추가. 프리셋 5개: 벨(classic·royal) / 과일 팝(fruit) / 서부 기타·총성(sheriff) / 신사 종·나무 딱따기(shiba) / 시계 태엽·유리(astral). 합성 레시피 표를 프리셋별로 갈아 끼우는 구조 |
| 기대감 연출 | 스캐터 2개가 먼저 떨어지면 남은 릴을 늦추고 긴장음. **렌더러 + 사운드 같이** — 업계 표준인데 우리만 없다. 결과는 바뀌지 않고 연출 시간만 늘어남 |
| 롤업 틱 | 당첨 금액이 올라가는 동안 짧은 틱, 끝날 때 마감음 |
| 버튼음 | 베팅 ±, 오토스핀, 시트 열기 |
| 음량 | 설정에 효과음 음량 슬라이더(현재 켜기/끄기만) |
| 배경음 | 게임별 짧은 루프. **기본 끔**, 설정에서 켬. 음원은 Suno 등으로 별도 발주 |
| 귀 판정 | 프리셋마다 사용자 확인 1회 |

### 2-2. 연출·아트 빈칸 (신작과 병렬)
- royal-diamond-777 프리스핀 배경 생성(나머지 4종과 맞춤)
- classic-777 스프라이트 시트 보강(다른 팩 3장 기준)
- 배경 cover 스케일, 프리스핀 카운터 가독성(웨이브 1 백로그)
- STOP 시 변형 압축 재생(2026-11-10 수정) — 디버그 프리셋으로 미스터리·랜덤 와일드를 강제해 눈으로 확인

### 2-3. 엔진 정합성 (신작 전 — #8이 와일드를 또 쓰므로)
- 와일드 전용 줄 접기를 릴별 와일드 칸 수 곱으로 정밀화 → **shiba-shrine 재튜닝 + 재감사**
- 와일드 1종 제한을 스키마에서 강제(또는 와일드별 챔피언 계산)

### 2-4. 품질·출시 준비 (계속 병렬, 배포 전 필수)
| 작업 | 이유 |

## 3. 실행 순서 (한눈에)

```
지금 ─┬─ W-A astral-clocktower 아트·감사·live              (반나절)
      ├─ 2-1 사운드 2차(게임별 세트·기대감·롤업·음량)        (1~2일)
      ├─ 2-3 엔진 와일드 정합성 + shiba 재튜닝               (1일)
      └─ 2-4 플레이키 2건 + 경로 이전                        (반나절)
          ↓ 위 넷 커밋
      W-B candy-cluster-pop (엔진 연쇄·클러스터 → 렌더러 → 허브 → 아트 → MC 감사)  (4일)
      ├─ 병렬: 2-2 연출·아트 빈칸
          ↓
      #7 olympus-nectar → #8 magi-stella
      실기기 검증·배포 준비는 W-B 끝난 시점에 한 번 (사용자 확인 후)
```

**진행 방식**: 웨이브마다 팀장(opus) + 파트별 레인(엔진/렌더러/허브/아트, sonnet·haiku). 파일 소유를 나눠 병렬, 파트별 리뷰어 검수 → 통합 검증(테스트·빌드·브라우저·RTP 감사) → `QA_LOG.md` 기록 → 페이즈마다 커밋. QA는 기능별 1회 확인표로 한다(시간 진행 QA 없음).
