## 2. 결정과 이유

1. **프리스핀 스트립.** 정지 위치가 `freeStrips` 기준이라 허브가 `spinTo(…, { frost: { freeSpin } })`을 넘기고, 렌더러가 스핀을 시작할 때 읽는 스트립을 사본(스트립만 교체, 한 번만 만든다)으로 갈아 끼운다. 엔진 `frostSpinMath`는 런타임 의존이 금지라(순수성 테스트) 같은 규칙을 렌더러에 둔다.
2. **마름모.** 릴마다 가운데 정렬 오프셋(`(rows − h) / 2` 칸)을 주고, 마스크를 릴별 창으로 바꾼다. 판 밖은 `__void__`라 그리지 않고, 변형 층에 앉히지도 않는다(앉히면 다음 스핀에서 창 안으로 흘러 든다). 판 밖 모서리는 빈칸이 아니라 서리 막(결정 가지)으로 덮는다.
3. **정지 순서.** 가운데 → 안쪽 둘 → 바깥 둘, 간격은 기존 ×1.3(꽝 판 총 길이 ≤ 기존 5릴). 터보·모션 축소는 한 번에. 기대감은 «앞 묶음에 구슬 trigger−1개, 구슬이 들 수 있는 릴»일 때만(결과와 무관).
4. **재생 순서.** 착지 → 평소 당첨(brief) → 얼림 → (큰 결과면) 빅윈 한 번. 얼음 보너스는 지갑에서 «재생이 끝날 때까지» 덜어 두고(말판과 같은 보류 장치), 끝나면 돌려준다. 빅윈 판정은 얼음 보너스까지 합친 뒤다.
5. **칸 회전.** 얼지 않은 칸의 심볼이 70ms마다 바뀌며 떨리고 차례로 서며 살짝 부푼다(칸 스프라이트 그대로, 스프라이트 추가 없음). 얼지 않은 칸은 밝기 60%로 눌러 둔다(다시 뽑힌 칸이 다른 줄을 만들어도 당첨처럼 안 읽히게).
6. **STOP/SPIN 버튼.** 얼림 도중에는 «다음 스핀»이 아니라 «남은 단계 압축»이다(단계당 90~220ms, 칸 회전 없이 착지만). 두 번째 눌림은 무시한다. 끝 화면은 최종값을 바로 보여 준다.
7. **모션 축소.** 움직임(회전·파편·오로라·궁전 번쩍임·녹는 효과)은 없고, 단계마다 짧게 머물러 읽을 수 있다.
8. **오로라 단계 표시.** 서버가 이월한 `carry.frost.level`을 새로고침 복원에 쓰고, 재생 중에는 `frostEnd` 시점에 `auroraAfter`로 올린다(누설 방지: 얼림이 끝나기 전에는 안 오른다).
9. **용어(쉬운 말).** 얼려 두기 프리스핀 · 얼음 보너스 · 오로라 · 궁전 완성 · 판과 지급. «0칸 → N칸», 곱셈식은 `×11 × 오로라 ×2 = 22배`(칸 수는 왼쪽에 이미 크게 있어 곱셈식에서 뺐다).

## 3. 시간 예산 (normal)

- 17단계 합 6.39s(게이트 ≤ 6.5s, 테스트가 고정). 1~4단계 640ms, 5단계부터 ×0.85씩, 하한 기본의 0.35배(224ms).
- 대상 빛남 120 · 정적 160 · 얼음 240ms. 끝: 곱셈식 900ms(보너스 0/1배 미만은 300ms), 오로라 700, 궁전 +900, 녹음 350.
- 실측(헤드리스, 390×844): 평균 얼림 약 4~5초, STOP 시 남은 단계 약 2초 안에 끝남.

## 5. 남은 것 / 병합 메모

- 아트 레인의 프레임(1024×1536, 정사각 창)이 들어오면 셀 크기를 한 번 더 잴 것(현재는 벡터 프레임 기준 실측).
- 사운드(`frost` 프리셋·얼림 효과음)는 사운드 레인 몫이다. 화면 쪽은 이벤트(`frostStart/Step/End`)만 낸다 — 단계마다 `land`가 «쩡», 눈금 통과는 `crossed`, 끝은 `frostEnd start`.
- 로비 카드 문구(«얼려 두기 프리스핀 · 가운데부터 720길»)는 `GameSummary`에 피처 목록이 없어 넣지 못했다(공용 스키마 변경이 필요해 코어/병합 때 결정).
- 병합 시 공용 파일 충돌 지점: `pixiRenderer.ts`(분기들), `types.ts`(이벤트·옵션 끝), `GameScreen.tsx`(마운트·이벤트·도움말 분기), `store/game.ts`(얼림 재생 블록), `i18n/*.ts`(끝에 `aurora*` 키).
