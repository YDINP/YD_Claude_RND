## 1. 허브 컨셉

**세련된 모던 카지노 라운지.** 번쩍이는 네온이나 만화적인 과장 대신, 깊은 네이비 바탕에 브라스(황동) 금속 질감과
유리 하이라이트로 고급 멤버스 라운지의 절제된 분위기를 낸다. 서로 다른 게임(클래식 777, 프루트 피에스타 등)이
허브 안에서 나란히 놓여도 하나의 브랜드로 읽히도록, 모든 심볼은 동일한 3/4 탑뷰 카메라 각도·글로시 토이 렌더링·
스튜디오 조명 세팅을 공유한다. 모바일 퍼스트이므로 심볼은 실제 릴 렌더 크기인 **64px에서도 실루엣이 구분**되어야
하고, 이는 심볼마다 형태를 확실히 다르게(원형/막대형/별형/텍스트형) 만드는 것으로 확보한다.

## 3. 에셋 스펙 표

| 종류 | 생성 크기 (gpt-image-1) | 후처리 | 최종 산출 | 용도 |
|---|---|---|---|---|
| 심볼(symbol) | 1024×1024 | 크로마키 제거 → 트림(bbox) → 리사이즈 | `512×512` webp (렌더러) + `128×128` webp (썸네일/페이테이블 UI) | 릴 위 심볼 스프라이트 |
| 릴 프레임(frame) | 1024×1536 | 릴 창 영역만 크로마키 제거(알파) → 리사이즈 | `1080×1350` webp (portrait) | 릴을 감싸는 브라스 베젤, 창 안쪽은 투명 |
| 배경(bg) | 1024×1536 | 리사이즈(크로마키 없음) | `1080×1920` webp (portrait) | 게임 화면 최하단 배경 |
| 로비 썸네일(thumb) | 1536×1024 | 리사이즈(크로마키 없음) | `640×400` webp | 로비 카드 목록 이미지 |

### 파일 명명 규칙
```
games/<id>/theme/symbols/<symbolId>.webp   # 512px, 렌더러가 실제 로드
games/<id>/theme/symbols/<symbolId>@thumb.webp  # 128px, 선택. 없으면 512본을 축소 사용
games/<id>/theme/frame.webp
games/<id>/theme/bg.webp
games/<id>/thumb.webp
```
`<symbolId>`는 반드시 `math.json`의 `symbols[].id`와 정확히 일치해야 한다 (예: `wild`, `seven`, `bar3`, `bar2`,
`bar1`, `bell`, `cherry`, `blank`). 렌더러가 이 id로 파일을 찾기 때문에 하나라도 어긋나면 심볼이 깨진다.

## 4. classic-777 컨셉 시트

**컨셉명: Brass Lounge 777 (브라스 라운지 777)**

선정 이유: 허브 톤이 "번쩍이지 않는 모던 카지노 라운지"로 이미 정해져 있다 (네이비 셸 + 브라스 포인트).
클래식 777은 허브의 1호 게임이자 가장 보수적인 3×3 5라인 구성이므로, 레트로 다이너(Neon Diner)나
라스베가스 네온 같은 시끄러운 컨셉 대신 **"고급 라운지의 빈티지 슬롯 머신"** 이미지를 잡는다. 어두운 네이비
공간에 브라스 금속과 벨벳 질감의 조명이 떨어지는 느낌으로, 허브 셸과 게임 화면 사이에 시각적 단절이 없다.

무드: 차분하고 고급스럽지만 심볼 자체는 클래식 슬롯의 원색(빨강 세븐, 초록 체리 잎)을 살려 게임성이 죽지
않게 한다. "라운지"는 배경/프레임의 무드이고, 심볼은 여전히 선명한 캐주얼 게임 색이다.

## 5. 릴 프레임 기획

브라스 베젤 프레임 1장이 릴 캔버스를 감싼다. 캔버스 1080×1350 (portrait) 기준 레이아웃:

```
y   0% ─┬─────────────────────────────┐
        │   상단 마퀴 (게임명 플레이트)   │  0% – 18%
y  18% ─┼─────────────────────────────┤
        │  브라스 베젤 사이드 필러       │
        │  ┌─────────────────────┐    │
        │  │                     │    │  릴 창(window)
        │  │   3×3 릴 창 영역      │    │  x  8% – 92%
y  22% ─┼──│  (#00FF00 채움)      │──┤  y 22% – 68%
        │  │                     │    │
y  68% ─┼──└─────────────────────┘──┤
        │  브라스 디바이더 스트립       │  68% – 74%
y  74% ─┼─────────────────────────────┤
        │  페이라인 레전드 스트립        │  74% – 92%
y  92% ─┼─────────────────────────────┤
        │  하단 브라스 받침대(그림자)     │  92% – 100%
y 100% ─┴─────────────────────────────┘
        x 0%                        100%
```

- **상단 마퀴 (0–18%)**: 어두운 네이비 플레이트에 브라스 스크롤워크 테두리, `CLASSIC 777` 워드마크를
  브라스 세리프 각인으로 새김. 게임마다 프레임을 따로 생성하므로 게임명을 직접 구워 넣는다.
- **릴 창 (x 8–92%, y 22–68%)**: 실제 게임 심볼은 PixiJS가 이 영역 위에 별도로 그린다. 프레임 아트에서는
  이 사각형을 평평한 `#00FF00`으로 채워 생성하고, 후처리에서 알파로 뚫어(키잉) 아래 레이어(릴 캔버스)가
  비쳐 보이게 한다. 창 안쪽 가장자리에 살짝 안으로 파인 느낌의 브라스 이너 베젤 하이라이트만 남긴다.
- **디바이더 (68–74%)**: 가느다란 브라스 스트립 하나로 창과 레전드를 분리.
- **페이라인 레전드 (74–92%)**: 브라스 스트립 위에 5개 페이라인 모양을 작은 라인 아이콘으로 음각 표현
  (가로줄 3개 + 대각선 2개) — `math.json`의 `paylines`와 시각적으로 대응.
- **하단 받침대 (92–100%)**: 무게감을 주는 짙은 그림자와 브라스 받침 몰딩.
- 좌우 사이드 필러(약 0–8%, 92–100% x축)는 상단부터 하단까지 이어지는 브라스 스크롤워크 기둥.

## 6. 생성 파이프라인

### 프로바이더
| 프로바이더 | 용도 | 알파 지원 |
|---|---|---|
| OpenAI `gpt-image-1` | 1차. `size` 파라미터가 1024×1024 / 1024×1536 / 1536×1024만 허용 | `background: transparent` 네이티브 지원 (심볼에 한해 크로마키 대신 사용 가능) |
| Google Gemini 이미지 모델 | 2차 (비용/쿼터 대체) | 알파 미지원 → 항상 불투명 반환 |
| 로컬 ComfyUI (기존 세팅 재활용) | 오프라인 폴백 | 워크플로우 의존, 기본은 불투명 |

**결정: 프롬프트 자체는 항상 `#00FF00` 크로마키 배경을 명시한다.** 이유는 세 프로바이더 중 Gemini와
ComfyUI가 알파를 못 뱉기 때문에, 프롬프트 레벨에서 프로바이더에 관계없이 동일하게 동작하는 방식(크로마키)을
기본값으로 고정한다. `gpt-image-1`을 쓸 때는 `theme-gen`이 `background: "transparent"` 파라미터를 추가로
얹어 크로마키 없이 바로 알파를 받을 수 있지만(선택적 최적화), 프롬프트 텍스트 자체를 바꾸지 않아도 되도록
설계한다 — 즉 크로마키 지시문은 "이 배경을 나중에 제거할 것"이라는 의도 표시이지, 실제 매 프로바이더에서
그린 배경이 그대로 남는다는 뜻은 아니다.

**키잉 절차 (`tools/theme-gen`, `sharp` 사용):**
1. `#00FF00` 근접 색상(허용 오차 포함)을 알파 0으로 치환
2. 디스필(despill): 남은 초록 색 번짐을 인접 픽셀의 보색으로 감쇠시켜 가장자리 초록 테두리 제거
3. 알파 채널 기준 바운딩 박스로 트림 (심볼 에셋만 해당 — 프레임은 창 영역만 부분 키잉이므로 트림하지 않음)
4. 목표 해상도로 리사이즈 후 `webp` 인코딩 (심볼 512/128, 프레임 1080폭, 배경 1080폭, 썸네일 640폭)

### 일관성 확보 전략
- 모든 프롬프트가 동일한 `stylePrefix` 문자열로 시작 (스타일 고정)
- 신규 게임 착수 시, 개별 심볼 프롬프트를 낱개로 생성하기 전에 **심볼 전체를 하나의 그리드 이미지로
  먼저 생성**해 조명 방향·재질·팔레트가 스타일 락(lock) 되었는지 눈으로 먼저 확인한 뒤 개별 심볼로 넘어간다
- `negative` 프롬프트도 전 에셋 공유 (금지 요소 목록, `prompts.json`의 `negative` 필드)

### QA 체크리스트
- [ ] 64px로 축소했을 때도 심볼 실루엣이 서로 구분되는가 (형태 기반, 색만으로 구분되면 안 됨)
- [ ] 심볼마다 실루엣이 명확히 다른가 (원형 vs 막대형 vs 별형 vs 숫자형)
- [ ] 의도하지 않은 텍스트/글리프 드리프트가 없는가
- [ ] 전 심볼의 조명 방향이 동일한가 (좌상단 하이라이트로 통일)
- [ ] 크로마키 제거 후 가장자리에 초록 번짐(디스필 실패)이 남지 않았는가
- [ ] 프레임의 릴 창이 정확히 8–92% / 22–68% 영역에 위치하는가 (렌더러 오버레이 좌표와 어긋나면 심볼이
      베젤에 가려지거나 창 밖으로 삐져나옴)

## 8. fruit-fiesta 컨셉 시트 (허브 2호 게임)

**컨셉명: Brass Lounge: Fruit Fiesta (브라스 라운지: 프루트 피에스타)**

5릴 3행 20라인 + 프리스핀. `stylePrefix`와 `negative`는 classic-777과 **완전히 동일한 문자열**을 재사용해
"같은 라운지 안의 다른 캐비닛"이라는 패밀리 정체성을 지킨다. 다른 점은 팔레트 포인트와 무드뿐이다:
브라스 바탕에 초록·주황 에나멜 인레이 포인트를 더해 축제(fiesta) 느낌을 내고, 프레임/배경은 어두운 실내
대신 **황혼의 라운지 테라스**로 옮겨 파티 분위기를 준다. 심볼은 캔디글라스(candy-glass) 질감의 과일로,
클래식 777의 유리 재질 언어를 과일에 적용한 확장판이다.

`seven`과 `bell`은 두 게임에 공통으로 존재하는 심볼 id이므로, **동일한 조형 언어(크롬 레드 세븐, 브라스
벨)를 재사용**해 허브 전역에서 같은 심볼이 같은 룩으로 읽히게 했다 — 유저가 게임을 옮겨도 세븐/벨을
즉시 알아보게 하려는 의도.

### 심볼별 색 포인트 (티어)

| 심볼 id | 티어 컬러 | 설명 |
|---|---|---|
| `wild` | 브라스 플레이트 + 레드 젬 | `WILD` 각인 브라스 명판 위에 큼직한 레드 페이싯 젬 |
| `scatter` | 골드 스타 + 텍스트 리본 | 골드 별 배지 + `FREE SPINS` 리본. **허브에서 유일하게 심볼 자체에 문구가 들어가는 예외** (프리스핀 트리거를 즉시 알아보게 하기 위함) |
| `seven` | 레드/골드 히어로 | classic-777과 동일 조형 (허브 전역 일관성) |
| `bell` | 골드 | classic-777과 동일 조형 (허브 전역 일관성) |
| `watermelon` | 핑크레드/그린 캔디글라스 | 최고 배당급 과일로 예상, 가장 화려한 단면 표현 |
| `grape` | 바이올렛 캔디글라스 | 알알이 하이라이트가 도는 클러스터 |
| `plum` | 딥퍼플레드 캔디글라스 | 은은한 블룸(bloom) 하이라이트 |
| `orange` | 오렌지 캔디글라스 | 은은한 세그먼트 텍스처 |
| `lemon` | 옐로 캔디글라스 | 양끝이 뾰족한 실루엣으로 orange와 구분 |
| `cherry` | 레드 캔디글라스 | classic-777의 체리보다 재질만 캔디글라스로 통일, 형태는 동일 |

모든 과일 심볼은 공통으로 **얇은 브라스 줄기(stem)** 를 달아 "브라스 라운지" 패밀리 신호를 유지한다.

### 릴 프레임 — classic-777과의 차이

5릴이라 창이 훨씬 넓어야 한다. classic-777 프레임(§5)과 달리 다음이 다르다:

| 항목 | classic-777 | fruit-fiesta |
|---|---|---|
| 릴 창 좌표 | x 8–92%, y 22–68% | x 6–94%, y 20–72% (더 넓음) |
| 창 테두리 | 안쪽 브라스 베벨 하이라이트 있음 | **베벨/그라데이션 없음**, 플러시 플랫 브라스 라인만 |
| 마퀴 | y 0–18%, `CLASSIC 777` | y 0–16% (더 컴팩트), `FRUIT FIESTA` |
| 페이라인 레전드 | y 74–92%에 5라인 아이콘 스트립 | **없음** — 20라인은 아이콘으로 표기하기엔 너무 많아 생략, 하단은 순수 받침대 |
| 하단 받침대 | y 92–100% | y 72–100% (레전드가 없어 더 넓음) |
| 사이드 필러 장식 | 브라스 스크롤워크 | 브라스 스크롤워크 + 작은 초록 에나멜 리프 모티프 |

레전드를 생략한 이유: 20라인의 지그재그 페이라인은 작은 아이콘으로 압축하면 오히려 산만해진다.
라인 정보는 게임 화면의 별도 UI(페이테이블 팝업 등)로 옮기고, 프레임 아트는 단순하게 유지한다.

### 배경 — classic-777과의 차이

classic-777의 `bg`는 어두운 실내 라운지(벨벳 드레이프, 브라스 펜던트 조명)였다. fruit-fiesta는 같은
라운지가 **야외 테라스로 확장된 것**으로 설정해 시간대를 황혼으로 옮긴다: 페이퍼 랜턴 보케, 난간·화분
실루엣, 주황-보라 황혼 하늘이 네이비로 이어지는 그라데이션. 실내→야외 전환이 "허브 안의 다른 게임"이라는
느낌을 주되, 팔레트 앵커(§2)는 그대로 유지해 브랜드가 끊기지 않는다.

### 모션 노트 (렌더러 참고)

| 심볼 | 아이들 | 승리 시 |
|---|---|---|
| `wild` | 젬 은은한 펄스 글로우 | 강한 레드 젬 플래시 + 브라스 플레이트 쉬머 |
| `scatter` | 별 배지 살짝 반짝임 | 리본이 펄럭이는 듯한 확대 팝 + 골드 광선 확산 (프리스핀 진입 신호) |
| `seven`/`bell` | classic-777과 동일 | classic-777과 동일 |
| `watermelon`/`grape`/`plum`/`orange`/`lemon`/`cherry` | 정지 | 통통 튀는 스쿼시&스트레치 바운스 (체리와 동일 계열의 캐주얼 모션) |

## 9-11. 웨이브 1 신작 3종 — 멀티 스타일 패밀리로 전환

`docs/GAME_CATALOG.md`(2026-09-03, game-design-director)가 신작 10종을 6개 스타일 패밀리로 나눠 기획했다.
지금까지 이 문서는 "허브 = 브라스 라운지 단일 패밀리"를 전제했지만(§1–§8, classic-777/fruit-fiesta),
카탈로그 규모에서는 스타일 다양성 자체가 로비의 매력이 된다 — 게임을 열 때마다 완전히 다른 세계가
펼쳐지는 것이 "브라스 라운지 변주 10개"보다 소셜 카지노 로비로서 강하다. 그래서 웨이브 1부터 게임마다
**독자적인 `stylePrefix`**를 쓴다(브라스 라운지 문자열을 재사용하지 않는다). §2의 공통 규칙(격리·크로마
그린, 64px 판독성, 그림자 굽지 않기, 지시 없는 텍스트 금지, 프레이밍 10% 패딩)은 패밀리와 무관하게
전 게임에 그대로 적용된다 — 스타일이 갈라져도 "허브 하나"라는 신뢰는 이 공통 규칙이 만든다.

버티컬 프레임 좌표(§5 v2: 릴 창 x 4–96%, y 14–86%, 얇은 사이드 레일, 컴팩트 마퀴)도 전 게임 공통 SSOT다.
`prompts.json`의 `frame` 프롬프트가 정답이며, 아래 세 게임 모두 이 좌표를 그대로 따른다.

## 9. royal-diamond-777 컨셉 시트

**컨셉명: Royal Diamond Deco (로열 다이아몬드 데코)**

카탈로그는 이 게임을 "브라스 라운지의 정통 후속작"으로 부르지만, 로비에 브라스 라운지 변주가 두 개나
있으면(classic-777, fruit-fiesta) 셋째는 구별이 안 된다. 그래서 재질 언어를 한 단계 끌어올린다: 네이비
대신 **깊은 블랙 벨벳**, 브라스 대신 **광택 플래티넘**, 여기에 다이아몬드 시안과 벨벳 레드 두 보석
포인트를 얹은 아르데코 라운지로 분화시켰다. 조형 원칙(글로시 3D 토이 렌더, 히어로 심볼 위계)은
브라스 라운지와 동일하게 물려받아 "허브 가족"이라는 신호는 유지하면서, 재질만 한 단계 더 값비싸 보이게
만들어 "브라스 라운지의 프리미엄 룸"이라는 위치를 준다.

### 팔레트 앵커 (hex)

| 역할 | 값 |
|---|---|
| 블랙 벨벳(바탕) | `#0d0c14` |
| 플래티넘(메탈) | `#d7dbe0` |
| 다이아몬드 시안(젬) | `#8fe3f2` |
| 벨벳 레드(보석 포인트) | `#8f1f2e` |

### 심볼별 색 포인트 (10종)

| 심볼 id | 설명 |
|---|---|
| `wild` | 플래티넘 아르데코 선버스트 + 다이아몬드 시안 별 젬, `WILD` 각인 |
| `mystery` | 블랙 벨벳 타일 + 플래티넘 프레임, 물음표를 젬처럼 커팅 — **헤드라인 메커닉 심볼**(스핀 정지 후 화면의 물음표 타일 전부가 동시에 같은 심볼로 크로스페이드 리빌) |

| `seven` | 벨벳 레드 에나멜 숫자 7 + 플래티넘 테두리 (히어로 심볼, classic-777 세븐의 재질만 교체) |
| `diamond` | 다이아몬드 수트 실루엣의 대형 시안 젬스톤 |

| `cherry` | 벨벳 레드 체리 2알 + 플래티넘 줄기 + 시안 젬 잎 |

### 프레임/배경 — v2 버티컬 + 아르데코

릴 창 좌표는 공용 v2(x 4–96%, y 14–86%)를 그대로 쓴다. 차이는 장식 언어뿐이다: 사이드 레일이 스텝
쉐브론(계단형 아르데코 선) 안에 시안 젬 2–3개를 박은 형태, 마퀴는 블랙 벨벳 플레이트에 선버스트 테두리로
`ROYAL DIAMOND 777`을 새긴다. 배경은 블랙 벨벳 라운지 인테리어에 멀리 보이는 샹들리에를 암시하는 작은
시안 스파클 점들만 흐릿하게 배치 — brass-lounge의 펜던트 조명 보케를 시안 스파클로 치환한 것.

**bg-freeSpins 없음**: 카탈로그의 아트 수량(`심볼 10 + frame + bg + thumb = 13장`)에 프리스핀 전용 배경이
없다. UX 명세도 "리빌 순간 골드 광선 플래시 300ms"만 있고 배경 전환은 없다고 명시한다 — 미스터리 리빌은
같은 화면 위 심볼 크로스페이드로 끝나는 즉시성 있는 연출이라, 별도 배경까지 바꾸면 오히려 리듬이 끊긴다.

## 10. sheriff-sixgun 컨셉 시트

**컨셉명: Sheriff's Six-Gun (보안관의 6연발)**

브라스 라운지 계열에서 완전히 벗어난 두 번째 스타일 패밀리 — **먼지 낀 웨스턴**. 카탈로그 팔레트(사막
황토·세이지·선셋 오렌지·밤하늘 네이비)를 그대로 쓰고, 재질을 무광 가죽·놋쇠 리벳·풍화된 목재로 못박아
