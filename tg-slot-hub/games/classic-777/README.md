# Classic 777 / 클래식 777

3릴 3행 5라인 클래식 슬롯. 허브의 1호 게임이다. 코드는 없고 `math.json` + `manifest.json`만 있다.

## 실측 수치

전수 조사(`computeExactRtp`, 32³ = 32,768개 정지 조합 전부)로 얻은 **정확한** 값이다.
추정이 아니라 확정값이며 `tools/rtp-sim/src/games.test.ts`가 이 숫자를 그대로 검증한다.

| 지표 | 값 |
|---|---|
| RTP | **95.996%** (정확히 0.9599609375, 목표 96.0% 대비 -0.004%p) |
| 적중률 | **30.493%** (32,768조합 중 9,992) |
| 최대 배수 | **140.60x** (총 베팅액 기준) |
| 정지 조합 수 | 32,768 |

변동성 지표는 전수 조사로 나오는 값이 아니라 시뮬레이션 관측값이다.

| 시뮬레이션 (seed 42, 2,000,000 스핀) | 값 |
|---|---|
| RTP | 95.704% |
| 적중률 | 30.491% |
| 표준편차 | 3.449 (배수 기준) |

RTP는 6개 베팅 레벨(10 / 20 / 50 / 100 / 200 / 500) 전부에서 동일하다.
페이라인마다 심볼의 주변분포가 같기 때문에 라인 수나 베팅액이 RTP를 바꾸지 않는다.

재현:

```bash
pnpm --filter @tgslot/rtp-sim sim classic-777 --exact
```

## 페이테이블

배수는 **라인당 베팅액(총 베팅액 ÷ 5)** 기준이다. 왼쪽 릴부터 연속으로 이어져야 지급한다.

| 심볼 | 3개 | 2개 |
|---|---:|---:|
| 와일드 다이아 (`wild`) | 500 | — |
| 럭키 세븐 (`seven`) | 120 | 8 |
| 트리플 바 (`bar3`) | 75 | — |
| 더블 바 (`bar2`) | 30 | — |
| 싱글 바 (`bar1`) | 20 | — |
| 벨 (`bell`) | 15 | — |
| 체리 (`cherry`) | 10 | 2 |
| 빈칸 (`blank`) | — | — |

- 와일드는 모든 심볼을 대체한다 (스캐터 없음).
- 와일드 3개는 자기 배수 500과 대체 해석 중 **높은 쪽**으로 지급한다. 500이 항상 이긴다.
- 한 라인에서는 가장 비싼 해석 하나만 지급한다. 3연속일 때 2연속 배당을 겹쳐 주지 않는다.
- 총 베팅액 100코인 기준 와일드 라인 1개 = 10,000코인(100x). 다른 라인이 함께 터지면 최대 14,060코인(140.60x).

## 릴 구성

스트립 길이는 세 릴 모두 32. 배당이 높은 심볼일수록 적게 넣었다.

| 심볼 | 릴 1 | 릴 2 | 릴 3 |
|---|---:|---:|---:|
| `wild` | 1 | 2 | 1 |
| `seven` | 2 | 2 | 2 |
| `bar3` | 3 | 3 | 3 |
| `bar2` | 4 | 4 | 4 |
| `bar1` | 5 | 5 | 5 |
| `bell` | 5 | 5 | 5 |
| `cherry` | 5 | 5 | 6 |
| `blank` | 7 | 6 | 6 |
| 합계 | 32 | 32 | 32 |

같은 심볼이 스트립에서 인접하지 않도록 배치했다. 릴 2에만 와일드를 2개 둬서
가운데 릴이 자주 이어 주는 클래식 슬롯 특유의 리듬을 만든다.

## 페이라인

`math.json`의 `paylines`는 라인마다 **릴별 행 인덱스**를 적는다. 행은 위에서부터 0, 1, 2다.

| 라인 | 좌표 | 모양 |
|---|---|---|
| 0 | `[1, 1, 1]` | 가운데 가로줄 |
| 1 | `[0, 0, 0]` | 윗 가로줄 |
| 2 | `[2, 2, 2]` | 아랫 가로줄 |
| 3 | `[0, 1, 2]` | 왼쪽 위 → 오른쪽 아래 대각선 |
| 4 | `[2, 1, 0]` | 왼쪽 아래 → 오른쪽 위 대각선 |

## RTP 기여 상위 구간

총 베팅액 100코인 기준. 전체 83개 배수 구간 중 기여가 큰 순서다.

| 배수 | 확률 | RTP 기여 |
|---:|---:|---:|
| 4.00x | 2.893% | 11.572% |
| 6.00x | 1.706% | 10.236% |
| 15.00x | 0.668% | 10.025% |
| 2.00x | 4.187% | 8.374% |
| 3.00x | 2.505% | 7.516% |
| 0.40x | 12.518% | 5.007% |
| 24.00x | 0.171% | 4.102% |
| 15.40x | 0.189% | 2.914% |
| 7.00x | 0.409% | 2.863% |
| 1.60x | 1.688% | 2.700% |

적중의 41%는 0.4x짜리 체리 2개다. 원금을 밑도는 소액 적중이 리듬을 만들고,
RTP의 큰 몫은 4x~15x 구간이 담당한다. 이것이 medium 변동성의 형태다.

## 수정할 때

`math.json`을 고치면 반드시 다시 측정하고 이 문서의 숫자를 갱신한다.

```bash
pnpm --filter @tgslot/rtp-sim sim classic-777 --exact   # 새 수치 확인
pnpm --filter @tgslot/rtp-sim test                       # 게이트 통과 확인
```

게이트 테스트는 RTP 목표 ±0.5%p와 README 고정값을 함께 검사하므로,
문서를 갱신하지 않으면 테스트가 먼저 막는다. 절차는 `games/_template/HOWTO.md` 참고.
