# Classic 777 / 클래식 777

3릴 3행 5라인 클래식 슬롯. 허브의 1호 게임이다. 코드는 없고 `math.json` + `manifest.json`만 있다.

**빈칸이 없다.** 릴의 모든 칸이 실제 심볼이다. 채움용 `blank` 심볼은 쓰지 않는다.

## RTP를 두 조각으로 나눠 놓은 이유

이 게임의 페이테이블은 **94.5%**를 겨냥한다. 96%가 아니다.

허브의 프로그레시브 잭팟은 하우스가 재원을 댄다. 전 게임 베팅의 1%를 풀에 적립하고,
풀에는 하우스가 넣은 시드 25,000이 얹혀 있다. 당첨 시점의 기대 지급액을 적립액으로 나누면
분모 50,000에 시드 25,000이 더해져 **적립액의 1.5배**가 나간다.
즉 잭팟은 베팅액의 1% x 1.5 = **1.5%**를 플레이어에게 되돌린다.

| 조각 | 값 | 소유자 |
|---|---|---|
| 기본 게임 RTP (`rtpTarget`) | 94.5% | `math.json` 페이테이블 |
| 허브 잭팟 기여 (`jackpotContribution`) | 1.5% | API의 잭팟 원장 |
| **체감 총 RTP** (`rtpTotalTarget`) | **96.0%** | 플레이어가 실제로 받는 값 |

게이트 테스트가 검사하는 것은 `rtpTarget`(94.5%)이다. 잭팟은 수학 모델 밖에 있으므로
`computeExactRtp`에 잡히지 않는다. 이 게임의 페이테이블만 놓고 96%를 맞추면
잭팟까지 합쳐 97.5%가 되어 하우스 엣지가 사라진다.

## 실측 수치

전수 조사(`computeExactRtp`, 42³ = 74,088개 정지 조합 전부)로 얻은 **정확한** 값이다.
추정이 아니라 확정값이며 `tools/rtp-sim/src/games.test.ts`가 이 숫자를 그대로 검증한다.

| 지표 | 값 |
|---|---|
| 기본 게임 RTP | **94.4944%** (정확히 0.9449438505560954, 목표 94.5% 대비 -0.006%p) |
| 체감 총 RTP | **95.994%** (기본 94.4944% + 잭팟 1.5%) |
| 적중률 | **41.619%** (74,088조합 중 30,835) |
| 최대 배수 | **131.60x** (총 베팅액 기준) |
| 정지 조합 수 | 74,088 |

변동성 지표는 전수 조사로 나오는 값이 아니라 시뮬레이션 관측값이다.

| 시뮬레이션 (seed 42, 2,000,000 스핀) | 값 |
|---|---|
| RTP | 94.361% |
| 적중률 | 41.639% |
| 표준편차 | 3.193 (배수 기준) |
| 최대 승리 | 13,160 coins (131.60x) |

기본 게임 RTP는 6개 베팅 레벨(10 / 20 / 50 / 100 / 200 / 500) 전부에서 동일하다.
페이라인마다 심볼의 주변분포가 같기 때문에 라인 수나 베팅액이 RTP를 바꾸지 않는다.

재현:

```bash
pnpm --filter @tgslot/rtp-sim sim classic-777 --exact
```

## 페이테이블

배수는 **라인당 베팅액(총 베팅액 ÷ 5)** 기준이다. 왼쪽 릴부터 연속으로 이어져야 지급한다.

| 심볼 | 3개 | 2개 | 1개 |
|---|---:|---:|---:|
| 와일드 다이아 (`wild`) | 500 | — | — |
| 럭키 세븐 (`seven`) | 150 | 8 | — |
| 트리플 바 (`bar3`) | 50 | — | — |
| 더블 바 (`bar2`) | 30 | — | — |
| 싱글 바 (`bar1`) | 20 | — | — |
| 벨 (`bell`) | 6 | — | — |
| **아무 BAR** (`anybar` 그룹) | **5** | — | — |
| 체리 (`cherry`) | 4 | 2 | **1** |

- **체리 1개**는 릴 1(왼쪽 끝)에만 나오면 지급한다. 나머지 두 릴은 무엇이든 상관없다.
- **아무 BAR**는 `bar1`/`bar2`/`bar3`가 섞여도 3개면 지급한다.
  같은 종류로 이어지면 그 심볼의 배당(20 / 30 / 50)이 더 크므로 그쪽이 이긴다.
- 와일드는 모든 심볼을 대체하고, 그룹 연속에도 낀다 (스캐터 없음).
- 와일드 3개는 자기 배수 500과 대체 해석 중 **높은 쪽**으로 지급한다. 500이 항상 이긴다.
- 한 라인에서는 가장 비싼 해석 하나만 지급한다. 3연속일 때 2연속 배당을 겹쳐 주지 않는다.
- 총 베팅액 100코인 기준 와일드 라인 1개 = 10,000코인(100x). 다른 라인이 함께 터지면 최대 13,160코인(131.60x).

## 릴 구성

스트립 길이는 세 릴 모두 42. 빈칸이 없으므로 **채움 역할을 실제 심볼이 나눠 맡는다.**

| 심볼 | 릴 1 | 릴 2 | 릴 3 |
|---|---:|---:|---:|
| `wild` | 1 | 2 | 1 |
| `seven` | 4 | 3 | 3 |
| `bar3` | 5 | 4 | 4 |
| `bar2` | 5 | 4 | 4 |
| `bar1` | 6 | 6 | 4 |
| `bell` | 20 | 9 | 4 |
| `cherry` | 1 | 14 | 22 |
| 합계 | 42 | 42 | 42 |

빈칸을 없애면 모든 칸이 배당 후보가 되므로 적중률이 폭발한다. 이걸 누르는 장치가 **비대칭 배치**다.

- **릴 1은 벨이 채운다** (42칸 중 20). 벨은 3개 연속에만 배당이 있어서
  릴 2·3에서 벨을 줄이면(9개, 4개) 벨 3연속 자체가 드물어진다. 한쪽에 몰아넣으면 값이 싸다.
- **릴 2·3은 체리가 채운다** (14개, 22개). 체리 연속은 릴 1에서 시작해야 하는데
  릴 1의 체리가 1개뿐이라 체리 2개·3개 배당은 거의 나오지 않는다.
- **릴 1의 체리는 1개**다. 체리 1개 배당이 릴 1에서만 판정되므로 여기 개수가
  적중률을 그대로 결정한다. 1개면 와일드까지 합쳐 2/42, 스핀당 약 14%가 여기서 나온다.
- BAR는 세 릴 모두 15~16개로 고르게 뒀다. 아무 BAR 배당은 세 릴의 곱이라
  한 릴만 줄여도 급격히 떨어지므로 균형이 필요하다.

## 페이라인

`math.json`의 `paylines`는 라인마다 **릴별 행 인덱스**를 적는다. 행은 위에서부터 0, 1, 2다.

| 라인 | 좌표 | 모양 |
|---|---|---|
| 0 | `[1, 1, 1]` | 가운데 가로줄 |
| 1 | `[0, 0, 0]` | 윗 가로줄 |
| 2 | `[2, 2, 2]` | 아랫 가로줄 |
| 3 | `[0, 1, 2]` | 왼쪽 위 → 오른쪽 아래 대각선 |
| 4 | `[2, 1, 0]` | 왼쪽 아래 → 오른쪽 위 대각선 |

## RTP 기여 상위 구간

총 베팅액 100코인 기준. 전체 86개 배수 구간 중 기여가 큰 순서다.

| 배수 | 확률 | RTP 기여 |
|---:|---:|---:|
| 1.00x | 14.720% | 14.720% |
| 30.00x | 0.294% | 8.827% |
| 10.00x | 0.794% | 7.937% |
| 1.20x | 6.112% | 7.334% |
| 1.60x | 3.419% | 5.470% |
| 4.00x | 1.223% | 4.891% |
| 2.00x | 2.102% | 4.203% |
| 6.00x | 0.620% | 3.717% |
| 31.60x | 0.089% | 2.815% |
| 31.20x | 0.070% | 2.190% |

적중의 3분의 1이 1.00x, 곧 원금 반환이다. 체리 1개가 만든 리듬이다.
잔고가 천천히 줄면서 릴은 자주 멈춰 서고, RTP의 큰 몫은 10x~31x 구간이 담당한다.

## 수정할 때

`math.json`을 고치면 반드시 다시 측정하고 이 문서의 숫자를 갱신한다.

```bash
pnpm --filter @tgslot/rtp-sim sim classic-777 --exact   # 새 수치 확인
pnpm --filter @tgslot/rtp-sim test                       # 게이트 통과 확인
```

게이트 테스트는 RTP 목표 ±0.5%p와 README 고정값을 함께 검사하므로,
문서를 갱신하지 않으면 테스트가 먼저 막는다. 절차는 `games/_template/HOWTO.md` 참고.
