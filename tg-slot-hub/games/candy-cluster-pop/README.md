### 스트립 (다시 만드는 법)

릴마다 120칸, 6릴 모두 같은 밀도표다. 하트 9 · 별 10 · 젤리빈 11 · 빨간 물방울/파란 각설탕/초록 구슬/보라 캡슐 17 · 노란 별사탕 16 · 와일드 3 · 스캐터 3.
뭉침은 물방울 5종 0.27, 하트·별·젤리빈 0.1(`clumpBy`), 기본 0.1이고 스트립 시드는 **365**다.

```json
{ "reels": { "heart": 9, "star": 10, "bean": 11, "drop_red": 17, "drop_blue": 17, "drop_green": 17,
             "drop_purple": 17, "drop_yellow": 16, "wild": 3, "scatter": 3 },
  "clump": 0.1,
  "clumpBy": { "drop_red": 0.27, "drop_blue": 0.27, "drop_green": 0.27, "drop_purple": 0.27, "drop_yellow": 0.27,
               "heart": 0.1, "star": 0.1, "bean": 0.1 } }
```

`pnpm --filter @tgslot/rtp-sim run tune candy-cluster-pop --strips <위 JSON 경로> --strip-seed 365 --spins 1000000 --shards 4`가 같은 스트립을 만든다
(`--write`를 주면 math.json을 덮어쓰니 주의). 시드가 바뀌면 배열이 통째로 달라져 연쇄 깊이가 크게 흔들린다(같은 밀도표에서 시드 400개를 15만 스핀씩 쟀을 때 ×5 단계 빈도가 0.13%에서 1.5%까지, 중앙값 0.35%로 흩어졌다).
365는 그중 적중률 51%대에서 연쇄가 깊고(×5 단계 0.74%), 물방울 5색의 터지는 빈도 차(최대/최소 1.4배)와 스캐터 진입(약 178스핀에 1회)이 고른 시드를 골랐다.

**계획과 다른 점.** 이 엔진(스트립 끌어오기 리필)에서는 P(지속)이 최초 클러스터율의 약 절반(0.27 대 0.51)에 묶인다. 계획의 평균 연쇄 1.6은 적중률 게이트(≤60%)를 깨지 않고는 못 낸다.
그래서 평균 연쇄를 1.19 → 1.38로만 올리고, 대신 **깊은 연쇄가 눈에 띄도록** 물방울 클러스터를 뭉치게 해 ×5 단계를 0.085% → 0.73%로(약 8배),
×8 단계를 0.009% → 0.15%로(약 16배) 끌어올렸다. 사다리는 실제로 닿는 ×8까지만 그린다(옛 ×12·×20은 130만 스핀에 1회라 약속과 실제가 달랐다).
값은 적중률이 35% → 53%로 올라 1배 미만 소액 당첨이 늘어난 것이다. 뭉침(`clumpBy` 물방울)을 낮추고 같은 방식으로 시드를 다시 고르면 되돌릴 수 있다.
평균 연쇄를 더 올리려면 엔진 쪽 리필 규칙(낙하 칸이 이웃과 같은 심볼이 될 확률을 높이는 식)이 필요하다.
