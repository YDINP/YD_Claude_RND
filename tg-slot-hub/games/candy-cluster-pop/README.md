# Candy Cluster Pop / 캔디 클러스터 팝

> 같은 사탕 5개가 붙으면 터지고, 다시 터질 때마다 배수가 오른다.

**6릴 5행, 클러스터 5+, 연쇄(텀블).** 카탈로그 #6, 웨이브 2 첫 게임. 정본 계획은
`docs/PLAN_candy-cluster-pop.md`다.

- 배당 기준: 총 베팅액 × 페이테이블 배수 × 그 연쇄의 사다리 배수(`[1,2,3,5,8,12,20]`, 매 스핀 리셋)
- 와일드: 무지개 롤리팝. 여러 심볼의 클러스터에 동시에 낀다
- 보너스: 스캐터 4개 → **주문 카드 라운드**(8스핀, 카드 3장, 완료마다 상품 + 2스핀, 최대 6장, 최장 20스핀)
- 상한: 연쇄 12회, 라운드 지급 5,000×

스트립은 릴마다 120칸이다. 밀도표(와일드 3, 스캐터 3(6번 릴만 4), heart 9, star 10, bean 11, 물방울 17/17/17/17/16)에

주문 카드는 target 5~8 / 연쇄 2~3으로 낮추고 상품을 3.35~13.5x로 맞췄다.

**계획과 다른 점.** 이 엔진(스트립 끌어오기 리필)에서는 P(지속)이 최초 클러스터율의 약 절반에 묶인다.
최초 클러스터율 32%에서 평균 연쇄 1.6(P(지속) 0.375)을 내려면 최초 클러스터율이 70% 가까이 돼야 해서 적중률 게이트(≤60%)를 깬다.
그래서 적중률 목표를 지키고 평균 연쇄는 1.19로 뒀다. 사다리 2단계 이상 몫은 22.3%p다.
