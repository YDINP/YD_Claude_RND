# Hanbok Night Market / 한복 야시장

> 청사초롱 세 개가 켜지면 야시장 한복판 윷판이 펼쳐진다. 윷을 던져 말을 옮기고, 갈림길에 딱 멈추면 지름길로 꺾어 결승 등불탑의 큰 상을 노린다.

**5릴 3행, 25 페이라인, 말판 보너스.** 카탈로그 #10. 정본 계획은 `docs/PLAN_hanbok-night-market.md`다.

- 배당 기준: 라인당 베팅액 × 페이테이블 배수, 왼쪽 릴부터 연속, 와일드(호랑이 탈)가 초롱 말고 전부 대신한다
- 보너스: 청사초롱(`bonus`)은 릴 1·3·5에만 있고 한 릴에 하나만 보인다. 3개 = 총 베팅 ×2 + **말판 보너스**
- 말판: 윷판 29칸, 기회 5번(윷·모·한 번 더 칸 +1, 던진 수 + 기회 ≤ 12), 등불 3개(함정 3번이면 끝), 결승 큰 상 30,
  지급 = max(5, 바구니 × 배수) (총 베팅 배수), 갈림길(첫째 모퉁이 o5·둘째 모퉁이 o10·방 c)에 딱 멈추면 다음부터 지름길
- 서버 권위: 말판 전체는 트리거 스핀 응답 하나(`features[].type === 'boardBonus'`)에 실린다. 화면의 «윷 던지기»는 연출이다
- 상한: 말판 구조상 최대 200배(`boardBonus.maxWin`, DP로 검사), 라운드 캡 1,000배(`round.maxWinCap`, 구조상 닿지 않음)

통합 QA에서 고친 것:

플레이어 QA 뒤 2차 통합 QA에서 고친 것(2026-11-26):
- **꼬리표 오독** — 한가운데(×+2) 칸 꼬리표가 바로 옆 «코인 8» 칸에 더 가까워 «개 → 8코인»으로 읽혔다. 꼬리표 자리를 고를 때 «다른 칸보다 제 칸에 10px 이상 가깝다»(`chipOwnership`, `CHIP_OWN_MARGIN`)를 조건으로 넣고 방향 후보를 22.5° 간격 16개로 늘렸다. 꼬리표마다 제 칸을 가리키는 말풍선 꼬리(`chipTail`)를 그린다. 도달 가능한 35상태·136꼬리표 전수에서 최소 여유 10.0px, 단위 테스트로 고정(`chipPlan.test.ts`)
- **결승 순간이 0.46초 만에 요약에 덮임** — 마지막 던지기 효과 뒤 `finaleMs`(보통 1.2s·빠름 1.0·터보 0.8·모션 축소 0.9, ⏩ 중 +0.5, 탭 넘김 +0.3)를 더 머문다. 결승은 판 가운데 큰 배너 «결승! 큰 상 30» + 탑에서 판 안쪽으로 번지는 빛 고리 두 겹 + 불꽃 두 번(탑·탑과 중앙 사이)으로 키웠다. 측정: 결승 효과 시작 → 요약 1.66s(이전 0.46s)
- «지름길!»을 판 한가운데 배너에서 결과 외침 줄로 옮겼다(한가운데 칸의 말·배수 펀치를 덮던 문제)
- 판이 끝나는 던지기(결승 도착)에서는 윷·모라도 «한 번 더!» 도장을 찍지 않는다
- 칸 효과 글자(«등불이 꺼졌어요» 등)는 다음 대기 상태에서 걷고, 갈림길 칸에 효과가 뜨는 동안 «지름길» 작은 글자를 숨긴다(겹침 «지름±3» 해소)
- 도움말 배수 칸: «배수가 적힌 만큼 올라요(처음 ×1, 최대 ×4). 마지막에 바구니 전체에 곱해져요»
- ⏩/⏭ 버튼을 시스템 이모지에서 코드 SVG 아이콘으로
- 말판 화면 세로 배치: 결과 외침 줄이 판과 윷 멍석 사이 빈 띠를 나눠 가진다(48~132px)
- 안전장치: 말판 오버레이를 `BoardErrorBoundary`로 감싸 렌더 중 예외가 나면 말판을 접고 `finishBoard()`로 spin()의 기다림을 푼다

플레이어 QA 2회차 뒤 3차 통합 QA에서 고친 것(2026-11-26):
- **요약 카드의 틀린 등식** — 최소 지급이 적용된 판(약 5%)에서 «바구니 2배 × 배수 2 = 5배»가 찍혔다. 식은 바구니×배수 결과 그대로 쓰고, 아랫줄 «→ 최소 지급 5배로 올려 받아요»가 올린다(ko/en, 회귀 테스트)
- 결승 탑에 «+30» 딱지(말 위 층), 합친 꼬리표 가운뎃점(«개·윷»), 영어 숫자 꼬리표는 먹색 바탕(«코인 2» 칸과 구별), 칸 효과 글자가 뜨는 동안 «지름길» 글자 숨김, HUD 받침판, 요약 코인은 엽전 그림
- 복원한 판이 끝난 뒤 WinStrip이 라운드 합계(라인 + 초롱 + 말판)까지 오른다(스냅숏 `totalWin`)
- ⏩로 건너뛴 요약은 저절로 닫히지 않는다 — 자동 닫힘은 오토스핀·[자동]만(기획 7-6)
- 병합 대비: 골든 해시에 이 팩 추가, 말판 게이트 `state == null`, 렌더러 `setPaused` 선택 메서드, RTP 리포트는 말판 팩에서 프리스핀 0% 줄 대신 말판 진입률

병합 핫스팟(리드 참고): featureTriggerCount 체인(`evaluate.ts`·`anticipation.ts`), `SOUND_PRESETS`·`SoundPreset`, `SpinDebugPresetSchema`·`FeatureTriggerSchema`, `toSharedFeature`·`matchesDebugPreset` switch는 세 팀이 같은 줄을 고친다. `resolveSpin`의 RNG 소비 순서는 «릴 정지 → 뮤테이션 → 말판 윷 → (다른 팀 피처) → 잭팟»으로 두면 이 팩 골든이 그대로다.

베팅 레벨별 RTP: 레벨 100이 +0.564%p로 ±0.5%p를 살짝 넘지만 게이트는 «자기 CI 안» 조항으로 통과했다. 이 게임의 지급(라인·스캐터·말판)은 모두 총 베팅에 선형이라 기대값은 레벨마다 같다 — 레벨별 차이는 표본 잡음이다.

- 시트: `bonus-win`은 후광·반짝임을 빼고 종이 안쪽 빛만 바뀐다(1차는 크림색 후광 얼룩), `lantern_girl-win`은 소품(바구니)이 끼어든 1차를 버렸다. 시트 도안은 정지 심볼과 완전히 같지는 않다(호랑이 탈 줄무늬 등) — 승리 1초 동안 도는 것이라 허용.
- 칸 아이콘·윷가락·말 받침·결승 탑·윷판 선은 기획서 §8-3대로 **생성하지 않고 코드 드로잉**한다(말은 `lantern_girl`, 탑 꼭대기는 `bonus` 그림 재사용).

**검수 기록(브라우저 390×844·430×932, 헤드리스 크롬).** 대기 화면 5열이 프레임 창에 맞고(잘림 0), 당첨은 빨간 테두리·어두워진 나머지 칸으로 표시, 빅윈 스킨(세리프 제목·꽃잎/엽전/불꽃 입자·이중 고리) 적용, 말판 화면에 멍석 배경이 깔리고 노드가 읽힘, 진입·복귀 클립이 실제로 재생되어 단색 커튼 폴백 대신 쓰임을 눈으로 확인했다.

## 사운드 (사운드 레인, 2026-11-26)

프리셋 `hanbok`(`theme.json` `sound.preset`). 평조 오음(G A B D E) 한 옥타브 반(G4~E6)에 가야금(명주실 줄)·해금(활)·대금(숨)·장구·꽹과리·징만 쓴다.
shrine 의 고토가 미야코부시 음계의 날카로운 뜯는 현이었다면 여기는 장조 오음의 부드러운 현이고, 금속성은 꽹과리(비조화 놋쇠)와 징(낮게 부푸는 울림)에서만 나온다. 합성은 전부 코드(`apps/hub/src/lib/audio.ts`·`bgm.ts`·`bgmVoices.ts`)이고 녹음 파일은 없다.

| 이벤트 | 소리 |
|---|---|
| 스핀 시작 | 가야금 짧은 글리산도(5음 상행) + 가죽 북 같은 낮은 딸깍 스핀 루프 |
| 릴 정지 | 장구 채편 «덕». 다섯째 릴만 궁편 «쿵»이 같이 울린다 |
| 작은 당첨 | 장구 «덩» + 가야금 3음 상행(G·D·G) + 엽전 몇 닢 |
| 큰 당첨 | 해금 활 긋기 스웰(대역통과 900→1500Hz, 5.5Hz 비브라토) + 꽹과리 «갱» + 가야금 상행. 등급이 오르면 스웰·꽹과리가 늘고 epic 등급부터 징, max 는 «갱 갱 갱개갱» |
| 피처(초롱 3 → 말판 진입) | 꽹과리 «갱 갱 갱개갱» + 징 저음 스웰 |
| 기대감 | 낮고 어두운 톱니파 상승음 + 징 저음 맥놀이 층(`Recipe.riserLayer`) |
| 롤업 틱 / 끝 | 가야금 하모닉 «팅»(오음계를 한 칸씩 오른다) / 징 짧게 |
| 윷 던지기 `playYutToss` | 서서히 차오르는 «휙» |
| 윷 착지 `playYutLand(steps)` | 나무 막대 «딱딱딱딱»(간격 34·36·54ms). 납작한 면이 위면 밝고 짧게, 둥근 면은 둔하고 길게. 모(5)는 넷 다 둔하다 |
| 결과 `playYutCall(steps)` | 도→모로 갈수록 오음계 한 칸씩 위 가야금 한 음(392→659Hz). 윷·모는 꽹과리 장식 + «한 번 더» 반짝 |
| 말 `playTokenHop(i)` | 부드러운 나무 «톡», 칸마다 반음씩 위(12칸에서 멈춤) |
| 엽전 칸 / 배수 칸 | «짤랑»(고정 패턴) / 해금 상행 슬라이드 + 하모닉(단계마다 한 음 위: 494→880Hz) |
| 함정 / 지름길 | 바람 «쉬익» + «훅» + 장구 «쿵» 하강 / 대금 숨 섞인 3음 상행 |
| 결승 / 요약 | 징 + 꽹과리 몰아치기 + 가야금 상행(음악 덕킹 2.6초) / 장구 «덩» + 가야금 화음(덕킹 1.4초) |

배경음 `HANBOK`(`bgm.ts`): 굿거리 12/8(점4분 = 80, 한 마디 4박·박 안에 3분할), 평조 G 오음, 가야금 분산화음 + 해금 선율 + 거문고 베이스 + 장구 장단(덩 · 기덕 쿵 · 더러러 쿵 · 기덕 쿵 덕), `accent`로 4마디마다 징 한 번.
말판 변주(free)는 자진모리 느낌으로 ×1.35 빨라지고 두 음 올라가며 꽹과리가 박을 짚고 선율이 해금에서 대금으로 바뀐다(`Kit.freeVoices`).
수치와 earshot 판독은 `docs/SOUND_CHECK.md` 의 «hanbok-night-market 사운드» 절. **수치는 참고값이고 최종 귀 판정은 사용자 몫이다.**

공용 파일에 더한 것(추가 위주): `SoundPreset`/`SOUND_PRESETS` 에 `hanbok`, `Recipe.riserLayer`(기대감에 층 추가, 다른 프리셋은 안 씀), `BgmRole 'gong'`·`BgmStyle.accent`(N마디마다 타악 한 방), `Kit.freeVoices`(변주에서 악기 교체).
말판 화면의 `boardSfx.ts`는 이제 `audio.ts`의 말판 함수를 직접 import 한다.
