# Growing Greenhouse / 자라는 온실 정원

> 4×4 화단에서 같은 꽃 5송이가 이어지면 터지고, 터진 칸이 쌓이면 판이 8×8까지 자란다. 새로 열린 화분의 씨앗은 판이 자랄 때마다 커져 그 칸이 낀 클러스터에 곱해진다.

**자라는 판(물리 8×8, 활성 4×4 → 8×8) · 직교 클러스터 5송이 이상 · 씨앗 배율 · 정원 프리스핀.** 정본 계획은
`docs/PLAN_greenhouse-garden.md`이고, 응답·이벤트·디버그·상태 계약은 그 문서 끝 「구현 계약」 절이다.

- 페이: 활성 영역 안 상하좌우 같은 꽃 5송이 이상(나비 포함). 배당 기준은 **총 베팅액**. 나비만 모인 그룹은 미지급, 물뿌리개는 클러스터를 막는다
- 연쇄: 터진 칸 제거 → 활성 범위 안 중력 → 위에서 리필(스트립 끌어오기, RNG 0회). 사다리 배수 없음(배율은 씨앗만). 팝 단계 상한 16
- 성장: 한 스핀 누적 터진 칸이 문턱 `[10, 19, 30, 42]`에 닿을 때마다 한 겹(5×5 → 6×6 → 7×7 → 8×8). 덮여 있던 화분 내용은 착지 때 이미 정해져 있다
- 씨앗: 새로 열린 칸마다 1회 추첨(기본 `없음 84 / ×2 11 / ×3 5`). 성장 때 기존 씨앗 +1등급(`×2 → ×3 → ×5 → ×10 → ×20`). 씨앗 칸이 낀 클러스터 × 씨앗 합(상한 ×100), 쓰이면 사라짐. 판 위 최대 16개
- 물뿌리개: 스핀이 끝난 활성 판에서 센다. 3·4·5·6+개 → 총 베팅 ×1.5·×4·×12·×50
- 정원 프리스핀: 물뿌리개 3·4·5+개 → 10·11·12스핀. 시작 크기 = 진입 스핀 마지막 크기(최소 5×5), 크기·성장 막대·씨앗이 스핀 사이에 남는다. 프리스핀 전용 스트립(물뿌리개 3/240, 묶음 짧음)·문턱 `[13, 28, 45, 64]`·씨앗 표 `82 / 13 / 5`
- 햇살: 프리스핀 8×8에서 막대가 64 + 48·k를 넘을 때마다(한 스핀 최대 1회) 씨앗 전부 +1등급, 빈 화분 2곳에 ×2 씨앗
- 리트리거: 물뿌리개 3개 이상 +4스핀, 최대 2회(최장 20스핀). 최저 보장: 프리스핀 합이 총 베팅 ×10 미만이면 마지막 스핀에서 채운다
- 상한: 라운드(진입 스핀 + 프리스핀) 지급 총 베팅 5,000×(`round.maxWinCap`)
- 유료 스핀 사이에는 아무것도 이월하지 않는다(기본 게임은 `nextState`가 없다)
