# Royal Diamond 777 / 로열 다이아몬드 777

> 물음표 타일이 한꺼번에 같은 심볼로 뒤집히는, 브라스 라운지의 정통 후속작.

5릴 3행 10라인. 카탈로그 #3.

빈칸은 없다. 릴의 모든 칸이 실제 심볼이다.

## RTP를 두 조각으로 나눠 놓은 이유

허브 잭팟은 하우스가 재원을 대고 베팅액의 1.5%를 되돌린다. 그래서 게임 페이테이블은
**94.5%**를 겨냥하고, 잭팟을 얹어 체감 96%가 된다. 잭팟은 수학 모델 밖(API의 잭팟 원장)에
있어 `computeExactRtp`에 잡히지 않는다.

| 조각 | 값 | 소유자 |
|---|---|---|
| 기본 게임 RTP (`rtpTarget`) | 94.5% | `math.json` 페이테이블 |
| 허브 잭팟 기여 (`jackpotContribution`) | 1.5% | API의 잭팟 원장 |
| **체감 총 RTP** (`rtpTotalTarget`) | **96.0%** | 플레이어가 실제로 받는 값 |

## 실측 수치

정지 조합이 2억 9천만 개라 전수 조사가 불가능하지만 **해석적으로 정확한 값**을 쓴다.
미스터리 공개 심볼로 조건부화하면 릴 독립이 복원되기 때문이다 (아래 메커닉 절 참고).

| 지표 | 값 |
|---|---|
| 산출 방식 | **해석적 계산** (`method: "analytic"`) |
| 기본 게임 RTP | **94.4697%** (목표 94.5% 대비 -0.030%p) |
| 체감 총 RTP | **95.970%** |
| 적중률 | **34.89%** (표본 추정, 20만 스핀) |
| 최대 배수 (기본 게임) | **128.00x** |
| 정지 조합 수 | 291,753,252 |

RTP 구성:

| 조각 | 기여 | 비중 |
|---|---:|---:|
| 페이라인 | 76.871% | 81.4% |
| 스캐터 | 2.668% | 2.8% |
| 프리스핀 | 14.930% | 15.8% |

프리스핀 진입 확률은 **1.0725%**, 약 93스핀에 한 번이다.
스캐터 3개 이상이면 프리스핀 8회가 열리고 승리에 2배가 곱해진다. 리트리거로 8회가 더 붙는다.

재현:

```bash
pnpm --filter @tgslot/rtp-sim sim royal-diamond-777 --exact
```

## 페이테이블

배수는 **라인당 베팅액(총 베팅액 / 10)** 기준이다. 왼쪽 릴부터 연속으로 이어져야 지급한다.
미스터리 심볼은 페이테이블이 없다. 공개된 뒤의 심볼로만 지급한다.

| 심볼 | 5개 | 4개 | 3개 | 2개 |
|---|---:|---:|---:|---:|
| 로열 와일드 (`wild`) | 500 | - | - | - |
| 럭키 세븐 (`seven`) | 400 | 120 | 40 | - |
| 블루 다이아 (`diamond`) | 300 | 90 | 30 | - |
| 트리플 바 (`bar3`) | 200 | 60 | 20 | - |
| 더블 바 (`bar2`) | 120 | 40 | 15 | - |
| 싱글 바 (`bar1`) | 80 | 30 | 10 | - |
| 브라스 벨 (`bell`) | 60 | 20 | 5 | - |
| 벨벳 체리 (`cherry`) | 40 | 12 | 4 | 1 |

### 스캐터

스캐터는 페이라인과 무관하게 화면에 보이는 칸을 전부 센다. 배수 기준은 **총 베팅액**이다.

| 스캐터 | 총 베팅액 배수 |
|---|---:|
| 3개 | 2x |
| 4개 | 10x |
| 5개 | 40x |

## 미스터리 공개

```json
"mutations": [
  { "type": "mystery", "symbol": "mystery",
    "weights": { "seven": 4, "diamond": 6, "bar3": 8, "bell": 14, "cherry": 26 } }
]
```

릴이 멈춘 뒤, 화면의 **모든** 미스터리 칸이 가중 추첨된 **하나의** 심볼로 동시에 바뀐다.
칸마다 따로 뽑지 않는다. 따로 뽑으면 칸 사이의 상관이 사라져 아래 해석식이 깨진다.

공개 풀에서 와일드와 스캐터는 제외된다. 공개 후 스캐터가 늘면 프리스핀 트리거 확률이
흔들리기 때문이고, 스키마가 이를 강제한다.

**왜 해석적으로 풀리는가.** "공개가 s였다"는 조건 아래에서 그리드는 미스터리 심볼이 s로
치환된 것과 같다. 릴별 심볼 분포는 미스터리의 확률 질량이 s로 옮겨간 것이고, 릴끼리는
여전히 독립이다. 따라서

```
E[승리] = Sum_s  P(공개 = s) x E[승리 | 미스터리 -> s]
```

이고 각 조건부 항은 기존 페이라인 닫힌 식 그대로다. 근사가 아니라 정확값이다.
`rtp.test.ts`가 이 값이 몬테카를로와 3 표준오차 안에서 맞는지 고정해 둔다.

## 릴 구성

스트립 길이는 릴마다 다르다. 앞 세 릴이 적중률을, 뒤 두 릴이 배당 크기를 정한다.
미스터리는 릴마다 2~3개로, 화면에 하나 이상 뜰 확률이 대략 절반이다.

## 수정할 때

`math.json`을 고치면 반드시 다시 측정하고 이 문서의 숫자를 갱신한다.

```bash
pnpm --filter @tgslot/rtp-sim sim royal-diamond-777 --exact
pnpm --filter @tgslot/rtp-sim test
```

게이트는 RTP 목표 +-0.5%p를 검사하고, 몬테카를로 모델은 `|rtp - target| <= max(0.5%p, 3xSE)`와
리포트의 `spins`/`seed`/`stderr`/`ci95` 존재를 함께 본다.
절차는 `games/_template/HOWTO.md` 참고.
