# Sheriff's Six-Gun / 보안관의 6연발

> 보안관 배지가 릴을 통째로 덮고, 딴 돈은 카드 한 장에 두 배가 되거나 사라진다.

5릴 3행 20라인. 카탈로그 #4.

빈칸은 없다. 릴의 모든 칸이 실제 심볼이다.

## RTP를 두 조각으로 나눠 놓은 이유

허브 잭팟은 하우스가 재원을 대고 베팅액의 1.5%를 되돌린다. 그래서 게임 페이테이블은
**94.5%**를 겨냥하고, 잭팟을 얹어 체감 96%가 된다. 잭팟은 수학 모델 밖(API의 잭팟 원장)에
있어 `computeExactRtp`에 잡히지 않는다.

| 조각 | 값 | 소유자 |
|---|---|---|
| 기본 게임 RTP (`rtpTarget`) | 94.5% | `math.json` 페이테이블 |
| 허브 잭팟 기여 (`jackpotContribution`) | 1.5% | API의 잭팟 원장 |
| **체감 총 RTP** (`rtpTotalTarget`) | **96.0%** | 플레이어가 실제로 받는 값 |

## 실측 수치

확장 와일드가 릴 창 전체를 덮으므로 닫힌 식이 없다. **몬테카를로**로 잰다.

| 지표 | 값 |
|---|---|
| 산출 방식 | **몬테카를로** (`method: "monte-carlo"`) |
| 스핀 수 / 시드 | 25,000,000 / `w1-tune` |
| 기본 게임 RTP | **94.3641%** (목표 94.5% 대비 -0.136%p) |
| 표준오차 | 0.0969%p |
| 95% 신뢰구간 | [94.1741%, 94.5540%] (반폭 **0.1899%p**) |
| 체감 총 RTP | **95.864%** |
| 적중률 | **32.03%** |
| 최대 배수 (기본 게임) | **195.40x** |
| 정지 조합 수 | 298,655,000 |

독립 시드 교차 확인: seed `w1`, 500만 스핀에서 94.715% (표준오차 0.218%p).

RTP 구성:

| 조각 | 기여 | 비중 |
|---|---:|---:|
| 페이라인 | 66.18% | 70.1% |
| 스캐터 | 4.40% | 4.7% |
| 프리스핀 | 23.78% | 25.2% |

프리스핀 진입 확률은 **1.806%**, 약 55스핀에 한 번이다.
스캐터 3개 이상이면 프리스핀 8회가 열리고 승리에 2배가 곱해진다. 리트리거로 8회가 더 붙는다.

재현:

```bash
pnpm --filter @tgslot/rtp-sim sim sheriff-sixgun --exact --mc 5000000
```

## 페이테이블

배수는 **라인당 베팅액(총 베팅액 / 20)** 기준이다. 왼쪽 릴부터 연속으로 이어져야 지급한다.

| 심볼 | 5개 | 4개 | 3개 | 2개 |
|---|---:|---:|---:|---:|
| 보안관 배지 (`wild`) | 340 | - | - | - |
| 보안관 (`sheriff`) | 450 | 140 | 45 | - |
| 무법자 (`bandit`) | 280 | 85 | 28 | - |
| 리볼버 (`revolver`) | 170 | 51 | 17 | - |
| 다이너마이트 (`dynamite`) | 110 | 40 | 14 | - |
| 편자 (`horseshoe`) | 80 | 28 | 9 | - |
| 위스키 (`whiskey`) | 57 | 20 | 7 | - |
| 선인장 (`cactus`) | 40 | 14 | 5 | - |
| 가죽 부츠 (`boot`) | 28 | 11 | 3 | 1 |

### 스캐터

스캐터는 페이라인과 무관하게 화면에 보이는 칸을 전부 센다. 배수 기준은 **총 베팅액**이다.

| 스캐터 | 총 베팅액 배수 |
|---|---:|
| 3개 | 2x |
| 4개 | 8x |
| 5개 | 30x |

## 확장 와일드와 갬블

```json
"mutations": [
  { "type": "expandWild", "symbol": "wild", "reels": [1, 2, 3],
    "minCount": 1, "coverScatter": false, "onlyIfWin": false }
]
```

릴 2/3/4(0-기준 인덱스 1/2/3) 중 하나에 배지가 하나라도 뜨면 그 릴 전체가 배지로 덮인다.
**스캐터 칸은 덮지 않는다.** 덮으면 프리스핀 트리거 확률이 흔들리기 때문이다.

`onlyIfWin: false`는 **의도한 값**이다. 이 게임의 배지는 조건 없이 항상 펼쳐지고,
페이테이블과 스트립도 그 전제 위에서 94.5%로 맞춰져 있다. `true`로 바꾸면 지급을 늘리지 못하는
확장이 전부 취소되므로 RTP가 내려가고 재튜닝이 필요하다.

확장은 RNG를 쓰지 않는다. 정지 그리드만 보면 결정되므로 같은 정지 위치는 항상 같은 확장을 낳는다.
그래서 `SpinResult.gridBefore`와 `mutations[]`만 있으면 렌더러가 확장 트윈을 그대로 재생할 수 있다.

**갬블은 API 계층이 담당한다. 엔진에는 없다.** 승리가 있을 때 서버가 `p=0.5`, `payout=2배`,
`maxSteps=5`의 코인 플립을 제안하고 결과를 라운드 레코드에 기록한다. 기대값이 중립이라
RTP를 바꾸지 않고 분산만 키우므로 이 문서의 수치에는 포함되지 않는다.

## 릴 구성

릴 1/2는 선인장이, 릴 3은 부츠가 채운다. 서로의 3연속을 막아 적중률을 30%대로 누른다.
부츠는 2연속 배당이 있어 릴 1/2에서 특히 희귀해야 한다. 릴 4/5는 보안관/무법자로 채워 배당을 키운다.

| 심볼 | 릴 1 | 릴 2 | 릴 3 | 릴 4 | 릴 5 |
|---|---:|---:|---:|---:|---:|
| `wild` | 1 | 1 | 2 | 2 | 3 |
| `scatter` | 3 | 2 | 1 | 3 | 2 |
| `sheriff` | 2 | 5 | 4 | 11 | 12 |
| `bandit` | 5 | 1 | 3 | 9 | 9 |
| `revolver` | 2 | 5 | 8 | 11 | 2 |
| `dynamite` | 3 | 3 | 1 | 6 | 2 |
| `horseshoe` | 7 | 2 | 7 | 1 | 6 |

## 수정할 때

`math.json`을 고치면 반드시 다시 측정하고 이 문서의 숫자를 갱신한다.

```bash
pnpm --filter @tgslot/rtp-sim sim sheriff-sixgun --exact --mc 5000000
pnpm --filter @tgslot/rtp-sim test
```

게이트는 RTP 목표 +-0.5%p를 검사하고, 몬테카를로 모델은 `|rtp - target| <= max(0.5%p, 3xSE)`와
리포트의 `spins`/`seed`/`stderr`/`ci95` 존재를 함께 본다.
절차는 `games/_template/HOWTO.md` 참고.
