# Idol Stage Live / 아이돌 스테이지 라이브

> 무대 초대권 3장이 서면 무대 룰렛이 열린다. 돌리기 3번 동안 상을 모으고, «한 단계 위로»에 걸리면 더 큰 상이 있는 안쪽 고리로 들어간다.

**5릴 4행, 1024 ways 왼쪽→오른쪽, `betDivisor 50`.** 카탈로그 #11. 정본 계획은 `docs/PLAN_idol-stage-live.md`다
(맨 끝 «구현 계약» 절이 엔진·API 계약).

- 배당 기준: 웨이당 베팅액(총 베팅 ÷ 50) × 페이테이블 × 경로 수. 룰렛 상은 **총 베팅 배수**
- 와일드: 황금 마이크. 릴 2~5에만. 초대권을 뺀 모든 심볼을 대신한다. 응원봉으로 세지 않는다
- 보너스: 무대 초대권(스캐터, 배당 없음). 3장 → 무대 룰렛(바깥 고리 시작), 4장 이상 → 가운데 고리 시작
- 무대 룰렛: 3겹(바깥 12칸·가운데 10칸·안쪽 8칸). 돌리기(곡) 3번, 앙코르로 최대 2번 더, 회전 최대 7번
- 응원봉 불빛: 트리거 스핀 화면의 응원봉 N개 → 고리마다 `litOrder` 앞 N칸(최대 6, 안쪽 5)에 불, 불 켜진 코인 칸 2배. 스핀 사이 이월 없음
- 상한: 한 스핀(ways + 룰렛) 2,000× (`round.maxWinCap`). 룰렛 단독 이론 최대 384×
- 결과는 트리거 스핀 응답 하나에 다 실린다(`features[]`의 `stageRoulette`). 프리스핀·`game_states` 없음

## 사운드·빅윈·전환 (사운드 레인, 2026-11-26)

정본 기록은 `docs/SOUND_CHECK.md`의 «idol-stage-live 사운드» 절과 `docs/TRANSITION_DESIGN.md` §2-8이다.

- **효과음 `idol` 프리셋**(`apps/hub/src/lib/audio.ts`): 손뼉(릴 정지)·신스 브라스(당첨)·4박 킥 드롭(큰 당첨)·손뼉 롤이 빨라지며 차오르는 진입음. 합성 «함성»은 earshot이 군중으로 읽지 못해(z −0.1~−0.7) 기획서의 대체 규칙대로 손뼉 롤로 바꿨다.
- **무대 룰렛 소리**(`rouletteSfx.ts` → `rouletteCues.ts` 기본 싱크): 틱·점등(반음씩 상승)·코인 «띠링»·한 단계 위로(탐 필 4타)·앙코르(손뼉 롤)·대상(팡파르 + 깊은 덕킹)·요약. 룰렛 `exit` 큐는 통합 QA에서 연결했다(연출 종료 때 UI «close» 소리 + BGM 커튼 덕킹).
- **배경음**(`bgm.ts`·`bgmVoices.ts`): 128bpm E장조 신스팝. 룰렛(free) 변주는 반음 위 + 16분 하이햇 + 마디 끝 손뼉 롤 필인.
- **빅윈 `celebration`**: 아트 레인의 스킨(별·음표·색종이·배지 파티클, 후광, 둥근 글씨, 이 게임 팔레트)을 브라우저로 확인했다(430·390, surge·cataclysm 등급). 사선 빛줄기 없음.
- **전환 클립**: 아트 레인이 만든 진입·복귀 2편을 그대로 쓴다(SeeDance 추가 발주 없음, 3편 $2.79는 아트 레인에서 소진). 브라우저로 진입 → 룰렛 → 복귀 → 빅윈 흐름을 확인했다.
- 수치(참고값, 최종 귀 판정은 사용자): 릴 정지 «a hand clap» z +3.26(킥 아님), 기존 프리셋과 CLAP 코사인 전 이벤트 < 0.90, BGM −31.1 / 룰렛 변주 −30.2 LUFS, 30초 장면 믹스 true peak −4.0 dBTP, 릴 정지 SFX−BGM +3.6 dB.
