# Kraken Treasure Cave / 크라켄 보물 동굴

> 금화 6개가 뜨면 코인 리스핀. 세로 한 줄을 금화로 채우면 크라켄 촉수가 감아 숫자 코인이 2배.

**5릴 3행, 20 라인, 코인 리스핀(홀드 앤 스핀) + 촉수 감기.** 카탈로그 #9, 웨이브 3. 정본 계획은
`docs/PLAN_kraken-cove.md`이고, 응답·이벤트·디버그 계약은 그 문서 끝 「구현 계약」 절이다.

- 라인: 왼쪽부터 3·4·5연속, 배당 단위는 라인당 베팅액(`총 베팅 ÷ 20`). 선은 그리지 않는다(연출 몫)
- 와일드: 크라켄(릴 2·3·4만, 코인은 대체하지 않는다, 자체 배당 없음)
- 코인: 라인 배당 없음. 뜰 때마다 서버가 금액(총 베팅 ×1·×2·×3·×5·×10) 또는 보물(작은 ×20 · 중간 ×50 · 큰 ×200)을 정한다
- 코인 리스핀: 기본 판에 코인 6개 이상 → 코인 고정, 리스핀 3회, 새 코인이 붙으면 3회로 리셋, 15칸 또는 0회면 끝
- 촉수 감기: 세로줄 3칸이 코인으로 차면 그 줄 숫자 코인 ×2(줄마다 1회, 보물 코인은 그대로)
- 최고 보물: 15칸을 다 채우면 ×1000 추가
- 상한: 스핀(=라운드) 지급 2,000×(`round.maxWinCap`). 자연 최대는 숫자 240 + 보물 270 + 최고 1000 + 트리거 스핀 라인(코인 6개 이상이라 수백 배 미만) ≈ 1,700× 미만이라 실전 도달 0이 목표(감사 0건)
- 리스핀은 **트리거 스핀 응답 하나**에서 다 풀린다. 추가 베팅·서버 상태(`game_states`) 없음

### 다시 만들 때 알아 둘 것
- **`props`는 `thumb` 종류로 만들었다.** theme-gen·game-sdk에 `'prop'` 종류가 아직 없고, `symbol`로 두면 팩 검사가 «math.json에 없는 심볼»이라고 오류를 낸다.
  `'prop'`이 병합되면 `art/prompts.json`의 소품 5개 `kind`만 바꾸면 된다. 그 전에 소품을 `--force`로 다시 만들면 트림되지 않은 그림이 나오니,
  네 장은 투명 여백을 잘라(8% 여백 정사각, 384/512px) 쓰고 `tentacle`은 알파 경계로 잘라 곧은 띠만 남긴다. 128px 썸네일은 두지 않는다.
- **`frame`은 `--reprocess`/`--force`를 돌리면 아래쪽 흰 진주(조개 속)가 구멍으로 뚫린다.** `processFrame`의 «색 감지 창»이 흰 진주를 릴 창으로 오인해 알파 0으로 만든다
  (코덱스가 이미 알파 창을 줘서 진짜 창은 색으로 안 잡힌다). 지금 파일은 `art/raw/frame.png`에서 «알파 실측 창 + 2px만 비우기»로 다시 만든 것이다.
  이 파일을 다시 만들 일이 있으면 같은 방식으로 하거나 `frameWindow.ts`를 고칠 것.
- 시트는 `fit-sheet-to-symbol.mjs`(`D:/park/tgslot-wt/_tools`)로 정지 심볼과 같은 크기에 맞췄다(`coin-win`은 18% 컸다).
- `wild`·`wild-win` 프롬프트는 같은 문장(산호색 조개 티아라 + 터키석 보석, 꽃병 손잡이처럼 솟은 촉수)을 쓴다. 처음 `wild-win`은 정지 그림과 티아라·촉수 모양이 달라 다시 만들었다.
- `jellyfish`는 첫 생성에서 코덱스가 다른 곳의 그림(강아지·고양이 사진)을 회수해 와서 컨택트 시트 검수에서 걸러 `--force`로 다시 만들었다. 생성 직후 눈 검수는 필수다.
- `fs-enter`는 원본 mp4의 1.2–3.0초(1.8배속)+3.0–5.0초를 이은 가변속 컷이다. 한계: 금화 더미가 화면 아래 약 65%까지만 차고 위쪽에 동굴이 보인다
  (재발주 한도 때문에 진입은 그대로 썼다). `fs-exit`는 «초근접» 문장으로 1회 재발주한 컷(0.7–3.7초)이라 첫 프레임부터 금화로 덮여 있다.
  두 클립의 금화에 작은 «$» 비슷한 양각이 보이고, 복귀 클립의 드러나는 동굴은 장난감 톤보다 실사에 가깝다.
- `coin-win`의 금화 가장자리에 무지개빛 번짐이 약간 있다(반 바퀴 돌 때 옆면). 금화 얼굴 글자는 코드가 그리므로 이 시트를 쓸 때 글자도 같이 돌려야 한다.
