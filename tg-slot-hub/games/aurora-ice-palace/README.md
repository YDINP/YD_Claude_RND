# Aurora Ice Palace / 오로라 얼음 궁전

> 가운데가 가장 긴 마름모 판(3·4·5·4·3칸)에서 가운데 릴부터 양옆으로 이어지면 맞는다. 프리스핀에서는 가장 큰 당첨 그림이 얼어붙어 판 위로 번지고, 얼린 칸 수만큼 «얼음 보너스»를 받는다.

**5릴 마름모(19칸), 가운데부터 720길, 얼려 두기 프리스핀.** 정본 계획은 `docs/PLAN_aurora-ice-palace.md`이고,
응답·이벤트·디버그 계약은 그 문서 끝 「구현 계약」 절이다.

- 판: 릴 높이 `reelHeights = [3, 4, 5, 4, 3]`, `rows = 5`. 판 밖 칸은 응답 `grid`에 `"__void__"`(엔진 `VOID_CELL`)로 실린다
- 지급(`ways.from: "center"`): 가운데 릴에 있어야 하고, 가운데에서 좌우로 끊김 없이 이어진 최대 범위 하나(3·4·5릴)로 한 번만 준다. 길 수 = 줄에 든 릴의 맞는 칸 수 곱, 길당 베팅 = 총 베팅 ÷ 50
- 와일드: «육각 얼음»(판의 눈꽃 그림과 헷갈리지 않게 2026-11-28 «얼음 결정»에서 이름을 바꿨다. 2·3·4번 릴만, 구슬 말고 전부 대신, 자체 배당 없음. 와일드만으로 된 길은 북극곰으로 지급)
- 오로라 구슬(스캐터): 판 어디든 3·4·5개 이상 → 총 베팅 ×2.5·×12·×60 + 프리스핀 8·10·12회
- 얼려 두기 프리스핀: 판은 `frostRespin.freeStrips`로 멈춘다. 당첨이 있으면 금액이 가장 큰 그림(동점이면 배당표 위쪽)과 와일드 칸이 전부 언다 → 얼지 않은 칸만 다시 뽑기 → 새로 언 칸이 없거나 19칸이 차면 끝 → 얼린 칸 수 표로 얼음 보너스
- 오로라: 한 판에 15칸 이상 얼리면 한 단계 오르고 **그 판 보너스부터** ×1 → ×2 → ×3 → ×5. 얼음 보너스에만 곱한다. 라운드 끝에 사라진다
- 리트리거: 프리스핀 착지 판 구슬 3개 이상 → +4회, 라운드 총 20회 상한
- 상한: `round.maxWinCap = 2500`. 유료 판은 판 단위, 프리스핀은 진입 판을 뺀 프리스핀 합 누적. 누적이 상한에 닿으면 남은 횟수와 상관없이 라운드가 끝난다
