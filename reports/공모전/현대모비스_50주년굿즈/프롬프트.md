# 이미지 생성 기록 — 1977 컨테이너 데스크 박스

- 도구: Codex CLI 내장 image_gen (OpenAI gpt-image), `gen_gpt.py`, 프롬프트 원문은 `prompts.json` (style + v1 4장 + v2 2장)
- 생성 기록: `생성기록.json`, 원본 PNG `raw/`
- 후처리: `compose.py` — 빈 명판에 각인 문구를 원근 맞춰 합성(Pillow, 맑은 고딕). 설정은 `plates.json`. 실제 상표·로고 이미지는 쓰지 않음.

## 공통 스타일(요지)
중형 디지털 카메라·100mm 매크로·f/11 상업 제품 사진. 큰 창빛 하나+반사판, 접지 그림자. 20피트 ISO 컨테이너 1:40 강철 데스크 박스(약 15×6×6.5cm): 주름 측벽, 코너 캐스팅, 문 2짝·잠금봉 4개. 무광 남색 분체도장(오렌지필 질감). 금지: CGI·플라스틱 장난감 느낌, 광택, 과포화, HDR, 림라이트, 보케, 과샤픈, 반복 텍스처, 글자·숫자·로고·라벨, 사람·손.

## 버린 시안과 이유
- raw/v1_2.png (문 연 모습 1차): 긴 측벽 한 면이 통째로 없고 양 끝에 문이 달린 구조 오류 → 「문은 한쪽 끝에만, 나머지 다섯 면은 막힘」으로 다시 생성(v2_1).
- raw/v1_3.png (문 정면 1차): 잠금봉 4개 중 1개에 손잡이가 없음(3개) → 「네 봉 모두 같은 높이 손잡이」로 다시 생성(v2_2).

## 검수 메모(부분 확대)
- 히어로: 문 손잡이 2개(봉 2·3번)만 보임 — 실제 컨테이너 단순화 모형 수준으로 허용. 펜 길이와 박스 길이 비율이 실제 치수(약 14cm/15cm)와 맞음.
- 문 정면(v2_2): 정면 비율이 실제 20피트(폭<높이)보다 가로가 약간 넓음. 확대 컷이라 허용했으나 정밀 심사 시 눈에 띌 수 있음.
- 쌓기: 모든 박스 표면에 글자·표식 없음, 코너 캐스팅 정렬 정상.
- 합성 각인: 확대 크롭 `build/zoom_01_hero.png`, `build/zoom_03_plate.png` 확인.
