## KISTEP 지역 현안 해결 솔루션 챌린지 — 제출 방법

- 아이디어: **경기 하남 신도시 공사장 비산먼지 AI 조기경보망** (환경·기후 / 경기도)
- 참여형태: 개인 (팀원 추가 시 각 서류에 팀원 서명이 따로 필요)
- 파일 (`KISTEP_지역현안챌린지/`):
  1. `양식1_지역현안해결아이디어제안서.pdf` (4쪽, 6쪽 이내 기준 충족)
  2. `양식2_개인정보수집이용동의서.pdf`
  3. `양식3_참가자서약서.pdf`
  4. `양식4_제안아이디어제3자공개공유동의서.pdf`
- **확인할 것:** 양식1의 **직업** 칸이 비어 있음(정보 없음). 채우려면 알려주면 재생성.
- 받는 사람: **ideacontest@kistep.re.kr** · 문의 043-750-2357
- 제목 예: `[지역 현안 해결 솔루션 챌린지] 아이디어 제출 – 경기 하남 신도시 공사장 비산먼지 AI 조기경보망 / 박용진`
- 본문 예:
  ```
  안녕하세요. 「제1회 지역 현안 해결 솔루션 챌린지」에 아이디어를 제출합니다.
   - 아이디어명: 경기 하남 신도시 공사장 비산먼지 AI 조기경보망 (경기도 / 환경·기후)
   - 대표자: 박용진 (개인 참여)
   - 첨부: 양식1~4 (PDF 4개)
  접수 확인 부탁드립니다. 감사합니다.
  ```
- 유의: 공고상 "응모작이 타 공모전 수상작과 중복되면 결격". 정책 톡! 하남(버스 혼잡)과는 주제가 달라 해당 없음.
