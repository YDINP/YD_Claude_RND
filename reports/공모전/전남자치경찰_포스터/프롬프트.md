# 프롬프트 · 시안 기록 — 「자치경찰은 사고 ‘전’에 출동합니다」

- 생성: Codex CLI 내장 image_gen(gpt-image), 1024×1536 세로. 원문 프롬프트·스타일 전체는 `build/prompts.json`, 생성 기록(thread_id·원본 경로)은 `build/생성기록.json`.
- 후처리(`build/make_poster.py`): 테두리 종이 여백 16px 잘라 냄 → 176×250mm 비율로 크롭 → Lanczos 업스케일 2079×2733 + 약한 언샤프 → 가짜 글자 자국 2곳 지움(엔진 덮개의 'ILL' 모양 선, 조끼 옆 노란 점 / 색 조건 마스크 + 인페인트) → 하단 남색 띠 230px 붙임 → 그레인 → 한글 타이포 합성(Noto Serif KR 헤드라인, Noto Sans KR 본문, 2종).
- 최종: `build/raw/v2_2.png` → `자치경찰은 사고 전에 출동합니다(박용진).jpg` (2079×2953, 300dpi, JPG)

## 공통 스타일 (요지)
손으로 찍은 포스터: 냉압 종이 위 무광 과슈 + 3도 리소그래프(그레인, 살짝 어긋난 판), 제한 팔레트(남보라 해질녘 · 볏짚 황토 · 크림 종이) + 형광 안전노랑 별색은 반사지와 조끼 줄무늬에만. 위 40~55%는 빈 하늘(헤드라인 자리). 광택·과포화·렌즈플레어·보케·대칭·HDR·과잉 디테일·글자·로고·배지 금지.
