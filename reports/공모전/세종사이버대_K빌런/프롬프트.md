# 프롬프트·시안 기록 — 「한 편만 더 보면 안 잡아먹지」

## 컨셉 (통찰 한 줄)
「해와 달이 된 오누이」의 호랑이는 한 번에 잡아먹지 않고 **고개마다 떡을 하나씩** 받아 갔다. 지금 서울에서는 이것이 휴대전화 속 "한 편만 더"다. 무섭게 생긴 괴물보다 웃으며 '딱 하나만' 달라는 쪽이 진짜 빌런이다.

### 후보 3개 채점 (흔하지 않음 / 통찰 / 실행성, 각 5점)
| 후보 | 흔하지 않음 | 통찰 | 실행성 | 합 |
|---|---|---|---|---|
| **해님달님 호랑이 → "한 편만 더" 호랑이 (고개마다 떡 하나 = 숏폼 한 편)** | 4 | 5 | 5 | **14** |
| 도깨비감투 쓴 사람 → 익명 악플러 (투명해져 남의 것을 훔침) | 3 | 4 | 3 (투명한 빌런은 그림으로 보여 주기 어려움) | 10 |
| 놀부 → 제비 다리 부러뜨려 보상받는 '후기 조작·자작극' | 3 | 3 | 4 | 10 |

공고의 K-빌런 정의는 "한국 고전 설화 또는 전래동화 캐릭터의 재해석"이다. 그래서 설화 속 캐릭터를 그대로 쓰되, 공고 예시(도깨비·구미호·호랑이 일반)와 달리 **특정 설화 한 편의 줄거리 구조**를 현대에 그대로 옮긴 1안을 골랐다.

## 생성 도구
OpenAI ChatGPT 이미지 생성(gpt-image), Codex CLI 내장 image_gen 도구. 스크립트 `build/gen_gpt.py`, 기록 `build/생성기록.json`, 프롬프트 원문 `build/prompts_r1~r3.json`.

## 라운드별 시안 (`시안/`)
| 파일 | 내용 | 판정 |
|---|---|---|
| r1_A | 달동네 계단, 계단참마다 호랑이, 시네마틱 일러스트 | 탈락: 과한 발광·광택, 미세 디테일 과잉, 실제 서울 타워 실루엣(랜드마크 묘사) — 전형적인 AI 그림 느낌 |
| r1_B | 원룸 침대, 화면에서 나온 호랑이 | 탈락: 사이언 발광, 매끈한 피부, 'AI 일러스트' 느낌 |
| r1_C | 휴대전화 산맥 위 호랑이 | 탈락: 대칭 구도, 매끈한 3D 질감, 서울 타워 |
| r2_A | 리소 인쇄풍 계단 버전 | 후보: 사람이 그린 느낌은 좋음. 다만 호랑이가 떡을 **건네는** 것처럼 보여 빌런으로 읽히지 않음 |
| r2_B | 리소 인쇄풍 원룸 버전 | 탈락: 호랑이가 화면에서 나오는 것으로 보이지 않음, 서사가 약함 |
| **r3_A2** | 리소 인쇄풍 계단, **빈 손바닥** + 곁의 떡 더미가 위로 갈수록 높아짐, 능글맞은 표정 | **채택** |
| r3_C2 | 리소 인쇄풍 휴대전화 산맥 | 탈락: 호랑이 손이 사람 손, 행인이 조선 복장이라 '21세기 서울'에서 벗어남 |

### 최종 후보 비교 (r2_A vs r3_A2)
둘 다 리소 인쇄 질감이라 AI 느낌은 적다. r3_A2를 고른 이유: ① 빈 손바닥과 쌓인 떡으로 "더 내놔"가 한눈에 읽힌다. ② 반쯤 감은 눈, 혀 내민 웃음이 '능청스러운 사기꾼'으로 보인다. ③ 위쪽 남색 여백이 넓어 제목을 그림 위에 얹지 않아도 된다. ④ 색이 남색·주황·크림으로 더 절제돼 실제 인쇄물처럼 보인다.

## r3_A2 세부 검수 (확대 크롭 `build/crops/r3A2_*.png`, 직접 확인)
| 항목 | 결과 |
|---|---|
| 손가락 수 | 직장인: 양손으로 휴대전화를 쥠, 이상 없음. 호랑이 3마리: 만화식 손 4~5개, 같은 모양으로 일관됨 |
| 눈·얼굴 | 호랑이 3마리 모두 같은 얼굴(반쯤 감은 눈, 송곳니, 혀), 비대칭은 의도한 표정. 직장인 옆얼굴 이상 없음 |
| 녹아내린 사물 | 없음. 떡 더미 4·5·7단(위로 갈수록 높아짐 — 의도대로), 가방 안 노란 통 + 떡 1개 |
| 원근 | 계단, 계단참, 난간 원근 일관됨. 호랑이 크기가 거리에 맞게 작아짐 |
| 가짜 글자 | 간판 없음. 앞쪽 옹벽의 얼룩·금은 콘크리트 얼룩으로 읽히며 글자 모양이 아님(`r3A2_wall.png`) |
| 반복 텍스처 | 망점이 고르게 퍼져 있고 타일처럼 반복되는 부분 없음 |
| 가장자리 | 아래 끝이 계단에서 잘리지만 발은 화면 안에 있음 |
| 확대 품질 | 1800×2400 실제 크기 크롭(`p_100.png`) 확인, 망점 질감 덕에 뭉개짐 눈에 띄지 않음 |

손으로 고친 영역은 없음(크롭, 확대, 약한 언샤프만).

## 최종 프롬프트 (r3_A2)
**장면:** `build/prompts_r3.json` 의 A2 항목 (지원서에 원문 수록).
**공통 화풍:** 리소그래프 별색 4도(형광 주황·남색·겨자색·먹색), 크림 종이, 망점, 판 어긋남, 민화 목판식 붓선. 피할 것: 광택, 3D, 에어브러시 그라데이션, 과포화 네온, 보케, 렌즈 플레어, 대칭 구도, 플라스틱 피부, 과잉 디테일. 글자·로고 일절 금지, 특정 작가 화풍 금지.

## 타이포 (Pillow 후합성, `build/make_poster.py`)
- 글꼴 2종: 맑은 고딕 Bold(제목), 맑은 고딕 Regular(머리글·부제)
- 위계: 머리글 34px(자간 +2%) → 제목 156px 두 줄(자간 −5%, 띄어쓰기 75%, 행간 1.13, 둘째 줄 주황) → 부제 40px 두 줄, 제목 둘째 줄 기준선에 맞춰 오른쪽 정렬
- 좌우 여백 132px, 위 여백 104px. 글자와 달·물탱크 사이 간격 확인(`crops/p_top.png`)
- 출력: 1800×2400px(3:4), 300dpi, PNG
