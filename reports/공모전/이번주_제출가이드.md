## 3. 춘천시 시민 제안 — 10/31(토) (하반기 심사분 마감)

**어디서**
- 국민신문고 https://www.epeople.go.kr → 로그인 → **제안** → 제안 신청 → 처리기관 **강원특별자치도 춘천시** 선택
- 또는 춘천시 누리집 → 시민참여 → 시민 제안 (로그인 시 국민신문고로 연결될 수 있음)

**입력** — `춘천시민제안_빈상가주거전환.md`의 각 항목을 그대로 복사

| 입력란 | 붙여 넣을 내용 |
|---|---|
| 제목 | `원도심 장기 빈 상가를 청년·시니어 주거로 — 「빈 상가 주거전환 원스톱 창구」 도입` |
| 현황 및 문제점 | 파일의 「현황 및 문제점」 전체 (현황 3개 + 문제점 3개) |
| 개선방안 | 파일의 「개선방안」 ①~④ + ※ 리본 프로젝트와의 관계 |
| 기대효과 | 파일의 「기대효과」 4개 |

- 마크다운 기호(`**`, `-`)는 그대로 붙여도 되지만, 깔끔하게 하려면 `**`만 지우세요.
- 입력란 글자 수 제한에 걸리면: 현황의 인용문을 한 문장으로 줄이고, 개선방안 ④를 한 줄로 줄이세요.
- 제출 후 **접수번호를 캡처**해 두세요.
- 시상: 금 300만 · 은 200만 · 동 100만 · 장려 50만 · 노력 30만. 우수 제안은 시 누리집 고시 후 개별 연락. 문의 기획예산과 033-250-3713.
