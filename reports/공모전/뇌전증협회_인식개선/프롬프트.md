# 「붙잡지 말고, 재세요」 이미지 생성 기록

- 도구: Codex CLI 내장 image_gen(ChatGPT gpt-image), 1024×1536 세로. 스크립트 `build/gen_gpt.py`, 프롬프트 원문 `prompts.json`, 응답 로그 `raw/codex_v*.jsonl`, 생성 기록 `생성기록.json`
- 한글 문구는 이미지에 넣지 않고 `build/make_poster.py`(Pillow, Noto Sans KR 1종)로 합성 → A3 세로 3508×4961px 300dpi

## 컨셉 (통찰 1문장)
목격자가 잘못 행동하는 건 몰라서가 아니라 '뭐라도 해야 한다'는 손 때문이다 → 그 손에 할 일 하나(시간 재기)를 쥐여 준다.

## 공통 스타일 (요지)
과슈·콜드프레스 종이 결·드라이브러시, 3색 리소 인쇄 느낌(약한 판 어긋남), 팔레트 제한(짙은 보라·크림·번트 오렌지·회보라). 상단 36% 빈 종이(제목 자리), 하단 20% 빈 바닥(정보 띠 자리). 손가락 5개·관절 정상, 스톱워치 숫자 없음(눈금만). 금지: 광택·크롬·과포화·보케·HDR·대칭·과잉 디테일·글자·로고·피·구급장비. 원문은 `prompts.json`의 `style`.

## 시안과 판정
| 시안 | 내용 | 판정 |
|---|---|---|
| v1_1 | 위에서 본 보도, 겉옷 베고 누운 사람 + 스톱워치 든 손 | 버림: 얼굴을 겉옷에 묻은 엎드린 자세로 보여 '옆으로 눕히기' 수칙과 어긋남 |
| v1_2 | 크게 든 스톱워치 + 뒤에 누운 사람 | 버림: 사람 자세가 웅크려 엎드린 것처럼 모호, 손이 화면 아래까지 내려와 정보 띠에 가려짐 |
| v1_3 | 사람 없이 스톱워치·겉옷·가방 정물 | 버림: 안전하지만 '누구를 돕는지'가 안 보여 메시지가 약함 |
| v2_2 | 위에서 본 장면, 옆으로 누운 여성(얼굴 옆모습) + 손 | 버림: 얼굴은 자연스러우나 상체가 반쯤 엎드린 비틀린 자세, 발이 정보 띠에 걸림 |
| **v2_1** | 승강장 바닥에 옆으로 누운 사람(등·무릎 굽힘, 겉옷 베개) + 앞쪽에서 스톱워치 든 손 | **채택**: 회복 자세가 분명, 손이 사람을 만지지 않음, 상단·하단 여백이 레이아웃과 맞음 |

## 채택본 검수 (부분 확대)
- 손: 엄지 1(용두를 누름) + 손가락 4, 손톱·관절 방향 자연스러움, 붙거나 남는 손가락 없음 (`build/crops/v2_1_hand.png`, `final_hand.png`)
- 사람: 등을 보이며 옆으로 누움, 위쪽 무릎 굽힘, 머리는 접은 겉옷 위, 얼굴 안 보임(초상 문제 없음) (`build/crops/v2_1_person.png`)
- 스톱워치: 숫자·가짜 글자 없음, 눈금 12개, 바늘 1개 / 배경에 글자·로고·반복 텍스처 없음
- 확대(3.4배) 후 언샤프 마스크 + 약한 종이 결 노이즈로 업스케일 흐림을 가림
