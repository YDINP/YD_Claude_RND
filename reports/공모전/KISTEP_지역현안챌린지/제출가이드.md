## 5. 선정되면 (10월 중 통보)

**공동 기획 단계(10~11월)에서 준비할 것**
- 연구개발지원단 담당자와 회의 → 시범 지역(감일·교산 인접 권역), 센서 종류·대수, 예측 모델 범위를 구체화
- 하남시청(환경 부서)과 스마트시티 통합플랫폼 담당 부서에 협조 가능성 문의해 두면 발표평가에서 유리
- 상금은 **제안자와 연구개발지원단이 공동 수령**합니다 (대상 1,000만 · 최우수 600만 · 우수 300만)

**발표평가(12월) 예상 질문과 답변 요지**

| 예상 질문 | 답변 요지 |
|---|---|
| 서초구가 이미 하던 것 아닌가? | 서초구(2018)는 공사장 주변 실시간 **측정·감시**입니다. 본 제안은 기상예보와 공사 일정으로 **몇 시간 뒤 위험을 미리 예측**하고, 살수를 자동 가동하며, 흙 운반 차량을 영상으로 감시하고, 주민에게 공개하는 것까지 묶어 여러 대형 공사가 겹치는 신도시에 맞춘 것입니다. |
| 저가 센서는 정확도가 낮지 않나? | 공인 측정소 값으로 주기적으로 보정하고, 절대값보다 '평소 대비 급증'과 '공사장 간 비교'에 쓰므로 판단에 충분합니다. 경보 기준은 시범 운영 데이터로 조정합니다. |
| 비용은 누가 내나? | 시범은 R&D 과제로, 확대 단계에서는 시공사의 비산먼지 저감 의무와 연계해 센서 설치·살수 비용을 분담하는 구조를 제안했습니다. |
| 예측이 틀리면? | 살수 후 실제 농도 변화를 다시 학습해 정확도를 높이는 구조이고, 예측은 '선제 대응 권고'이지 단속 근거가 아니므로 오탐의 부담이 작습니다. |
| 왜 하남인가? | 교산(약 631만㎡)·3호선 연장(2027~2032)·캠프콜번 개발이 겹치고, 이미 입주한 신도시 바로 옆에서 공사하며, 아동 비중이 16.4%로 높습니다. 시장도 2026년 7월 '끝없는 공사판, 비산먼지' 고통을 직접 호소했습니다. |
| 다른 지역에도 쓸 수 있나? | 남양주 왕숙·고양 창릉·부천 대장·인천 계양 등 다른 3기 신도시와 대규모 재개발 지역에 표준 모델로 보급할 수 있습니다. |

  - 이 아이디어를 다른 공모전에 다시 내려면 KISTEP 결과가 나온 뒤에 하세요.
- 시상 후 문제가 발견되면 선정 취소와 상금 환수, 법적 책임은 참가자에게 있습니다.
