## 제안 요지

- 완도 주민등록 20·30대 약 5,300명 vs 외국인 주민 20·30대 4,756명(47%). 외국인 주민 5,957명 = 인구의 13.5%(전남 평균 4%). 이들이 전국 전복 70%를 내는 양식업의 손인데, E-9는 최장 4년 10개월이면 떠나고 가족도 못 데려오며, 군 정착 정책 대상(주민등록 기준)에도 없음
- 법무부(2026.6·10 E-7-4 개선, 단계 경로 고시 추진)·전남(E-7-4R 쿼터 558→993)이 길을 열었지만 섬 어가 근로자가 증빙·추천까지 혼자 갈 다리가 없음 → 군이 ① 체류 만료 달력 ② 완도 양식 기술 확인서 ③ 추천 기준 공개 ④ 가족 주택·가족센터 연결 ⑤ 성과지표
- 첫 달 시범: 2027.1. 노화읍·보길면 체류 3년 차 이상 20명(엑셀 명부 + 1쪽 확인서). 계절근로 MOU·한마음 행사·통합가족정책(결혼이민 중심)과 다름을 문서에 명시

## 확인할 것
- [ ] **hwpx는 한글 없이 XML로 채운 것** → 보내기 전 한글로 열어 쪽 넘김·글자 넘침 확인. 제2쪽은 작성방법 안내 행을 지우고 표가 쪽을 넘어 나뉘도록 설정. 참고자료는 hwpx에선 그림 대신 글(수치 목록)로 넣음
- [ ] hwpx에는 서명 이미지 없음(이름만, "(서명 또는 인)" 그대로). 서명은 PDF에만
- [ ] 작성일 2026. 11. 4.(지침대로) — 발송일과 맞추려면 content.py `ME` 의 d 만 바꾸고 `python -X utf8 make_pdf.py && python -X utf8 make_hwpx.py`
- [ ] 수치 기준 시점: 주민등록은 2026.10., 외국인 주민은 행안부 「외국인주민 현황」(k-calc 집계, 조사 기준일 표기 불분명). 문서에 "기준 시점 다름, 대략 비교"로 적음. 군청 자체 통계로 바꿀 수 있으면 더 좋음
- [ ] 군 발표(2025.8.)는 "외국인 근로자 1,100여 명"이라 행안부 2,805명과 다름(집계 범위 차이로 보임) — 문서엔 행안부 수치만 씀
- [ ] 완도군이 법무부 지역특화형 비자(F-2-R)·전남 E-7-4R 추천에 이미 참여 중인지는 확인 못 함. 참여 중이어도 이 제안은 "섬 어가 근로자를 그 제도까지 잇는 명부·확인서·가족 정착"이라 겹치지 않음
